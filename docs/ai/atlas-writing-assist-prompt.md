# Atlas Writing Assist Prompt — Green Fineness

Use this prompt when editing Green Fineness content inside browser-based writing tools such as Writing Desk Lite.

## Default Instruction

ช่วยเกลาภาษาให้เป็นสไตล์ Green Fineness / คุณตั้ม

หลักการ:
- สุขุม อ่านง่าย เป็นธรรมชาติ
- มีความรู้ แต่ไม่แข็งเกินไป
- ไม่ขายเกินจริง
- ไม่ใช้ภาษาตื่นเต้นเกินจำเป็น
- ไม่ overclaim เรื่องจุลินทรีย์ ธาตุอาหาร ปุ๋ย ดิน หรือผลลัพธ์ของพืช
- คงความหมายเดิม ไม่แต่งข้อมูลใหม่
- ถ้าข้อมูลไม่พอ ให้เขียนแบบระมัดระวัง
- ใช้คำว่า “อาจ”, “ในบางบริบท”, “ภายใต้เงื่อนไขที่เหมาะสม”, “มีส่วนเกี่ยวข้องกับ” เมื่อเป็นข้อกล่าวอ้างเชิงวิชาการ
- ไม่ทำให้จุลินทรีย์ ปุ๋ย หรือธาตุอาหารดูเป็นของวิเศษ
- รักษาโทน Knowledge Hub: สงบ ชัดเจน ถ่อมตัวทางความรู้

งาน:
[ใส่สิ่งที่ต้องการให้ช่วย]

## Example Use Case

Original:
จุลินทรีย์ช่วยตรึงไนโตรเจนให้พืชใช้ได้

Safer version:
จุลินทรีย์บางกลุ่มอาจมีส่วนเกี่ยวข้องกับการตรึงหรือเปลี่ยนรูปไนโตรเจนในดิน ภายใต้เงื่อนไขที่เหมาะสม ทำให้ไนโตรเจนบางส่วนอยู่ในรูปที่พืชสามารถนำไปใช้ได้มากขึ้น

## Workflow Note

Recommended workflow:

1. Write or paste draft in Writing Desk Lite
2. Run Arbor Review
3. Use Atlas Writing Assist only for specific fixes such as hook, paragraph clarity, or tone
4. Re-run Arbor Review
5. Export / Append to WorkOS
6. Final review before publish

Atlas Writing Assist is a point-editing helper.
Arbor Review remains the main editorial and claim-safety layer.
WorkOS remains the archive and workflow system.
