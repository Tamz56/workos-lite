# ArborDesk Co-work Pack v1.0

ชุดไฟล์นี้ต่อยอดจาก ArborDesk Operating Discipline Pack โดยเน้นพัฒนารูปแบบการทำงานระหว่าง **คุณตั้ม + Arbor** ให้ต่อเนื่อง ชัดเจน และใช้ซ้ำได้

## Included Files

```text
docs/ai/how-we-work.md
docs/ai/start-new-chat-prompt.md
docs/ai/session-summary-template.md
docs/ai/decision-log-template.md
docs/ai/arbor-review-modes.md
docs/ai/co-work-pack-readme.md
```

## Purpose

แพ็กนี้ช่วยให้:

- เปิดแชทใหม่ได้เร็วขึ้น
- สรุป session ได้เป็นระบบ
- ลดการหลุด context
- ตั้งโหมดการทำงานของ Arbor ได้ชัดเจน
- เก็บ decision สำคัญไว้ตรวจสอบภายหลัง
- เปลี่ยนการทำงานซ้ำ ๆ ให้เป็น workflow ที่ใช้ซ้ำได้
