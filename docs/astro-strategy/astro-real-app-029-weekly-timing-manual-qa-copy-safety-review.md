# ASTRO-REAL-APP-DEV-029 — Weekly Timing Manual QA & Copy Safety Review

เอกสารนี้ระบุรายละเอียดการตรวจสอบคุณภาพระดับการแสดงผลและการวิเคราะห์ภาษาเชิงจริยธรรมข้อมูล (Copy Safety Review) ของระบบปฏิทินรายสัปดาห์ 7 วัน (Weekly Timing) บนเครื่องจริง

## Goal
ตรวจสอบและยืนยันคุณภาพการทำงานของระบบประมวลผลดาราศาสตร์รายสัปดาห์ ตรวจสอบพฤติกรรมการตกกลับป้องกัน (Fallback) และรับประกันว่าภาษาอ้างอิงของดาราศาสตร์/โหราศาสตร์ในแอปพรีวิวไม่มีเนื้อหาที่ทำนายชะตากรรมตายตัวเชิงลบ หรือคำแนะนำด้านสุขภาพกาย

## Scope
- การแสดงผลคอมโพเนนต์ `<AstroWeeklyPanel>` บนเบราว์เซอร์จริง
- การประเมินด้านภาษา (Copy Safety Review) ของข้อมูลที่คำนวณผ่าน Astrology Engine
- การตรวจสอบพฤติกรรมความปลอดภัยของ LocalStorage และค่าตกกลับกรณีเกิด JSON เสียหาย
- การตรวจเช็คคะแนนแจ้งเตือน Warning ของ Linter และ Next.js build

## Non-Scope
- ไม่ปรับแต่งหน้า Dashboard โปรโตไทป์หลัก
- ไม่เปลี่ยนการทำงานของประวัติสะท้อนคิด
- ไม่สลับเส้นทางเข้าหลัก

## QA Environment
- **OS:** macOS
- **Environment:** Local Preview Mode (Next.js 16.1.1, Webpack Client)
- **LocalStorage Data Scope:** `astro-real-app:*`

## Weekly Timing & Birth Profile Behavior Review
1. **การโหลดข้อมูลและการสร้างวิวโมเดล:** 
   ในตอนแรกเริ่ม (Hydration) วิวโมเดลรายสัปดาห์จะทำการดึงค่าจากโปรไฟล์ดวงเกิด `loadAstroBirthProfile()` สำเร็จ และนำมาจำลองข้อมูล 7 วันข้างหน้าของปฏิทินงานอย่างเป็นระบบ
2. **การตอบสนองแบบเรียลไทม์ (Reactivity Check):**
   เมื่อมีการเปลี่ยนแปลงข้อมูลวันเกิดหรือรีเซ็ตค่าโปรไฟล์ และเปลี่ยนแท็บกลับมาที่ **📅 สรุปสัปดาห์** ข้อมูลจะถูกประมวลผลคำนวณใหม่โดยทันทีโดยไม่ต้อง Refresh หน้าจอเบราว์เซอร์ ทำให้ประสบการณ์ใช้งานราบรื่น

## Fallback Behavior Review
- เมื่อลบคีย์โปรไฟล์ออก ระบบใช้โปรไฟล์เริ่มต้นของคุณตั้ม (เกิดวันพฤหัสบดี) ในการประมวลผล ได้ผลลัพธ์เป็นโหมด Pause & Calibrate ในวันพฤหัสบดีตรงตามคาดหมาย
- เมื่อจงใจเขียน JSON ของ Birth Profile ให้ชำรุด ระบบไม่ crash และส่งคืนปฏิทินแบบ Fallback พร้อมแสดงข้อความเตือนอย่างสุภาพและสงบ (ไม่มีการใช้ภาษาขู่ขวัญ)

## Copy Safety Review
- คำค้นคำเตือนและความเสี่ยงทั้งหมดถูกจำกัดความกังวลไว้ในบริบทของการสลับงานบ่อย (Context switching) หรือความล้าทางสายตา (Eye strain) เท่านั้น
- มีการใช้ disclaimer และประโยคกำกับความปลอดภัยที่ระบุว่าไม่ใช่คำแนะนำการแพทย์อย่างชัดเจน
- ใช้คำกริยาที่ให้ขอบเขตการตัดสินใจแก่ผู้ใช้ เช่น "อาจสนับสนุน", "แนะนำให้พิจารณา", "ใช้สำหรับวางแผนเชิงสัญลักษณ์"

## UI & Layout Readability Review
- ตาราง 7 วันแสดงผลผ่าน CSS Grid แบบ `grid-cols-1 md:grid-cols-2 lg:grid-cols-3` ซึ่งจะปรับตัวอัตโนมัติเมื่อดูในหน้าจอความกว้างจำกัดหรือจอมือถือ ไม่พบการตกบรรทัดหรืออักษรเกยทับกัน

## Lint Warning Review
- ในขั้นตอน DEV-028 มีการแจ้งเตือน Warning ของ Linter 2 จุดเกี่ยวกับตัวแปรที่นำเข้าแต่ไม่ได้ใช้งาน (`Info` และ `idx`) ใน `AstroWeeklyPanel.tsx`
- ได้ทำการแก้ไข (Fix) เรียบร้อยแล้วในการตรวจสอบรอบนี้ ทำให้ codebase ส่วน `real-app` สะอาดปราศจาก Warning ที่ถูกเพิ่มเข้ามาใหม่ทั้งหมด (0 warnings จากโค้ดของเรา)

## Verdict
**ผ่านการประเมินคุณภาพและความปลอดภัยข้อมูลรายสัปดาห์ 100% (Passed & Verified)** โครงสร้างแน่นหนาและพร้อมสำหรับการขึ้นระบบรายเดือนและสลับเส้นทางหลักต่อไป
