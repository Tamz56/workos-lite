# DEV-030 — Monthly Reflection Integration QA & Copy-Safety Review

## Validation Checklist

### 1. UI Integration Verification
- [ ] สลับไปที่แท็บ **"📅 สรุปรอบเดือน"** ในหน้า Real App Preview แล้วแผง `AstroMonthlyPanel` แสดงผลถูกต้อง
- [ ] มีตารางแสดงสถิติประวัติสะสม 3 หมวดหมู่ (จำนวนบันทึกสะท้อนคิด, โหมดงานเด่น, แนวโน้มสภาพการทำงาน)
- [ ] คำเตือนจริยธรรมข้อมูลดาราศาสตร์และคำปฏิเสธความรับผิดชอบแสดงผลท้ายหน้ารายเดือน

### 2. Time Window Calculation Verification
- [ ] การคำนวณวันและโหมดใน `buildMonthlyReflectionViewModel` คำนวณตั้งแต่วันที่ 1 ถึงวันสุดท้ายของเดือนปัจจุบัน โดยอ้างอิงจากปีและเดือนจริงของเครื่อง
- [ ] สถิติการสะท้อนคิดกรองเฉพาะประวัติที่อยู่ในปีและเดือนปัจจุบันเท่านั้น

### 3. Optional Context & Fallback Verification
- [ ] กรณีมีประวัติการบันทึก: ระบบดึงข้อมูลจาก `historyLogs` มาสรุปเป็นข้อความ `reflectionPatternSummary` สอดคล้องกับประวัติ
- [ ] กรณีไม่มีประวัติการบันทึก (Empty Logs): หน้าจอแสดงข้อความแนะนำให้เริ่มบันทึกอย่างปลอดภัย และยังประมวลผลแผนกลยุทธ์จากดาราศาสตร์หลักได้สมบูรณ์ (ไม่พัง ไม่ค้าง)
- [ ] กรณี Birth Profile เสียหรือว่าง: ระบบเปลี่ยนมาประมวลผลโดยใช้โปรไฟล์ดวงเกิดเริ่มต้น (Default Profile) และแสดงคำเตือน Fallback สีเหลืองด้านบนแผงควบคุมอย่างเรียบร้อย

### 4. Copy-Safety and Tone Review
- [ ] ไม่มีคำว่า "ดวงร้าย", "ชะตาชีวิต", "สุขภาพ", "ความรัก" หรือคำทำนายแบบเด็ดขาดเชิงเคราะห์กรรม
- [ ] ไม่ใช้คำว่า "พลังงานเฉลี่ย" (ในลักษณะตัวเลขตัดสินศักยภาพ) แต่ใช้คำว่า "แนวโน้มสภาพการทำงาน" "สภาวะหลักที่ลงเช็คอิน" และ "โหมดจังหวะเวลาส่วนตัว"
- [ ] ข้อความคำอธิบายกระตุ้นการวางแผนและการฟื้นฟูสภาพแวดล้อมสมาธิ (Recovery Anchors, Focus Areas) คุมโทนการทำงานเชิงผลสัมฤทธิ์ (Professional Strategy)

### 5. Multi-Tab Dynamic Synchronization
- [ ] เมื่อมีการเปลี่ยนข้อมูล Birth Profile ในแท็บโปรไฟล์ หรือทำการเซฟประวัติสะท้อนคิดเพิ่มจากแท็บสะท้อนคิด ข้อมูลและสถิติในแผง "สรุปรอบเดือน" ได้รับการประมวลผลใหม่แบบเรียลไทม์โดยไม่ต้องรีโหลดหน้าเว็บใหม่
