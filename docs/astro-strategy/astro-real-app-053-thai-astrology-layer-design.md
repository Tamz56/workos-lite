# ASTRO-REAL-APP-DEV-053 — Thai Astrology Layer Design

## Goal
จัดทำเอกสารข้อกำหนดการออกแบบ (Design Specification) ของระบบ **Thai Astrology Strategy Layer v0.1** สำหรับเฟส **MVP-v4 — Advanced Astro Strategy Layer** ในระบบ Astro Strategy Lab ของ ArborDesk เพื่อเป็นแนวทางในการผสานแนวคิดฤกษ์ยามไทย (ยามอุบากอง และระบบธาตุวันเกิด) มาเป็นข้อมูลช่วยประคองโฟกัส การวางแผนเวลาทำงาน และการสะท้อนสติส่วนบุคคล โดยปราศจากความงมงายและการทำนายที่ฟันธงเด็ดขาด

---

## Scope
- การวิเคราะห์เหตุผลความสำคัญที่เลเยอร์ไทยควรถูกเริ่มพัฒนาก่อนเพื่อน
- ข้อกำหนดเป้าหมายผลิตภัณฑ์และกรณีใช้งาน (Use Cases) ในชีวิตประจำวัน
- รายละเอียดข้อมูลนำเข้า (Input Model) และข้อมูลส่งออก (Output Model) เฉพาะเลเยอร์
- การออกแบบแนวคิดหลักในเวอร์ชัน v0.1 (ยามอุบากองย่อ, ธาตุสัมพันธ์ประวัติดวงเกิด)
- ขอบเขตหัวข้อและฟีเจอร์ที่ต้องคัดออกในเวอร์ชันนี้ (Out of Scope for v0.1)
- เกณฑ์ความปลอดภัยทางภาษาตัวอย่าง (Copy-safety Rules & Text Patterns)
- การจัดการข้อขัดแย้งของสัญญาณข้ามระบบ (Conflict Resolution with Existing Engine)
- สถาปัตยกรรมตัวแปลงข้อมูล (Future Adapter Architecture)
- แผนการตรวจสอบความถูกต้อง (Manual QA Plan)

## Non-scope
- การแก้ไขหรือดัดแปลงซอร์สโค้ดโปรแกรมรันไทม์ในโฟลเดอร์ `src/` (Documentation-only)
- การเขียนโปรแกรมคำนวณปฏิทินดาราศาสตร์จริงในรอบรันนี้

## Why Thai Astrology Layer Should Be the First Implementation Candidate

1. **ความง่ายในการเชื่อมโยงและจัดเตรียมข้อมูล (Input Simplification)**:
   โหราศาสตร์ไทยขั้นต้นสามารถใช้ประวัติวันเกิดประจำสัปดาห์ (Birth Weekday) และวันเวลาเป้าหมายในการให้คำแนะนำที่ใช้งานได้ทันที ซึ่งในระบบ Birth Profile เดิมมีย่อยคีย์ข้อมูลนี้เรียบร้อยแล้ว จึงพร้อมใช้งานโดยไม่ต้องเพิ่มการดึงไลบรารีดาราศาสตร์ซับซ้อน (Ephemeris calculations) หรือคำนวณสมการดาวเคราะห์บนเบราว์เซอร์
2. **ความคุ้นเคยของผู้ใช้งานในบริบทวัฒนธรรม (Cultural Familiarity)**:
   ยามอุบากองเป็นศาสตร์สัญญะของเวลาที่คนไทยและคนทำงานในท้องถิ่นมีความเข้าใจพื้นฐานอยู่แล้ว สามารถนำมาดัดแปลงเป็น "เครื่องเตือนใจในการจัดรอบเวลาทำงานย่อย (Time-blocking Guide)" ได้อย่างเป็นธรรมชาติและมีประโยชน์ต่อการนัดหมาย
3. **ประสิทธิภาพของระบบและแนวคิด Local-first (Performance & Efficiency)**:
   การคำนวณฤกษ์ยามอุบากองแบบ Rule-based ใช้พื้นที่ประมวลผลต่ำมาก ทำให้แอปพลิเคชันยังคงทำงานได้อย่างรวดเร็วทันที ปลอดภัย ข้อมูลทั้งหมดคำนวณและประมวลผลอยู่บนคอมพิวเตอร์ของผู้ใช้โดยตรงโดยไม่มีการส่งข้อมูลออกสู่อินเทอร์เน็ต

## Thai Astrology Layer v0.1 Product Purpose
เป้าหมายของเวอร์ชัน v0.1 คือการทำหน้าที่เป็น **"กระจกสะท้อนจังหวะการจัดวางเวลา (Timing Contemplation Mirror)"** ช่วยเตือนสติให้ผู้ใช้งานบริหารสมาธิรอบวันและทบทวนความล้าสะสมตามธาตุเกิดของตนเอง โดยมุ่งลดภาวะหมดไฟ (Burnout prevention)

---

## Supported Use Cases in v0.1

1. **Daily Timing Reflection (ประเมินจังหวะการจัดวางนัดหมายรายวัน)**:
   ผู้ใช้สามารถเปิดดูตารางแบ่งย่อย 5 คาบเวลาทำงานในเวลากลางวัน (ยามอุบากอง) เพื่อประกอบการตัดสินใจส่งมอบงานนัดประชุมสำคัญ หรือเป็นช่วงเวลาเริ่มโปรเจกต์งานเขียนเชิงลึก
2. **Weekly Planning Support (การประเมินทิศทางรายสัปดาห์)**:
   เตือนให้ทราบว่าวันเกิดประเคราะห์หรือวันสมพงษ์ประจำสัปดาห์ตรงกับวันใด เพื่อประกอบการจัดลำดับงานเบา-งานหนัก
3. **Monthly Strategy Support (แผนกลยุทธ์รายเดือน)**:
   วิเคราะห์ภาพรวมการสะสมความล้าของดวงเกิดคู่กับธาตุประจำเดือนเพื่อแนะนำช่วงทบทวนระบบ
4. **Work Rhythm & Low-burnout Planning (สไตล์การทำงานอิงตามธาตุเกิด)**:
   นำเสนอคำแนะนำด้านท่าทีการทำงานที่สมดุลกับพลังงานของธาตุประจำตัว (ดิน น้ำ ลม ไฟ)
5. **Reflection Prompts (คำถามสะกิดใจจดบันทึก)**:
   แปลงสัญญะเชิงลบหรือเชิงระมัดระวังในยามต่างๆ ให้เป็นคำถามปลายเปิดเพื่อกระตุ้นให้ผู้ใช้วิจารณ์อุปสรรคในการสะท้อนคิดประจำวัน

## Core Concepts to Support in v0.1

### 1. Birth Weekday Interpretation (จังหวะวันเกิดสุริยคติประจำสัปดาห์)
- **วันรอบเกิด (Birth Weekday Cycle)**: เมื่อวันปัจจุบันตรงกับวันเกิดในสัปดาห์ (Solar Weekday Cycle) ระบบจะถือเป็นโหมด **Pause & Calibrate** แนะนำให้ชะลอการเปิดโครงการใหม่ และหันมาปิดงานค้างสะสม
- **วันกัลยาณมิตรประจำธาตุ (Supporting Days)**: แนะนำสไตล์การสื่อสารที่เกื้อกูลกับธาตุอื่นประจำวัน

### 2. Yam Ubakong (ยามอุบากองสำหรับการบริหารโฟกัสรายวัน)
แบ่งเวลา 24 ชั่วโมงออกเป็นช่วงเวลาละ 2 ชั่วโมง 24 นาที (กลางวัน 5 ยาม กลางคืน 5 ยาม) โดยการคำนวณอ้างอิงกับปฏิทินสุริยคติ/จันทรคติอย่างง่าย:
- **ยามปลอดโปร่ง (สี่จักรา/สองศูนย์)**: จังหวะเวลาที่จิตใจแจ่มใส โฟกัสดี เหมาะแก่งการประชุมสำคัญหรือการทำ Deep Work เขียนโค้ดหลัก
- **ยามระมัดระวังรอบคอบ (ยามศูนย์หนึ่ง/ยามมหาอุบาทว์)**: จังหวะเตือนใจเมื่อมีความตึงเครียดสะสม ให้เน้นการสะสางเอกสาร การทดสอบระบบ (QA/Testing) และการกำหนดจุดแวะพักหน้าจอชั่วคราว

### 3. Thai Element Alignment (ธาตุสัมพันธ์ ดิน น้ำ ลม ไฟ)
ประเมินความสอดคล้องของธาตุในวันนั้นๆ เพื่อกำหนดเป้าหมาย:
- **ธาตุลม (Wind)**: ส่งเสริมการคิดวิเคราะห์วางแผนการตลาดและการสื่อสาร
- **ธาตุดิน (Earth)**: ส่งเสริมการสะสางฐานข้อมูล เอกสารข้อตกลง โครงสร้างหลัก
- **ธาตุไฟ (Fire)**: ปลุกพลังสร้างสรรค์การออกแบบ UI ปิด Checkpoint รวดเร็ว
- **ธาตุน้ำ (Water)**: ส่งเสริมความยืดหยุ่น การเจรจาลดความตึงเครียด

## Concepts Explicitly Out of Scope for v0.1
* **ห้าม** คำนวณแผ่นดวงเกิดสุริยยาตร์ หรือการผูกดวงแบบดวงพิชัยสงคราม
* **ห้าม** คำนวณพิกัดดาวนพเคราะห์จริงด้วย Ephemeris Engine ขนาดใหญ่
* **ห้าม** คำนวณหรือพยากรณ์โรคภัยไข้เจ็บ อุบัติเหตุรุนแรง ความเป็นความตาย เคราะห์ตกต่ำ
* **ห้าม** ชี้นำให้ซื้อสินค้าบูชาวัตถุมงคล หรือบังคับให้ทำพิธีกรรมปัดเป่าเสนียดจัญไร

## Copy-Safety & Ethics Rules (คู่มือป้องกันความวิตกกังวลทางจิตใจ)

### 1. Example Safe Output Patterns (ข้อความที่อนุญาตให้นำเสนอ)
- *"จังหวะเวลาช่วงเวลานี้ตรงกับช่วงยามระมัดระวัง (ศูนย์หนึ่ง) เหมาะสำหรับการทบทวนและตรวจสอบเอกสารเพื่อความรอบคอบ แทนการตัดสินใจเร่งรีบ"*
- *"พลังธาตุลมไทยในวันนี้เอื้อต่อการจัดเรียงลำดับความคิดและวางโครงร่างข้อมูลแผนงานชิ้นถัดไป"*
- *"สอดคล้องกับจังหวะธาตุน้ำ: แนะนำให้เข้าหาการประสานงานด้วยความยืดหยุ่นและผ่อนปรนความขัดแย้ง"*

### 2. Example Unsafe Phrases to Avoid (ข้อความที่ห้ามปรากฏโดยเด็ดขาด)
- *"วันนี้เป็นยามอับโชคใหญ่ ห้ามเจรจาค้าขายเพราะจะเจ๊งและเสียทรัพย์แน่นอน"*
- *"ระวังอุบัติเหตุร้ายแรงในการเดินทางไปพบคู่ค้าบ่ายนี้"*
- *"ดวงชะตาขาด ห้ามทำงานและห้ามลงนามสัญญาเด็ดขาด"*

## Conflict Handling & Composer Integration
- **ลำดับความสำคัญ (Priority)**:
  หากตัวนำทางหลักของ Today Engine สั่งโหมดพักผ่อน `Pause & Calibrate` แต่ผลการประเมินยามไทยเป็นยามปลอดโปร่ง `ลุยได้เต็มที่` **ระบบ composer จะยึดถือโหมดพักผ่อนเป็นสำคัญ** 
  - *การแสดงผล*: แอปพลิเคชันจะแนะนำให้ผู้ใช้ "พักผ่อนเพื่อรักษาพลังจิตใจ" แต่จะแทรกข้อแนะนำย่อยว่า "หากจำเป็นต้องลงมือทำ ให้ใช้โอกาสความปลอดโปร่งในช่วงยามนี้เคลียร์งานเก่าอย่างรวดเร็วแทนการเปิดโครงการใหม่"

## Architectural Implications

### 1. Data Model Implications
- โครงสร้างคีย์ใน LocalStorage และ schema ของ `ReflectionHistoryItem` ต้องไม่มีการเปลี่ยนแปลงโครงสร้างหลัก โดยข้อมูลผลลัพธ์ของ Thai Astrology Layer จะถูกสกัดเป็น JSON ออบเจ็กต์เสริมภายใต้ฟิลด์ `timingContext` ของประวัติสะสม

### 2. Storage & Export/Import Implications
- ข้อมูลที่ถูก Backup ต้องคงความเป็น JSON ธรรมดา การตรวจสอบ Validator ใน v3 ต้องยอมรับ Optional data ของ `thaiAstroId` หรือ `thaiElementId` ได้อย่างยืดหยุ่น

### 3. UI Implications
- สัดส่วนของหน้าจอ Desktop Layout อิงตาม AGENTS.md จะแสดงผลตารางยามอุบากองย่อและการประเมินสมาธิในแผงประเมินด้านขวามือ (Right panel: 360–420px) โดยมีปุ่มปิด/เปิดแสดงผล (Toggle Button) เพื่อลดภาระสายตา

## Manual QA Checklist for Future Implementation
1. **วันเกิดครบรอบสุริยคติ (Weekday Match QA)**:
   - ทดสอบจำลองวันปัจจุบันให้ตรงกับวันใน Birth Profile (เช่น เกิดวันพฤหัสบดี วันปัจจุบันเป็นวันพฤหัสบดี) ตรวจสอบว่าระบบแนะนำ `Pause & Calibrate` และมีการแนะนำให้สังเกตสเตตัสความล้าถูกต้องหรือไม่
2. **การคัดกรองคำศัพท์ต้องห้าม (Forbidden Words QA)**:
   - ตรวจหาคำต้องห้ามในคลังข้อความ เช่น "เคราะห์กรรม", "อุบัติเหตุ", "วิบัติ", "หายนะ" ต้องไม่แสดงบนหน้าจอในทุกกรณี
3. **การตรวจสอบผลลัพธ์ยามอุบากองตามเวลาเบราว์เซอร์ (Time-zone QA)**:
   - ทดลองเปลี่ยนเวลาของระบบและตรวจสอบว่าช่วงยามอุบากองเปลี่ยนแผงตามคาบเวลา 2 ชั่วโมง 24 นาทีอย่างถูกต้องและไม่เกิด Hydration error บน Next.js
