# ASTRO-REAL-APP-DEV-073 — Thai Transit Output Contract & Copy Safety Review

## 1. Goal
จัดทำข้อกำหนดสัญญาข้อมูลผลลัพธ์ (Output Contract Specification) และสแกนความปลอดภัยของถ้อยคำภาษาหน้าจอ (Copy Safety Review) ของระบบดวงจรไทยเวอร์ชัน v0.1 (Thai Transit Timing v0.1) สำหรับเป็นแนวทางเชิงสถาปัตยกรรมของ Astro Strategy Lab ใน ArborDesk เพื่อแปลงพิกัดสัมพันธ์ดวงดาวไปเป็นกลยุทธ์การบริหารสมาธิและการพักผ่อน โดยรับประกันว่าจะปราศจากน้ำเสียงขู่เข็ญ โทนคำเตือนเชิงเคราะห์กรรม หรือคำสั่งทำนายตัดทอนการตัดสินใจของผู้ใช้

---

## 2. Output Contract Interface Concept
โครงสร้างสัญญาประเภทข้อมูลของผลลัพธ์การคำนวณและการแปลความหมายสำหรับเลเยอร์ดวงจรไทย v0.1:

```typescript
export interface ThaiTransitStrategyOutput {
  readonly layerName: "Thai Transit Strategy";
  /** ระบุระบบอัลกอริทึมที่คำนวณ */
  readonly source: string;
  /** วันที่ประเมินรอบดาวจร */
  readonly transitDate: string;
  /** โหมดวิถีเวลาจรประจำวัน (Focus | Stabilize | Pause) */
  readonly transitMode: "Focus" | "Stabilize" | "Pause";
  /** รายชื่อเรือนชะตาในดวงกำเนิดที่ดาวจรดวงสำคัญกุมสถิตอยู่ */
  readonly activeTransitHouses: string[];
  /** ข้อมูลสรุปดาวจรสำคัญ */
  readonly transitPlanetSummary: {
    readonly planetId: number;
    readonly zodiacSign: string;
    readonly isRetrograde: boolean;
  }[];
  /** รายการประเมินดาวจรกระทบเรือนชะตากำเนิด */
  readonly natalHouseImpacts: {
    readonly houseName: string;
    readonly impactLevel: "high_support" | "high_pressure" | "neutral";
    readonly durationDays: number;
  }[];
  /** ความสอดคล้องธาตุวันจรคู่ธาตุเกิด */
  readonly elementRelationship: {
    readonly compatibilityType: "supporting" | "neutral" | "clashing";
    readonly elementPairAdvice: string;
  };
  /** รายการรหัสสัญญาณการบริหารจังหวะงานประจำยามย่อย */
  readonly workTimingSignals: string[];
  /** รายการรหัสสัญญาณระมัดระวังการจดจ่อ */
  readonly decisionCautionSignals: string[];
  /** รายการรหัสสัญญาณการทำสมาธิพักผ่อนฟื้นฟู */
  readonly recoverySignals: string[];
  /** รายการกิจกรรม/โหมดงานที่ดาวจรสนับสนุนเชิงบวก */
  readonly recommendedWorkModes: string[];
  /** รายการกิจกรรม/สไตล์การทำงานที่ควรเลื่อนหรือชะลอออกไปชั่วคราว */
  readonly avoidOrDelayModes: string[];
  /** คำถามสะท้อนคิดประเมินจุดบล็อกความคิด */
  readonly reflectionPrompt: string;
  /** บันทึกคำอธิบายระดับความมั่นใจของโครงคำนวณ */
  readonly confidenceNotes: string;
  /** คำประกาศสิทธิ์การรักษาความเป็นอิสระและจริยธรรมข้อมูล */
  readonly safetyDisclaimer: string;
  /** วันเวลาประทับเมื่อสร้างออบเจ็กต์ */
  readonly generatedAt: string;
}
```

## 3. Field Definitions
* **transitMode**: ตัวแปรระดับสัญญะเพื่อระบุทิศทางภาพรวมของวันจรคู่ดวงกำเนิด โดยมี 3 สถานะ คือ **Focus** (ส่งเสริมการลุยสร้างงาน), **Stabilize** (การสะสาง จัดระเบียบเอกสาร), และ **Pause** (การพักผ่อน ตรวจทานเชิงลึกเพื่อระงับความเครียดสะสม)
* **natalHouseImpacts**: รายการบ่งชี้ผลลัพธ์เมื่อดาวจรพิกัดขยับเข้าทับหรือทำมุมในเรือนชะตาของแผ่นดวงเกิด พร้อมกับระบุระดับผลกระทบ (เช่น `high_pressure` เมื่อดาวเสาร์จรเข้าทับเรือนตนุ) และช่วงเวลาส่งผลโดยประมาณ (durationDays) เพื่อให้ผู้ใช้เตรียมตั้งรับปรับใจ
* **workTimingSignals**: รหัสอ้างอิงสั้น (IDs) เพื่อจับคู่นำข้อชี้แนะกิจกรรมลงมือทำงานที่สอดคล้องตามยามอุบากองและรอบธาตุรายวัน
* **decisionCautionSignals**: รหัสเตือนข้อเฝ้าระวังส่วนบุคคล เช่น สภาวะการสลับหน้าจอบ่อย (Context Switching) หรือความร้อนรนยามดาวอังคารจรทำมุมสัมพันธ์เชิงตึงเครียด
* **recoverySignals**: รหัสชี้ชวนให้สลับเข้าสู่โหมดฟื้นฟูจักระหรือพักสายตา 3 นาที
* **avoidOrDelayModes**: บ่งชี้ประเภทกระบวนการทำงานที่ควรเลื่อนออกไป (เช่น หลีกเลี่ยงการขึ้นฟีเจอร์หลักในรอบวันที่ดาวจรเรือนงานอริมีแรงกดดันสูง)
* **confidenceNotes**: คำรับรองเพื่อแจ้งให้ผู้ใช้ทราบว่าพารามิเตอร์ข้อมูลวันเกิดสมบูรณ์เพียงใดและระดับความผันผวนของค่าประมาณการเชิงสัญญะ

## 4. Signal ID Policy
เพื่อสกัดปัญหาการเพิ่มขึ้นของปริมาณข้อมูลจนพื้นที่ LocalStorage หรือไฟล์สำรองเต็ม (Data Bloat):
* **สิทธิการรันคำนวณ**: โค้ดในส่วน Calculation Layer จะประมวลผลและส่งผลลัพธ์เป็นรหัสสัญญาณสั้น (Short IDs เช่น `TH_SIG_REFACTOR`) เท่านั้น
* **สิทธิการเรนเดอร์**: Interpreter Layer จะทำหน้าที่ดึงข้อความภาษาไทยอธิบายรหัสสั้นจาก Static Client Dictionaries มาแมปแสดงผลบนหน้าจอแอปพลิเคชัน
* **ข้อห้ามบันทึก**: ห้ามนำเอาข้อความภาษาไทยที่แมปเสร็จแล้วเขียนบันทึกลงฐานข้อมูล `ReflectionHistoryItem` ของผู้ใช้โดยตรง แต่ให้อ้างอิงด้วยรหัสสั้นเพื่อประหยัดเนื้อที่การจัดเก็บและส่งออก JSON

## 5. Safe Copy Patterns (ถ้อยคำปลอดภัย)
คำชี้แนะกลยุทธ์ต้องเขียนด้วยโทนภาษาประนอมสติ กระตุ้นทางเลือกในการสะท้อนตนเอง:
* *"จังหวะรอบวันช่วงนี้เหมาะสำหรับการตรวจสอบความถูกต้องและดีบักระบบ แทนการโหมสร้างฟีเจอร์ใหม่"*
* *"ดาวจรทำมุมเฝ้าระวังในเรือนปัตนิ: แนะนำให้เข้าหาคู่เจรจาด้วยความยืดหยุ่นและการเจือจางความตึงเครียด"*
* *"เหมาะแก่การสะสางเอกสารคงค้างและการRefactor ลบโค้ดส่วนเกินที่ไม่ได้ใช้งาน"*
* *"ควรชะลอการตัดสินใจเรื่องใหญ่ที่ยังไม่มีข้อมูลรองรับที่รอบด้าน"*
* *"จัดสรรตารางเวลาสั้น ๆ เพื่อสลับพักฟื้นฟูสายตาและดื่มน้ำ"*

---

## 6. Forbidden Copy Patterns (คำศัพท์และโทนน้ำเสียงต้องห้าม)
ห้ามใช้คำสะกดจิตขู่หรือล่วงละเมิดความมีอิสระในการกำหนดชีวิตของผู้ใช้เด็ดขาด:
* *"จะเกิดเหตุอุบัติเหตุร้ายแรงแน่นอน"*, *"เป็นวันเคราะห์กรรมตกต่ำซวยที่สุด"*
* *"ห้ามลงนามสัญญาตัวนี้เด็ดขาดเพราะจะโดนโกงแน่นอน"*
* *"ความสัมพันธ์กำลังจะล่มสลาย เงินทองจะรั่วไหลสูญสิ้น"*
* *"ดวงชะตากาลกิณีห้ามก้าวขาออกจากบ้าน"*
* คำแนะนำและคำเคลมเกินจริงเกี่ยวกับการรักษาโรคทางกายภาพ หรือคำชี้แนะทางการแพทย์ จริยธรรมการเงิน

## 7. Transit-to-Strategy Mapping Safety
ตารางจับคู่สัมพันธภาพดาวจรตกเรือนกำเนิดไปเป็นข้อแนะแนวพฤติกรรมทำงานปลอดภัย:
* **กัมมะ (การงาน)** -> *"จังหวะเหมาะกับการทบทวนวินัย ลำดับความสำคัญ และกระบวนการดำเนินภารกิจหลัก"*
* **อริ (อุปสรรค)** -> *"จังหวะที่ดีในการสแกนสเปก ค้นหาจุดบกพร่อง ทำ QA และแก้ไขบั๊กที่ค้างสะสม"*
* **ลาภะ (ความสำเร็จ)** -> *"จังหวะปิดโปรเจกต์ ส่งมอบผลงาน หรือเขียนสะท้อนความสำเร็จประจำสัปดาห์"*
* **วินาศ (เบื้องหลัง)** -> *"จังหวะสำหรับเคลียร์โฟลเดอร์ ค้นคว้าข้อมูลเชิงลึก (Research) หรือจัดระเบียบสารสนเทศส่วนตัว"*
* **ปัตนิ (ผู้คน)** -> *"จังหวะดีในการนัดประชุม สรุปข้อตกลง หรือรับฟังความคิดเห็นจากคู่สัญญาแบบประนีประนอม"*
* **ตนุ (พลังชีวิตตัวตน)** -> *"จังหวะประเมินระดับกำลังสมาธิ ตรวจเช็คความล้าส่วนบุคคลเพื่อจัดสรรภารกิจ"*

## 8. Conflict Handling
* **ความตึงเครียดขัดแย้งเชิงจังหวะเวลา**: หากระบบคำนวณดวงจรชี้ว่าดวงขึ้นมีแรงหนุนดีพร้อมลุย แต่บันทึกประวัติสะท้อนคิดของผู้ใช้ระบุว่ามีความล้าสะสมในเกณฑ์หนัก -> ระบบ interpreter จะต้องยึด **"Low-burnout priority"** เป็นที่ตั้ง แนะนำให้ผู้ใช้เบรกการทำงานและสลับไปที่โหมดพักผ่อนโดยไม่มีการโฆษณาโหมลุยงานตามดวงดาว
* **ลำดับการเหนี่ยวรั้งความขัดแย้งข้ามระบบ**: หากกล่องจรไทยวิเคราะห์ข้อเสนอตรงกันข้ามกับ Today Engine หรือศาสตร์เมตาฟิสิกส์จีน -> ระบบจะให้ความสำคัญแก่ Today Engine ของ ArborDesk เป็นหลัก และมองผลดวงดาวเป็นเพียงบริบทอ้างอิงเสริมช่วยเปรียบเทียบ

## 9. User Autonomy Disclaimer

> **[!NOTE]**
> *คำแนะนำดวงจรและฤกษ์ยามโบราณเป็นเพียงเครื่องมือสะท้อนสัญญะสำหรับช่วยวางแผนรอบวันและประเมินสมาธิส่วนบุคคล ไม่ใช่คำทำนายโชคชะตาเบ็ดเสร็จหรือทดแทนการตัดสินใจของผู้ใช้ ผู้ใช้ควรพิจารณาตัดสินใจโดยอ้างอิงตามสุขภาพทางกาย ความพร้อมของเวลา และความเป็นจริงเฉพาะตนเป็นสำคัญ*

## 10. Storage / Export / Import Compatibility
* **ไม่มีการดัดแปลงในเฟสนี้**: ยังไม่มีการเพิ่มหรือดัดแปลง schema ภายในเครื่องคอมพิวเตอร์จริง
* **ความเป็นมิตรกับข้อมูลเก่า (Compatibility)**: ข้อมูลวิเคราะห์ระบบดวงจร v0.1 ในอนาคตจะจัดเก็บในรูป optional structure และบันทึกเพียงเฉพาะรหัสสั้น (Signal IDs) ส่งผลให้กระบวนการนำเข้าไฟล์สำรอง JSON MVP-v3 ดั้งเดิมยังคงผ่าน Validator ได้อย่างปลอดภัย
