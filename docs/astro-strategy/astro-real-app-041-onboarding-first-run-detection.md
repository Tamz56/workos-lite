# ASTRO-REAL-APP-DEV-041 — Onboarding / First-Run Detection Implementation

เอกสารรายละเอียดสถาปัตยกรรมและผลลัพธ์ของฟีเจอร์ตรวจจับการใช้งานครั้งแรก (First-run/Onboarding Detection Layer) สำหรับ Astro Real App MVP-v3

## Goal
ออกแบบระบบตรวจจับสถานะผู้ใช้ใหม่เพื่อแสดงแผงคำแนะนำการจัดจังหวะชีวิตและการสะท้อนคิดครั้งแรกอย่างเหมาะสม อบอุ่น และไม่บังคับ/ขัดขวางการทำงานหลักของระบบ โดยยังคงรักษาข้อมูลเก่าของผู้ใช้ทั้งหมดและไม่เขียนทับพื้นที่จัดเก็บเดิม

---

## Scope & Non-Scope

### ขอบเขตงาน (Scope)
1. เพิ่มคีย์ควบคุม Onboarding พิเศษเฉพาะ: `astro-real-app:onboarding:v1`
2. สร้างโมดูลวิเคราะห์สถานะและสัญญาณ First-run (ตรวจสอบการไม่มีอยู่ของคีย์ Birth Profile และ Reflection History)
3. พัฒนาคอมโพเนนต์ `<AstroOnboardingPanel>` ที่รองรับการแนะนำและการนำทางไปยังแท็บต่าง ๆ พร้อมปุ่มซ่อน (Dismiss)
4. ผสานสถานะเข้ากับเพจหลัก `AstroRealAppPreview.tsx` ทั้งโหมด Production และ Preview
5. ผูกฟังก์ชันรีเซ็ต Onboarding เข้ากับเครื่องมือรีเซ็ตของ Data Tools ในหน้า Preview

### นอกเหนือขอบเขต (Non-Scope)
- ไม่ทำการสลับเส้นทางนำทางหลัก หรือปรับโครงสร้างโฟลเดอร์เพจเดิม
- ไม่ลบหรือย้ายข้อมูลโดยอัตโนมัติ (No Auto-migration)
- ไม่แก้ไขระบบประวัติสะสมเก่าของโปรโตไทป์หลัก
- ไม่เขียนทับคีย์ดวงเกิดดั้งเดิม หรือทำการย้ายข้อมูลข้ามระบบเว้นแต่ผู้ใช้จะกดยืนยันผ่าน Data Tools เอง

---

## Detection Rules & Storage Key

### คีย์จัดเก็บข้อมูล Onboarding
- **LocalStorage Key**: `astro-real-app:onboarding:v1`
- **โครงสร้างข้อมูล**:
  ```typescript
  export interface AstroOnboardingStorageEnvelope {
    version: number;
    updatedAt: string;
    isDismissed: boolean;
  }
  ```

### เงื่อนไขการตรวจจับการใช้งานครั้งแรก (First-Run Detection)
แผง Onboarding จะแสดงผลเมื่อ:
1. ค่าใน LocalStorage คีย์ `astro-real-app:onboarding:v1` มีฟิลด์ `isDismissed` เป็น `false` หรือไม่มีคีย์นี้อยู่ (Null)
2. **และ** ตรวจพบลักษณะการใช้งานครั้งแรกอย่างน้อย 1 อย่าง:
   - คีย์โปรไฟล์วันเกิด (`astro-real-app:birth-profile:v1`) ไม่มีอยู่ในระบบ (ยังไม่ได้กรอก)
   - คีย์ประวัติสะท้อนคิด (`astro-real-app:reflection-history:v1`) ไม่มีอยู่ในระบบ (ยังไม่มีประวัติสะสม)

## UI Behavior & Production vs Preview

- **Calm and Non-Blocking**: แผงแนะนำจัดวางในส่วนบนสุดของเพจ (ถัดจาก Banner หัวข้อแอป) เพื่อชี้แนะการเริ่มต้นใช้งาน แต่ไม่ใช้วิธี Modal บดบังหน้าจอ ทำให้ผู้ใช้สามารถกดใช้แท็บงานอื่น ๆ (เช่น Today, Weekly, Monthly) ได้ทันทีอย่างอิสระ
- **Interactive Checklists**: ลิงก์ภายในแผงแนะนำ เช่น "ไปที่แท็บโปรไฟล์ดวงเกิด" สามารถคลิกเพื่อเปลี่ยนแท็บหลักของแอปได้โดยตรง เพื่อความสะดวกรวดเร็ว
- **Production Mode**: แสดงแผงแนะนำเหมือนปกติหากตรงเงื่อนไข เพื่อแนะนำผู้ใช้งานทั่วไป
- **Preview Mode**: แสดงแผงแนะนำและมีส่วนแนะนำการโอนย้ายข้อมูลเดิมเพิ่มเติม หากตรวจพบประวัติในคีย์เดิมของบราวเซอร์ นอกจากนี้ผู้ใช้สามารถเข้าแท็บ **"เครื่องมือข้อมูล" (Data Tools)** เพื่อสั่ง Reset Onboarding หรือล้างค่าพรีวิวทั้งหมดกลับมาทดสอบซ้ำได้

---

## Data Safety & Copy Safety Language

- **Data Privacy**: ข้อมูลทั้งหมดถูกจัดการและจัดเก็บที่ฝั่งไคลเอนต์ (LocalStorage) โดยตรง ไม่มีการส่งออกนอกเครื่องคอมพิวเตอร์
- **Ethical & Safety Copy**: หลีกเลี่ยงภาษาเชิงชะตาลิขิต เคราะห์ร้าย หรือข้อบ่งชี้ทางแพทย์ โดยแสดงผลว่าจังหวะเวลาเป็นเพียงกรอบสะท้อนเชิงสัญลักษณ์ (Symbolic Reflection Aids) ในการวางแผนเท่านั้น ปราศจากการทำนายเชิงหลอกหลอน
- **Dismiss Writing**: จะเขียนข้อมูลลงคีย์ `astro-real-app:onboarding:v1` เฉพาะเมื่อผู้ใช้คลิกปุ่ม **"รับทราบ / ซ่อนไว้ก่อน"** เท่านั้น โดยไม่มีการสุ่มเขียนหรือสร้างโปรไฟล์ขึ้นมาเองโดยพลการ
