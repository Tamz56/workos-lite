## 2. UI Hierarchy Review (โครงสร้างการเรียงลำดับสายตา)

แผงควบคุมหลักเรียงลำดับดิ่ง (Vertical Order) ได้อย่างถูกต้องตรงตามโครงสร้างที่ได้รับมอบหมาย:
1. **Daily Timing Brief Header**: แสดงผลส่วนบนสุดของ Today Panel
2. **Today's Mode / Strategic Direction**: แสดงเป้าหมายจังหวะสูงสุดประเมินจาก Today Engine ดั้งเดิม (มีคลาส `sm:col-span-2` กว้างเต็มจอ)

6. **Metadata / Disclaimer**: แสดงข้อมูลระบบและคำเตือนสิทธิ์ความปลอดภัยล่างสุดของฟอร์ม

## 3. Composer Summary Behavior (พฤติกรรมการกางพับและการแสดงเอาท์พุต)

- **ความทัศนวิสัย**: จะแสดงผลเลเยอร์สรุปนี้เฉพาะเมื่อมีค่า `composerStrategyContext` เท่านั้น
- **การทนต่อข้อผิดพลาด (Graceful Degrade)**: ในกรณีที่ Context มีค่าเป็น `null` ระบบจะไม่เรนเดอร์เลเยอร์นี้ และไม่ทำให้ส่วนติดต่อผู้ใช้อื่นพังหรือค้าง
- **ความไม่รกของหน้าจอ (Clean Layout)**: ปิดบังรหัสสัญญะดิบเบื้องหลังอย่าง `supportingSignals` และ `suppressedSignals` ไว้ทั้งหมด แสดงผลเฉพาะข้อแนะนำเนื้อหาภาษาไทยที่อ่านง่ายและกระชับ
- **การสลับย่อ-กาง (Accordion Toggle)**: ฟังก์ชัน Accordion สามารถย่อและกางได้เต็มรูปแบบ และตั้งค่าเริ่มต้นปิดกล่องรายละเอียดปลีกย่อยไว้ตามเกณฑ์ความหนาแน่นสายตา (Compact visual layout)
- **การประคองสติ**: แสดงเป้าหมายและน้ำหนักข้อเสนอแนะหลักเพียง 1 ยุทธศาสตร์หลัก, ข้อควรระวัง 1 จุด, กิจกรรมคืนพลัง 1 จุด และคำถามสะท้อน 1 ข้อ ไม่แย่งชิงหรือข่มระบบ Today Engine เดิม

## 4. Hydration Safety (ความปลอดภัยในการ Server Render)

- **ไม่มี Hydration Mismatch**: การคำนวณเอาท์พุตกลยุทธ์ประสานรวมจะเริ่มทำงานหลังจากการทำ Hydration เรียบร้อยแล้วเท่านั้น (`isHydrated === true`)
- **การควบคุมเวลารันไทม์**: ไม่มีการเรียกหรือพิมพ์ค่าวัตถุ `Date` สดบน server-side render path ป้องกันสเตตัสเวลาเบราว์เซอร์ไม่ตรงกับเซิร์ฟเวอร์
- **การรีเฟรชค่าข้อมูล**:
  - เมื่อผู้ใช้ทำการรีเซ็ตข้อมูลจำลองผ่าน Data Tools ตัวประมวลผล Composer จะคำนวณสดใหม่ทันทีบนโปรไฟล์มาตรฐานจำลอง
  - เมื่อผู้ใช้สลับแท็บไปมา (Tab Active Recalculation) ระบบจะตรวจจับการกลับมาหน้าสรุปและอัปเดตสัญญะกลยุทธ์รวมใหม่เสมอ ไม่มีปัญหาดึงข้อมูลค้างเก่า (Stale context)

## 5. Data Safety (การปกป้องโครงสร้างข้อมูล)

- **ห้ามบันทึก Composer**: ไม่มีคำสั่งเซฟค่าเอาท์พุต Composer ลง LocalStorage ในทุกรันไทม์
- **รักษา Schema เดิม**: โครงสร้างประวัติสะสม `ReflectionHistoryItem` ไม่ได้รับผลกระทบ
- **ไม่ยุ่งเกี่ยวกับระบบนำเข้า-ส่งออก**: กระบวนการ Import / Export / Restore ทำงานบน Baseline ดั้งเดิมของระบบ โดยไม่มีการเพิ่ม Layer Composer เข้าไปเกี่ยวข้อง

## 6. Copy Safety Scan (การคัดกรองคำต้องห้ามเชิงจิตวิทยา)

จากการรันคำสั่งสแกน Regex คำต้องห้ามทั้งหมดในไดเรกทอรี `src/` และ `docs/` มีรายละเอียดความปลอดภัยดังนี้:
- **คำว่า "เคราะห์"**: พบเฉพาะคำว่า **"วิเคราะห์"** (Analyze) และ **"สังเคราะห์"** (Synthesize) เท่านั้น ซึ่งจัดอยู่ในการแสดงความหมายเชิงวิชาการ/เชิงสร้างสรรค์ตามบริบทงานระบบ ไม่ใช่ความหมายเชิงงมงายหรือเคราะห์กรรม
- **คำต้องห้ามลบและฟันธงอื่นๆ**: **ไม่พบ** คำว่า *เคราะห์ (ในความหมายไม่ปลอดภัย), ซวย, กาลกิณี, อุบัติเหตุ, เงินเสียแน่, งานพัง, ความรักพัง, ห้ามทำเด็ดขาด, จะเกิดแน่นอน, ดวงบังคับ, ต้องทำวันนี้เท่านั้น, ถ้าไม่ทำจะเสียโอกาส* ปรากฏอยู่ในซอร์สโค้ดและรายงานใดๆ
- **บทสรุป**: ความปลอดภัยด้านคำศัพท์เป็นไปตามแนวทางจิตวิทยาบวกเชิงระบบ 100%

## 7. Fallback Test Cases (สถานการณ์ทดสอบการกู้คืนระบบ)

- **ไม่มีโปรไฟล์ดวงเกิด (No Birth Profile)**: ระบบประเมิน Composer จะปรับลดระดับความมั่นใจลงเหลือประมาณ 45% (Confidence score drops) และใช้ MOCK_TODAY_DATA และ fallback ย่อยเป็น baseline แทนอย่างปลอดภัยโดยไม่ Crash
- **ไม่มีประวัติบันทึกสะท้อนคิด (No Reflection History)**: ระบบดึงสถิติล้าเป็น 0 ครั้ง และไม่เข้าเงื่อนไขความเหนื่อยล้าสูง ทำให้ Composer ประเมินน้ำหนักกลยุทธ์ตาม Today Engine ดั้งเดิมปกติ
- **ดวงจรไทยเกิดข้อผิดพลาด (No Thai Transit Context)**: Composer ข้ามการประเมินดาวจร และคำนวณเป้าหมายความล้าคู่กับ Today Engine ทั่วไปตามตรรกะประนีประนอม
- **Composer คำนวณขัดข้อง (Returns null)**: UI ซ่อนเลเยอร์ Composer และทำงานตาม Today Engine ดั้งเดิมเสถียร
- **ความเหนื่อยล้าสูง (High Fatigue State)**: เมื่อตรวจพบระดับความล้าหรือร่างกายล้ามากจากประวัติสะสมล่าสุด ระบบสลับเข้าโหมดฟื้นฟู `Recover` อัตโนมัติและระงับการทำงานตึงเครียด (Suppressed signals triggered)
- **การรีเซ็ตข้อมูลและสลับหน้าจอ (Reset Data & Tab toggling)**: ค่ากลยุทธ์รวมเปลี่ยนแปลงตามโปรไฟล์และประวัติการสะท้อนคิดอย่างเรียลไทม์

## 8. Regression Review (การทดสอบความเสถียรย้อนหลัง)

- **ความคงอยู่ของระบบเดิม**:
  - ระบบ Today Engine ตัวเดิมยังทำงานและคำนวณโหมดทิศทางได้สมบูรณ์
  - การ์ดยามไทยอุบากอง (Thai Timing) แสดงอัตราความสอดคล้องปกติ
  - การ์ดธาตุจีนย่อย (Chinese Metaphysics) และดาวจรไทย (Thai Transit) แสดงเนื้อหาตรงตามหลักการคำนวณเบื้องหลัง
  - หน้าสรุปสัปดาห์ (Weekly) และเดือน (Monthly) ดึงโปรไฟล์และประวัติสะสมไปทำแผนงานได้ปกติ
  - ไม่เกิดผลกระทบย้อนหลังต่อ API, Schema ของฐานข้อมูล และระบบ Routing หลัก
