# QA Verification Record — ASTRO-REAL-APP-DEV-023

เอกสารนี้ใช้บันทึกผลการรับรองคุณภาพ (Quality Assurance) สำหรับหน้าจอจัดการข้อมูลวันเกิด (Birth Profile Form UI)

## Scope of Verification
- ตรวจสอบการคอมไพล์ TypeScript และความถูกต้องของ Syntax ทั้งหมด
- ตรวจสอบว่าฟอร์มโหลดค่าข้อมูลวันเกิดเริ่มต้น (คุณตั้ม) สำเร็จเมื่อไม่มีข้อมูลเดิมเก็บอยู่
- ตรวจสอบฟังก์ชันการบันทึก (Save) ข้อมูลลง `astro-real-app:birth-profile:v1`
- ตรวจสอบฟังก์ชันการรีเซ็ตค่าเริ่มต้น (Reset to default) ว่ามีการแจ้งเตือนยืนยันและดึงค่ากลับมาปกติ
- ตรวจสอบว่าระบบกรองข้อผิดพลาดการกรอกข้อมูล (Validation validation) ปฏิบัติงานได้ถูกต้อง (เช่น รูปแบบวันเกิด/เวลาผิดพลาด)
- รันลินต์เตือนปัญหาโค้ดและรันคอมไพล์ Next.js build ทั้งหมด

## Verification Checklist

### 1. UI Rendering & Initial State
- [x] แผงควบคุมแสดงผลแท็บใหม่ "👤 โปรไฟล์ดวงเกิด" (Birth Profile) ในเมนูนำทาง
- [x] เมื่อเปิดแท็บครั้งแรกและไม่มีคีย์ดั้งเดิม ระบบโหลดค่าโปรไฟล์เริ่มต้น (คุณตั้ม / อภิรักษ์, เกิด 5 มิ.ย. 1980 เวลา 06:45)
- [x] แสดงข้อความเตือนทางจริยธรรมข้อมูลและสิทธิส่วนบุคคลอย่างเด่นชัด

### 2. Form Input & Validation
- [x] เมื่อป้อนข้อมูลรูปแบบวันที่ไม่ถูกต้อง (ไม่ใช่ YYYY-MM-DD หรือพิมพ์ผิดปฏิทิน) และกดบันทึก ระบบบล็อกและแสดงคำแจ้งเตือน error ใต้ฟิลด์
- [x] เมื่อป้อนข้อมูลรูปแบบเวลาไม่ถูกต้อง (ไม่ใช่ HH:mm หรือเกินช่วง 23:59) และกดบันทึก ระบบบล็อกและแสดงคำแจ้งเตือน error ใต้ฟิลด์
- [x] ฟิลด์บังคับอื่นๆ (ชื่อจริง, ชื่อแสดงผล, สถานที่เกิด, เขตเวลา) หากลบว่างเปล่า ระบบแจ้งเตือน error ใต้ฟิลด์เมื่อกดบันทึก

### 3. Save & Reset Persistence
- [x] กดปุ่มบันทึก (เมื่อข้อมูลถูกต้องทั้งหมด) ระบบเซฟลงคีย์ `astro-real-app:birth-profile:v1` ครอบใน Envelope สำเร็จ และขึ้นแบนเนอร์ติ๊กถูกสีเขียว (Success Feedback)
- [x] กดปุ่มรีเซ็ตเป็นค่าเริ่มต้น มีการแสดง Confirm Window แจ้งเตือน และสลับข้อมูลบนหน้าฟอร์มกลับมาเป็นค่าเริ่มต้นเมื่อกดยืนยัน
- [x] ข้อมูลประวัติสะท้อนคิด, แผนกลยุทธ์, ดราฟต์พิมพ์ค้าง และคีย์ของฝั่งโปรโตไทป์หลักไม่ได้รับผลกระทบใด ๆ จากระบบโปรไฟล์นี้

### 4. Code & Build Health

- [x] `npm run lint` ตรวจผ่านฉลุย (ไม่มี Error, ไม่มี Warning)
