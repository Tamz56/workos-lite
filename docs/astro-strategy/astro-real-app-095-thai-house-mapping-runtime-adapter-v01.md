# ASTRO-REAL-APP-DEV-095 — Thai House Mapping Runtime Adapter v0.1 Report

เอกสารรายงานการนำระบบจัดผังเรือนชะตาไทย 12 ภพเวอร์ชัน 0.1 (Thai House Mapping Runtime Adapter v0.1) เข้าไปนำไปใช้ประมวลผลเชิงระบบในส่วนรันไทม์

---

## 1. Goal (วัตถุประสงค์และผลสัมฤทธิ์)

* **สร้างอแดปเตอร์รันไทม์**: พัฒนาโมดูลจัดวางเรือนชะตาจากจุดตั้งต้นราศีลัคนาอ้างอิงของชุดประมาณค่าดั้งเดิม ออกมาเป็นผัง 12 ภพของปฏิทินไทย
* **ระบบข้อมูลเชิงพฤติกรรม**: ส่งออกแบบร่างคุณลักษณะของกิจกรรมงานในรูปของชุดรหัสสั้น (Strategic Signal IDs) ปราศจากการแสดงเนื้อหาทำนายยาวหรือข้อความตัดสินโชคชะตา
* **ข้อจำกัดความเสถียรข้อมูล**: 
  - ทำงานแบบ In-memory เสมอเมื่อมีการเมาท์หน้าระบบ ไม่เขียนข้อมูลลงใน LocalStorage
  - ปิดกั้นการทำงานกับส่วนอินเตอร์เฟซผู้ใช้ (UI Components) ในรอบการรันงานนี้เพื่อความปลอดภัย

## 2. Proposed Changes (การเปลี่ยนแปลงไฟล์ระบบ)

### [astroRealAppTypes.ts](file:///Users/tamz/projects/workos-lite/src/components/workspaces/astro-strategy/real-app/data/astroRealAppTypes.ts)
* เพิ่มนิยามประเภทข้อมูล `ThaiZodiacSign`, `ThaiHouseName` และ `ThaiHouseNumber` สำหรับควบคุมความกว้างพารามิเตอร์โหราศาสตร์ไทย
* ออกแบบ Types และ Interface โครงสร้างอินพุต `ThaiHouseMappingInput` และโครงสร้างเอาต์พุต `ThaiHousePlacementV01` ตลอดจนอินเตอร์เฟซตัวจัดส่งข้อมูลผังภพชะตาหลัก `ThaiHouseMappingV01`

### [astroRealAppThaiHouseMappingAdapter.ts](file:///Users/tamz/projects/workos-lite/src/components/workspaces/astro-strategy/real-app/data/astroRealAppThaiHouseMappingAdapter.ts) [NEW]
* พัฒนาฟังก์ชันคำนวณการเดินราศีแบบ Equal Sign ทวนเข็มจักรราศีมาตรฐาน 12 ราศีทวนเข็มนาฬิกา
* จัดทำฟังก์ชันประเมินคะแนนความมั่นใจรายภพชะตา `calculateHouseConfidence` และกระบวนการลดทอนความเชื่อมั่นเมื่อข้อมูลตั้งต้นไม่แน่ชัด
* สร้างระบบคำเตือนสัญญะก้ำกึ่งรอยต่อเปลี่ยนวันเกิดผ่าน `buildHouseMappingConfidenceNotes` และแจ้งเตือนความคลาดเคลื่อนรายภพ
* คัดกรองและสกัดเอาต์พุตกลยุทธ์เฉพาะ Signal IDs สั้นในหมวดต่างๆ เพื่อเตรียมแมปคู่คำแปลในพจนานุกรมในเฟสถัดไป

## 3. Data Safety & No Persistence Status (ความปลอดภัยข้อมูลส่วนบุคคล)

* **ปราศจาก Side-effects ทาง LocalStorage**: ไม่มีคำสั่งจัดเก็บข้อมูลเรือนชะตาลงสู่หน่วยความจำถาวรของเบราว์เซอร์
* **ไม่มีการดัดแปลง Schema ประวัติ**: รักษาเสถียรภาพของโครงสร้างข้อมูลเดิม ปราศจากความเบี่ยงเบนของระบบ Import / Export / Restore
* **การปกป้องความเป็นส่วนตัว**: พฤติกรรมการสกัดข้อมูลเกิดเป็น Signal IDs ช่วยลดความเสี่ยงการจัดเก็บประวัติข้อมูลอ่อนไหวระดับบุคคลสูง
