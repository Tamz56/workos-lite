# ASTRO-REAL-APP-DEV-061 — Chinese Metaphysics Layer Design

## Goal
จัดทำเอกสารข้อกำหนดการออกแบบ (Design Specification) สำหรับ **Chinese Metaphysics Strategy Layer v0.1** ในระบบ Astro Strategy Lab ของ ArborDesk เพื่อนำเอาแนวคิดเรื่องพลังงาน 5 ธาตุและรอบฤดูกาลจีน (Five Elements & Seasonal Rhythm) มาประยุกต์ใช้เป็นข้อมูลช่วยวางแผนงาน บริหารสมาธิเชิงกลยุทธ์ และเตือนสติประคองความเหนื่อยล้าสะสมของผู้ใช้ โดยเป็นงานเฉพาะเอกสารเท่านั้นและไม่มีผลข้างเคียงต่อระบบรันไทม์เดิม

---

## Scope
- เหตุผลความจำเป็นและลำดับความต่อเนื่องถัดจากระบบยามไทย v0.1
- วัตถุประสงค์ผลิตภัณฑ์ของ Chinese Metaphysics v0.1 และความสัมพันธ์กับระบบยามไทย
- รายละเอียดข้อมูลนำเข้า (Input Model) และข้อมูลส่งออก (Output Model) เจาะลึกรายฟิลด์
- การออกแบบตรรกะระดับสัญญะของห้าธาตุและรอบฤดูกาลจีน
- รายการฟีเจอร์ที่อยู่นอกเหนือขอบเขตในเวอร์ชันนี้ (Out of Scope for v0.1)
- เกณฑ์ความปลอดภัยทางภาษาและตัวอย่างประโยคคัดกรอง (Copy-safety Guardrails)
- ลอจิกการผสานและขจัดข้อขัดแย้งของสัญญาณข้ามศาสตร์ (Conflict Handling & Low-burnout priority)
- ผลกระทบต่อสถาปัตยกรรมระบบดั้งเดิม (Data Model, Storage, Export/Import, UI)
- แผนการตรวจรับคุณภาพ (Manual QA Plan)

## Non-scope
- การเขียนโปรแกรมหรือปรับปรุงรหัสไฟล์รันไทม์ในโฟลเดอร์ `src/` (Documentation-only)
- การคำนวณปฏิทินจีน 100% สุริยคติ/จันทรคติที่อิงตามดาวเคราะห์จริง
- การปรับปรุง UI หรือเพิ่ม component จริงในรอบงานนี้

1. **การสร้างแม่แบบอ้างอิงที่มั่นคง (Pattern Reference)**:
   ความสำเร็จในการอิมพลีเมนต์ Thai Astrology Layer v0.1 ใน Today Panel (DEV-059) ได้วางฐานรากของลอจิกการโหลดเวลาหลัง Mount (Hydration state) และการประหยัดพื้นที่จัดเก็บข้อมูลด้วยการเก็บเฉพาะรหัส IDs ได้อย่างดีเยี่ยม การออกแบบระบบจีนโดยล้อไปตามแนวทางของระบบไทยช่วยรักษาความสอดคล้องทางวิศวกรรมซอฟต์แวร์
2. **ขยายมิติวางแผนระยะกลางถึงระยะยาว (Medium-to-Long-term Framing)**:
   ในขณะที่ระบบยามอุบากองไทยโฟกัสที่จังหวะเวลารายชั่วโมง (Short-term Timing) เลเยอร์จีนจะเข้ามาทำหน้าที่เป็นกรอบเวลาสะท้อนตนเองในระยะปฏิทินรายฤดูกาล (Seasonal & Element Balance) เพื่อช่วยให้ผู้ใช้เห็นจังหวะการใช้พลังงานในระดับเดือนหรือสัปดาห์ได้อย่างเป็นระบบ

## Relationship to Existing Thai Astrology Layer
* **การเสริมพลังในต่างระนาบเวลา (Temporal Complementarity)**:
  * **Thai Astrology Layer (ยามอุบากอง)**: ทำหน้าที่ระบุจังหวะเวลาเฉพาะชั่วโมง/ช่วงยามประจำวัน (Short-term Execution Timing) เน้นการปรับพฤติกรรมในชั่วโมงนั้นๆ
  * **Chinese Metaphysics Layer**: ทำหน้าที่ให้กรอบสะท้อนตนเองระยะยาวตามรอบฤดูกาล (Medium-to-Long-term Strategy) และธาตุคู่มิตร/คู่ปรับ เพื่อกำหนดทิศทางสมาธิในภาพกว้าง
* **การซ้อนทับแบบปราศจากการทำลาย (Non-destructive Layering)**:
  สองเลเยอร์นี้ทำงานแยกอิสระจากกันในแง่ตรรกะข้อมูล แต่จะถูกผสานโดยระบบรวมสัญญาณ (Composer) ก่อนแสดงผล เพื่อสะท้อนความเชื่อมโยงของเวลาเชิงกลยุทธ์รอบตัวผู้ใช้

## Supported Use Cases in v0.1

* **Daily Balance Reflection (การรักษาสมดุลสมาธิประจำวัน)**:
  นำธาตุประจำวันปัจจุบันมาจับคู่กับธาตุตัวตนเพื่อเตือนสติว่าควรชดเชยหรือลดทอนพฤติกรรมการทำงานแบบใด
* **Weekly Work Rhythm Support (การจัดระบบสัปดาห์)**:
  จัดลำดับความเร่งด่วนของภารกิจเขียนโปรแกรม/เขียนบทความตามธาตุธรรมชาติประจำสัปดาห์
* **Monthly Strategy Support (ภาพรวมฤดูกาลรายเดือน)**:
  ประเมินความเหนื่อยล้าอิงตามรอบฤดูกาลจีนเพื่อแนะนำจังหวะการสะสมพลังสมอง
* **Elemental Balance Framing (กรอบปรับสมดุลธาตุ)**:
  แนะนำสไตล์การทำงานอิงตามวงจรการเกื้อกูล (Generation Cycle) และควบคุม (Control Cycle)
* **Reflection Prompts (คำถามสะท้อนคิดเชิงกลยุทธ์)**:
  ใช้สัญญะของธรรมชาติจีนชวนให้ตั้งคำถามปลายเปิดเพื่อเขียนบันทึกลงประวัติสะสม
* **Low-burnout planning (การวางแผนป้องกันความเหนื่อยล้าสะสม)**:
  หลีกเลี่ยงการกระตุ้นให้ลงมือทำรุนแรงในช่วงที่ธาตุตัวตนและฤดูกาลปัจจุบันขัดแย้งกันอย่างหนัก โดยจะแนะนำกลยุทธ์ประคองตัวแทนการทุ่มพลังหมดตัว

## Input Model (โมเดลข้อมูลเข้า)

ข้อมูลนำเข้าสำหรับระบบคำนวณและประมวลผลจีน v0.1 ประกอบด้วย:

1. **Birth Date (วันเดือนปีเกิด)**: วันเกิดของผู้ใช้เพื่อใช้กำหนดธาตุเกิดหลักประจำตัวอย่างง่าย (Day Master Element) เช่น `"1992-05-18"`
2. **Birth Time (เวลาเกิด)**: เวลาเกิดของผู้ใช้เพื่อประเมินความแม่นยำของเสาเวลาแบบย่อ (เช่น ช่วงเช้า กลางวัน เย็น หรือกลางคืน)
3. **Birth Place / Timezone (สถานที่เกิดและเขตเวลา)**: เพื่อปรับความสอดคล้องของพิกัดเวลาเกิดจริงกับเวลาสุริยคติ
4. **Current Date (วันที่ประเมินเป้าหมาย)**: วันเดือนปีของวันที่ต้องการประเมินในปัจจุบัน (targetDate) เช่น `"2026-06-13"`
5. **Current Season / Month (ฤดูกาลหรือเดือนปัจจุบัน)**: ฤดูกาลปัจจุบันอ้างอิงตามค่าคงที่ประเมินย่อ (`spring` | `summer` | `autumn` | `winter` | `earth-transition`) ร่วมกับชื่อเดือนปัจจุบัน
6. **User Intention / Question (เจตจำนงหรือคำถามของผู้ใช้)**: ข้อความเป้าหมายหรือคำถามในวันนี้เพื่อให้ปัญญาประดิษฐ์หรือระบบใช้ปรับแต่งการตอบสนองสะท้อนสติ
7. **Reflection History Context (ประวัติการสะท้อนคิดย้อนหลัง)**: ข้อมูลบันทึกความล้าและพลังงานสะสมจาก `reflectionHistoryContext` เพื่อนำมาประเมินความสมดุลของธาตุที่ขาดไปจริง
8. **Existing Today / Thai Context Signals (สัญญาณจาก Today Engine และเลเยอร์ไทยเดิม)**: ข้อมูลยามอุบากองไทยเด่น และสเตตัส Today Engine ปัจจุบัน (`Stabilize & Structure` | `Focus & Deliver` | `Pause & Calibrate`)

```typescript
export interface ChineseMetaphysicsInput {
  /** birthProfile ครบถ้วนประกอบด้วย birthDate, birthTime, birthPlace, timezone */
  readonly birthProfile: AstroBirthProfile;
  /** วันที่ประเมินเป้าหมาย เช่น "2026-06-13" */
  readonly targetDate: string;
  /** ฤดูกาลปัจจุบันอ้างอิงตามค่าคงที่ประเมินย่อ */
  readonly targetSeason?: "spring" | "summer" | "autumn" | "winter" | "earth-transition";
  /** คำถามหรือเจตจำนงในการประเมินจังหวะการทำงานในวันนี้ */
  readonly userIntention?: string;
  /** ประวัติการเช็คอินเพื่อวิเคราะห์ธาตุที่ขาดสมดุล */
  readonly reflectionHistoryContext?: readonly ReflectionHistoryItem[];
  /** สัญญาณจากเลเยอร์ไทยและ Today Engine ในปัจจุบัน */
  readonly currentTodayMode?: string;
  readonly currentThaiYamId?: string;
}
```

## Core Concepts to Support in v0.1

### 1. Five Elements as Symbolic Strategy Language (ห้าธาตุแห่งสติและการลงมือทำ)
* **ธาตุไม้ (Wood)**: สัญญะแห่งการเติบโตและการแผ่ขยาย -> สนับสนุนการริเริ่มวางแผนระบบ สร้างโมดูลใหม่ หรือการดีไซน์แนวคิดหลัก
* **ธาตุไฟ (Fire)**: สัญญะแห่งการแสดงออกและการส่องสว่าง -> สนับสนุนการปิด checkpoint ส่งมอบผลงาน หรือการเขียนฟีเจอร์เร่งด่วน
* **ธาตุดิน (Earth)**: สัญญะแห่งความมั่นคงและศูนย์รวม -> สนับสนุนการบันทึกสรุปข้อมูล จัดการฐานข้อมูล เคลียร์งานเอกสาร
* **ธาตุทอง (Metal)**: สัญญะแห่งการควบคุมและการตัดทอน -> สนับสนุนการ Refactor โค้ด ตัดทอน Todo list ส่วนเกิน
* **ธาตุน้ำ (Water)**: สัญญะแห่งความยืดหยุ่นและลื่นไหล -> สนับสนุนการเจรจา ประสานงาน ย้ายสถานที่ทำงานเพื่อลดอาการล้า

### 2. Seasonal Rhythm (รอบฤดูกาลทำงาน)
แบ่งช่วงเดือนในรอบปีออกเป็นฤดูกาลอย่างง่าย เพื่อเตือนใจการใช้พลังงานในชีวิตจริง:
- **ฤดูใบไม้ผลิ (ก.พ. - เม.ย.) [ธาตุไม้]**: จังหวะเวลาแห่งการวางโครงการใหม่และการเริ่มต้นขยายขอบเขต
- **ฤดูร้อน (พ.ค. - ก.ค.) [ธาตุไฟ]**: จังหวะเวลาทุ่มพลังงานการพัฒนาและส่งมอบงานชิ้นใหญ่
- **ฤดูใบไม้ร่วง (ส.ค. - ต.ค.) [ธาตุทอง]**: จังหวะเวลาแห่งการ Refactor การตรวจสอบความถูกต้อง และการคัดจัดระเบียบ
- **ฤดูหนาว (พ.ย. - ม.ค.) [ธาตุน้ำ]**: จังหวะเวลาแห่งความสงบ ชะลอความเร็ว และหันมาวางแผนในมุมลึก
- **ดินรอยต่อฤดูกาล (ช่วงสัปดาห์สุดท้ายของแต่ละฤดู) [ธาตุดิน]**: ช่วงเวลาพักสะสาง จัดเรียงของ และฟื้นฟูร่างกาย

### 3. Balance / Imbalance as Planning Metaphor (ความสมดุล/ไม่สมดุลเป็นอุปมาอุปไมยการวางแผน)
* ระบบจะไม่ใช้คำว่า "ดวงดี" หรือ "ดวงตก" แต่ใช้สถานะพลังงานธาตุ เช่น **ธาตุล้นเกิน (Excess)** หรือ **ธาตุอ่อนกำลัง (Deficient)**
* ใช้กรอบคิดนี้เตือนใจว่าหากช่วงที่ผ่านมาลุยงานหนักมาก (พลังธาตุไฟ/ไม้สูงเกินจนเหนื่อยล้าสะสม) ควรวางแผนงานแบบธาตุน้ำหรือดินเพื่อชดเชย

### 4. Generation and Control Cycle (วงจรเกื้อกูลและควบคุม)
* **วงจรเกื้อกูล (Generation)**: ไม้ส่งเสริมไฟ -> ไฟส่งเสริมดิน -> ดินส่งเสริมทอง -> ทองส่งเสริมน้ำ -> น้ำส่งเสริมไม้
  * *ประโยชน์ใช้งาน*: หากต้องการไอเดียเติบโต (ธาตุไม้) ควรจัดระเบียบจิตใจให้ยืดหยุ่นลื่นไหล (ธาตุน้ำ)
* **วงจรควบคุม (Control)**: ไม้ทำลายดิน -> ดินทำลายน้ำ -> น้ำทำลายไฟ -> ไฟทำลายทอง -> ทองทำลายไม้
  * *ประโยชน์ใช้งาน*: หากอารมณ์ฟุ้งซ่านร้อนรน (ธาตุไฟล้น) ให้ใช้การตีกรอบวินัยและจำกัด Todo List (ธาตุทองควบคุม) หรือใช้ความยืดหยุ่นสยบความร้อน (ธาตุน้ำ)

### 5. Simple Element Tendency Mapping (การจับคู่แนวโน้มพลังงานอย่างย่อ)
* คำนวณหาธาตุหลักประจำวันเกิดอย่างง่าย (อิงปฏิทินสากลแปลงเป็นปฏิทินจีนแบบจำลอง) เพื่อให้ผลลัพธ์ธาตุตัวตนเด่น
* ทำการเปรียบเทียบเชิงสถิติเบื้องต้นกับธาตุของวันปัจจุบันและฤดูกาล เพื่อให้ได้คะแนนความสอดคล้อง (Alignment score)

## Concepts Explicitly Out of Scope for v0.1
* **ห้าม** คำนวณเสาหลักชะตาชีวิต BaZi เต็มรูปแบบ (สี่เสาชะตา เสาเวลาเกิด เสาปีเกิด)
* **ห้าม** คำนวณฮวงจุ้ยดาวเหิน (Flying Star Feng Shui) หรือชี้แนะตำแหน่งที่ตั้งอาคารสำนักงานและโต๊ะทำงานเชิงความลี้ลับ
* **ห้าม** ทำนายเรื่องโชคลาภการเงิน ความมั่งคั่งร่ำรวย การลงทุนหุ้น หรือการันตีผลลัพธ์ความสัมพันธ์และคู่ครอง
* **ห้าม** บังคับให้ทำพิธีกรรมปัดเป่าเคราะห์ หรือซื้อขายวัตถุมงคลฮวงจุ้ยเพื่อแก้เคล็ด
* **ห้าม** อ้างหลักการพยากรณ์เชิงกำหนดผลลัพธ์ตายตัว (Deterministic Fate) หรือใช้ภาษาเชิงข่มขู่ให้เกิดความกลัว (Fear-based language)

## Conflict Handling & Composer Integration

### 1. Conflict Handling with Today Engine
- **หลักการ**: Today Engine ถือเป็นเกณฑ์วิเคราะห์แกนหลักของสมาธิและปริมาณงาน (Workload & Burnout limits)
- **การจัดการ**: หาก Today Engine กำหนดให้พักผ่อน `Pause & Calibrate` แต่ระบบจีนวิเคราะห์รอบฤดูเป็นธาตุไฟ (พลังส่งเสริมความกระตือรือร้นลุยงาน) **ระบบ Composer จะดึงคำสั่งพักผ่อนของ Today Engine ขึ้นนำหน้าเสมอ** และผนวกข้อความจีนว่า *"แม้สัญญะธาตุไฟจะเร่งความเร้าใจในการเขียนโค้ด แต่ดัชนีสะสมความล้าของระบบหลักชี้ว่าควรชะลอตัวและผ่อนคลายเพื่อกันชนความเสี่ยงเหนื่อยล้าสะสม"*

### 2. Conflict Handling with Thai Astrology Layer
- **หลักการ**: ระบบไทยเน้นช่วงเวลารายชั่วโมง (Micro-timing) ระบบจีนเน้นสมดุลฤดูกาลและธาตุประจำวัน (Macro-timing)
- **การจัดการ**: หากยามอุบากองไทยเป็นยามเฝ้าระวังความล้า (ศูนย์หนึ่ง) แต่อิทธิพลฤดูกาลจีนเป็นธาตุทองเชิงสนับสนุน ระบบ Composer จะแสดงข้อมูลแยกส่วนแบบไม่ขัดแย้ง โดยชี้ว่า *"ชั่วโมงปัจจุบันควรพักสายตาตามรอบยามอุบากอง (ยามไทย) แต่ภาพรวมสัปดาห์นี้ธาตุทองยังคงเหมาะสมกับการจัดระเบียบงานสถาปัตยกรรม (จีน)"* หากสัญญาณมีความตึงเครียดสูงขัดกันอย่างรุนแรง ระบบจะระบุสเตตัสเตือนภัยระดับกลางแบบ `Mixed Signals` เพื่อให้ผู้ใช้ตัดสินใจอย่างรอบคอบด้วยวิจารณญาณตนเอง

### 3. Conflict Handling with Future I Ching / Chakra Layers
- **หลักการ**: เมื่อมีเลเยอร์เพิ่มขึ้นในอนาคต (เช่น คัมภีร์อี้จิง หรือศาสตร์จักระกระตุ้นพลังชีวิต) ระบบ Composer จะถูกกำหนดความสำคัญดังนี้:
  1. `Today Timing Engine` (ตัวควบคุมขีดจำกัดพลังงานกายและสติ - สูงสุด)
  2. `Thai Astrology Layer` (ยามชั่วโมงการกระทำ - รองลงมา)
  3. `Chinese Metaphysics Layer` (ฤดูกาลและธาตุประจำวัน - ระดับกลาง)
  4. `Future Layers` (อี้จิง/จักระ - ตัวชี้วัดความคิดและคำถามนำทางจิตวิทยา - ล่างสุด)
- **การจัดการ**: สัญญาณจากเลเยอร์ล่างสุดจะไม่มีสิทธิ์ขัดเกลาหรือหักล้างสัญญาณเตือนความเหนื่อยล้าจากเลเยอร์ระดับสูงได้ แต่จะทำหน้าที่เพิ่มมิติมุมมองสะท้อนใจ (Reflection Context Cards) ย่อยในรูปแบบ Toggle-based ด้านล่างสุด

## Low-Burnout Priority Rules
* ห้ามใช้หลักความเชื่อทางโหราศาสตร์ใดๆ มายุยงให้ผู้ใช้ฝ่าฝืนขีดจำกัดความเหนื่อยล้าทางร่างกาย
* หากระบบตรวจพบสถานะเหนื่อยล้าสะสม (`fatigue` / `burnout` ในประวัติสะสม) ข้อความแนะนำของธาตุจีนต้องเปลี่ยนไปใช้กลยุทธ์เสริมสร้างความชดเชยของธาตุเกื้อหนุนทันที (เช่น เสริมธาตุน้ำเพื่อความผ่อนคลาย หรือธาตุดินเพื่อความสงบมั่นคง)

## Architectural Implications

- **Data Model**: ข้อมูลวิเคราะห์ยามจีนจะถูกบันทึกเป็นฟิลด์เสริมประเภท Optional ภายใต้ `timingContext.chineseElementId` หรือ `timingContext.chineseSeason` ในรายการประวัติสะสม `ReflectionHistoryItem` โดยไม่มีการเพิ่มตารางหรือแก้ไข schema เดิมที่มีอยู่
- **Storage**: จัดเก็บข้อมูลบน `LocalStorage` หรือตัวเก็บประจุหลักในรูปของ String IDs สั้นๆ เพื่อป้องกันผลกระทบต่อประสิทธิภาพการเข้าถึงเนื้อความส่วนตัวของผู้ใช้
- **Export / Import**: ข้อมูลฟิลด์เสริมของจีนจะถูกแปลงลงใน JSON Backup โดยใช้โหมดกระจายข้อมูลแบบปลอดภัยย้อนหลัง (v3 Backward Compatible Data Export) หากตัวอ่านสำรองแบบเก่าไม่มีฟิลด์นี้ จะเพิกเฉยได้โดยไม่ทำให้ไฟล์พัง
- **UI Implications**: แสดงผลในลักษณะ Optional Context Card ที่ปิดตัวเรนเดอร์ได้ บนหน้าหลัก Today Panel และขยายปุ่มเปิดตั้งค่าในหน้า Preview Data Tools
