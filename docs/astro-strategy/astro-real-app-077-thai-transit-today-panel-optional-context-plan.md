# ASTRO-REAL-APP-DEV-077 — Thai Transit Today Panel Optional Context Plan

## 1. Goal
วางแผนการผสานผลลัพธ์ดวงจรไทย (**Thai Transit Adapter Output v0.1**) เข้าไปแสดงบนแผงควบคุมวันนี้ (**AstroTodayPanel**) ในลักษณะการ์ดเสริมย่อยพับปิดได้เป็นค่าเริ่มต้น (Optional Collapsible Context Card) โดยมีหน้าที่เตือนสติการบริหารเวลา สมาธิ และจัดสรรความเสี่ยงของสมอง โดยจะยังไม่แก้ไขซอร์สโค้ดในรันไทม์และไม่มีการเชื่อมต่อ UI จริงในขั้นตอนนี้

---

## 2. UI Placement (ตำแหน่งจัดวางบนหน้าจอ)
* **ตำแหน่งหลัก**: การ์ดข้อมูลดวงจรไทยจะจัดวางอยู่ภายใต้ Daily Brief / Today Timing Main Recommendation เพื่อให้ลำดับความสำคัญสอดคล้องตามเกณฑ์สายตา
* **การเรียงลำดับการ์ดเสริม**:
  - ลำดับที่ 1: กล่องข้อมูลยามไทยเดิม (Thai Timing Context)
  - ลำดับที่ 2: กล่องข้อมูลธาตุและฤดูกาลจีน (Chinese Metaphysics Context)
  - ลำดับที่ 3: กล่องจังหวะดวงจรไทยวันนี้ (Thai Transit Strategy Context - ใหม่)
  - ลำดับที่ 4: ข้อมูล Metadata เอนจิ้น และ Disclaimers หลักล่างสุด
* **สเตตัสเริ่มต้น**: ปิดพับตัวรายละเอียดไว้เป็นค่าเริ่มต้น (Default Collapsed) เพื่อป้องกันอาการสายตาลายและรกจอ (UI Clutter)

---

## 3. Card Content Structure (โครงสร้างข้อมูลเนื้อหาของการ์ด)
การ์ดจะจำกัดการแสดงผลเฉพาะข้อมูลที่สำคัญเชิงปฏิบัติ โดยมีข้อมูลดังนี้:
* **ชื่อหัวข้อการ์ด**: `"🧭 จังหวะดวงจรไทยวันนี้ (Thai Transit Strategy)"`
* **ข้อมูลโหมดเวลาจรประจำวัน (transitMode)**: แสดงสัญลักษณ์สีเพื่อชี้บ่งทิศทาง (Focus/Stabilize/Pause)
* **ข้อมูลเรือนจรสำคัญ (activeTransitHouses)**: นำเสนอในรูปป้ายขนาดเล็ก (Badges) แบบอ่านง่าย
* **โหมดงานที่แนะนำพิเศษ (recommendedWorkModes)**: ลิสต์สั้น 2-3 จุด
* **โหมดงานที่ควรชะลอชั่วคราว (avoidOrDelayModes)**: ข้อพึงสังเกตสั้น ๆ
* **รหัสสัญญาณระมัดระวัง (decisionCautionSignals)**: ปรากฏเมื่อมีเกณฑ์ดาวเบียดบังลัคนา
* **รหัสสัญญาณพักฟื้นฟู (recoverySignals)**: ชี้แนะนำคลื่นเสียงจักระเมื่อล้าสะสม
* **บันทึกความมั่นใจของข้อมูล (confidenceNotes)**: แสดงประกอบองศาลัคนาเกิด
* **คำประกาศDisclaimerแบบสั้น**: ยึดโยงการตัดสินใจจริงของผู้ใช้

---

## 4. Display Hierarchy (ลำดับการประเมินทัศนวิสัย)
* **อันดับที่ 1 (สำคัญที่สุด)**: ตัวนำทางหลัก Today Engine ของระบบ (Today's Mode, Work Recommendation, Risk Prevention, Recovery)
* **อันดับที่ 2**: บันทึกอารมณ์ความรู้สึกสะท้อนคิดของผู้ใช้ (Fatigue Level / Low-burnout priority) มีอำนาจสูงสุดในการควบคุมและกำหนดตัวเลือกงาน โดยดวงดาวจรจะไม่มีสิทธิ์สั่งหรือบีบให้ผู้ใช้ทำงานหากบันทึกระบุว่าเหนื่อยล้าสะสมหนัก
* **อันดับที่ 3**: เลเยอร์ข้อมูลจรไทย เป็นเพียงข้อมูลแวดล้อมสนับสนุนเชิงกลยุทธ์ (Supporting Context)
* **อันดับที่ 4**: เลเยอร์ยามไทยดั้งเดิมและจีนเมตาฟิสิกส์

## 5. Props Interface Plan
แผนการขยายพร็อพส์อินเทอร์เฟซของ `AstroTodayPanelProps` ในอนาคต:

```typescript
export type AstroTodayPanelProps = {
  // ... Props เดิม
  
  /** ข้อมูลผลลัพธ์ดวงจรไทย v0.1 */
  readonly thaiTransitContext?: ThaiTransitStrategyOutput | null;
  /** ตัวแปรเปิด/ปิดทัศนวิสัยของศาสตร์เสริมดวงจรจร */
  readonly showThaiTransitContext?: boolean;
  /** กำหนดสเตตัสการปิด Accordion เริ่มต้น */
  readonly defaultThaiTransitCollapsed?: boolean;
  /** ฟังก์ชันสลับการปิดพับ */
  readonly onToggleThaiTransitContext?: (expanded: boolean) => void;
};
```

## 6. Parent Data Flow Plan
ในอนาคต หน้ารวมของบอร์ดหลัก `AstroRealAppPreview.tsx` จะดำเนินการดังนี้:
1. ประมวลผลลัพธ์ดวงจรผ่าน `buildThaiTransitStrategyOutput(input)` ภายหลัง client mount และ hydration เสร็จสมบูรณ์แล้วเท่านั้น (`isHydrated === true` ใน `useEffect`)
2. ดึงข้อมูล Birth Profile ของผู้ใช้ และคำนวณลัคนารับส่งค่าเป็นตัวนำเข้า
3. ตรวจเช็คประวัติสะท้อนคิดสะสม และสกัดหาตัวแปรความล้า (`fatigueLevel` / `energyLevel`) ส่งต่อให้ Adapter ตรวจจับ override
4. ข้อมูลผลลัพธ์จะถูกส่งลงเป็น Props สู่ `<AstroTodayPanel />` โดยจะไม่มีการบันทึกหรือเขียนข้อมูลจรลงสู่หน่วยความจำ LocalStorage

## 7. Hydration Safety
* **ห้ามคำนวณสดบน Server**: ป้องกันไม่ให้เกิดปัญหาหน้าจอกระพริบ (Hydration mismatches) โดยรันการประมาณการดาวจรบนหน่วยความจำเบราว์เซอร์ฝั่งไคลเอนต์เท่านั้น
* **ตัวแปรกันชนเวลา (Noon Guard)**: ยึดเวลาเที่ยงตรงกรณีผู้ใช้สลับเครื่องเดินทาง
* **ตัวตัดทอน (Fallback)**: แสดงค่าว่างหรือซ่อนการ์ดหากข้อมูล Birth Profile คลาดเคลื่อน

---

## 8. Copy Safety (ความปลอดภัยถ้อยคำภาษา)
* **ข้อห้ามเด็ดขาด**: ห้ามมิให้มีการสร้างหรือแสดงผลคำเตือนเรื่อง "เคราะห์", "ซวย", "อุบัติเหตุร้ายแรง", "ความตาย", "เงินหมดตัว", "ความรักล้มเหลว"
* **การใช้ภาษาประกอบสะท้อนสติ**: ใช้คำแนะนำเชิงสร้างสรรค์ เช่น "ควรชะลอการตัดสินใจ", "เหมาะแก่การดีบักระบบ", "สลับพักสายตาด่วนเมื่อรู้สึกตึงเครียด"

---

## 9. UI Density Control (การควบคุมความหนาแน่นจอภาพ)
* **กลยุทธ์กะทัดรัด (Compact Design)**: ใช้ Accordion สำหรับขยายความเห็นเชิงลึก ข้อมูลเรือนจรตกเป็นรหัสภาษาอังกฤษแทนบทความยาว
* **สัญญะข้อสรุป**: แสดงผลสรุปภาพรวม 1-2 ประโยคสั้นๆ เพื่อให้สายตาผู้ใช้รู้สึกสบาย ไม่รกเรื้อและลดภาระสมองของผู้ใช้ (Cognitive load)

---

## 10. Non-scope (สิ่งที่ต้องไม่ทำในรอบนี้)
* **ห้ามดัดแปลงแก้ไขโค้ดใดๆ** ในไฟล์ `AstroTodayPanel.tsx` และ `AstroRealAppPreview.tsx` (รอบเอกสารเท่านั้น)
* **ห้ามเพิ่มศาสตร์อื่นนอกจาก 4 เลเยอร์หลัก**
