# ASTRO-REAL-APP-DEV-069 — Natal + Transit Strategy Core Architecture

## 1. Product Definition
Astro Strategy Lab เป็นระบบวิเคราะห์จังหวะชีวิตเชิงกลยุทธ์ตามบุคคลจริง โดยใช้ศาสตร์ดาราศาสตร์และโหราศาสตร์โบราณเป็นรากฐานของกลไกคำนวณ ความแตกต่างของผลิตภัณฑ์นี้จากระบบดูดวงทั่วไปคือ **"ไม่ทำนายโชคชะตาเชิงลี้ลับ ไม่ฟันธงเคราะห์กรรม และไม่มีการสยบยอมต่อโชคชะตา"** แต่ทำหน้าที่เป็นระบบปฏิบัติการช่วยประคองสมาธิและการวางแผนงาน (Personal Work & Life Strategy Operating System) ที่นำตำแหน่งและสัญญะของดวงดาวประจำตัวมาแปลเป็นตัวเลือกในการตัดสินใจ การเลือกจังหวะลุยงาน การคัดกรองความเสี่ยงทางพลังงานจิตใจ และการกำหนดจุดพักฟื้นตัวเพื่อป้องกันภาวะหมดไฟ (Burnout Prevention)

## 2. Core Product Formula
ระบบขับเคลื่อนการสร้างกลยุทธ์ส่วนบุคคลด้วยความสัมพันธ์แกนกลางหลัก:

$$\text{Birth Pattern (พื้นดวง)} + \text{Transit Timing (จังหวะจร)} + \text{Reflection History (ประวัติสะท้อนคิด)} \rightarrow \text{Personal Strategy (กลยุทธ์เฉพาะบุคคล)}$$

หรือเขียนเป็นความสัมพันธ์ภาษาไทย:
$$\text{พื้นดวงกำเนิด} + \text{จังหวะพลังงานจร} + \text{ประวัติบันทึกสะท้อนคิด} \rightarrow \text{กลยุทธ์การใช้ชีวิตและการทำงานเฉพาะบุคคล}$$

* **Birth Pattern (พื้นดวงกำเนิด)**: ศักยภาพพื้นฐาน ธาตุเด่น/พร่อง รูปแบบพฤติกรรม และจุดเปราะบางตามช่วงนาทีที่เกิด
* **Transit Timing (จังหวะจร)**: คลื่นพลังงานและตำแหน่งดาวบนท้องฟ้า ณ ช่วงเวลาปัจจุบันที่โคจรเข้ามาทำมุมกระทบหรือกระตุ้นจุดพิกัดในดวงกำเนิด
* **Reflection History (ประวัติสะท้อนคิด)**: บันทึกอารมณ์และระดับความล้าจริงของผู้ใช้ (Real-world feedback loop) เพื่อปรับค่าความสอดคล้อง (Calibration)

## 3. Core Astrology Scope
* **โหราศาสตร์ไทยเป็นแกนหลักหลัก (Primary Core)**: ระบบคำนวณและดึงพิกัดตำแหน่งดวงดาวทางดาราศาสตร์จะยึดตามหลักโหราศาสตร์ไทย (เช่น การคำนวณแบบปฏิทินสุริยยาตร์ หรือการแบ่งยามตามหลักภูมิปัญญาไทย)
* **ดวงกำเนิด (Natal Chart)**: เป็นฐานข้อมูลพื้นฐานของดวงชะตาส่วนบุคคล (Personal Baseline Structure)
* **ดวงจร / วันจร / ช่วงจร (Transit Timing)**: เป็นตำแหน่งการโคจรของดวงดาวจริงประจำวันหรือรอบคาบเวลาที่เคลื่อนเข้ามากระตุ้นจุดต่าง ๆ ในดวงกำเนิด
* **ศาสตร์เสริมทางเลือก (Optional Supporting Layers)**:
  - เมตาฟิสิกส์จีน (Chinese Metaphysics/BaZi)
  - ปรัชญาคัมภีร์อี้จิง (I Ching Decision Support)
  - ระบบพลังงานจักระและสมาธิ (Chakra/Meditation Support)
  ศาสตร์เสริมเหล่านี้จะทำหน้าที่เป็นข้อมูลแวดล้อมสนับสนุน (Secondary contexts) เพื่อตรวจสอบสมดุลรอบชีวิตในจุดที่ศาสตร์หลักระบุ ไม่ใช่แกนประมวลผลดั้งเดิมของแอป และผู้ใช้สามารถเปิด/ปิดได้ตามต้องการ

## 4. Natal Data Model Concept (ข้อมูลดวงกำเนิด)
แนวคิดโครงสร้างข้อมูลสำหรับดวงกำเนิดในอนาคต (Conceptual data structure, ยังไม่พึ่งพารันไทม์คำนวณใน v0.1):

```typescript
export interface NatalDataModel {
  /** ข้อมูลประวัติการเกิดพื้นฐาน */
  readonly birthProfile: {
    readonly birthDate: string; // YYYY-MM-DD
    readonly birthTime: string; // HH:MM
    readonly birthPlace: string;
    readonly birthWeekday: string;
  };
  /** จุดพิกัดลัคนา (Ascendant) */
  readonly ascendantZodiac: string; // เช่น เมษ, พฤษภ
  /** ราศีเกิดของดวงอาทิตย์ หรือดวงจันทร์ */
  readonly solarZodiac: string;
  /** พิกัดตำแหน่งดาวเคราะห์กำเนิดทั้ง 10 ดวงในแต่ละเรือน */
  readonly natalPlanets: {
    readonly planetId: number; // 0-9 (อาทิตย์ - พุธ - พฤหัส - ศุกร์ - เสาร์ - ราหู - เกตุ - มฤตยู)
    readonly zodiacSign: string;
    readonly houseId: string; // เรือนชะตาที่ดาวสถิต
    readonly degree: number;
  }[];
  /** เรือนชะตาทั้ง 12 (Houses) */
  readonly houses: {
    readonly houseName: string; // ตนุ, กฎุมพะ, สหัชชะ...
    readonly lordPlanetId: number; // ดาวเจ้าเรือน
  }[];
  /** สัดส่วนธาตุเกิดเด่น/พร่อง */
  readonly elementBalances: {
    readonly earth: number; // 0.0 - 1.0
    readonly water: number;
    readonly wind: number;
    readonly fire: number;
  };
  /** พิกัดทักษาปกรณ์กำเนิด (บริวาร อายุ เดช ศรี มูละ อุตสาหะ มนตรี กาลกิณี) */
  readonly thaksaSystem: {
    readonly sriPlanetId: number;
    readonly kaniPlanetId: number;
    readonly agePlanetId: number;
  };
  /** สรุปจุดแข็ง/จุดเปราะบางเชิงพฤติกรรมการทำงาน */
  readonly workBehaviorProfile: {
    readonly strengths: string[];
    readonly vulnerabilities: string[]; // เช่น สภาวะเร่งงานเกินพอดี, ลังเลในวันอาทิตย์จร
  };
}
```

## 5. Transit Data Model Concept (ข้อมูลดวงจร)
แนวคิดโครงสร้างสำหรับระบุตำแหน่งและการเคลื่อนที่ของดวงดาวประจำวันจร (ยังไม่รวมกลไกรันไทม์ใน v0.1):

```typescript
export interface TransitDataModel {
  /** วันเวลาที่ตรวจสอบข้อมูลจร */
  readonly targetDate: string; // YYYY-MM-DD
  readonly targetTime: string;
  /** พิกัดดาวจรในปัจจุบัน */
  readonly transitPlanets: {
    readonly planetId: number;
    readonly currentZodiac: string;
    readonly degree: number;
  }[];
  /** ดาวจรที่ทับหรือทำมุมสัมพันธ์ (Aspects) ชี้วัดกับดาวกำเนิด */
  readonly planetaryAspects: {
    readonly transitPlanetId: number;
    readonly natalPlanetId: number;
    readonly aspectType: "conjunction" | "opposition" | "trine" | "square";
    readonly severity: number; // 0.0 - 1.0 (ระดับความแรงของมุม)
  }[];
  /** เรือนชะตาในดวงกำเนิดที่กำลังถูกดาวจรสำคัญเคลื่อนเข้ามากระตุ้น */
  readonly activatedHouses: {
    readonly houseName: string; // เช่น กัมมะ (การงาน), ปัตนิ (คู่เจรจา)
    readonly durationDays: number; // ระยะเวลาส่งอิทธิพลจรโดยประมาณ
  }[];
  /** สัญญาณบ่งบอกทิศทางกลยุทธ์ */
  readonly strategySignals: {
    readonly signalType: "focus" | "review" | "delay" | "communicate" | "rest" | "decide" | "avoid-overload";
    readonly explanation: string;
  }[];
}
```

## 6. Strategy Interpreter Output Model
ผลลัพธ์ข้อมูลคำแนะนำจากการวิเคราะห์ผสาน (Interpreter Logic) จะต้องถูกจัดกลุ่มตามความเหมาะสมในการทำกิจกรรมส่วนบุคคล โดยหลีกเลี่ยงความเชื่อไสยศาสตร์อย่างสิ้นเชิง:

* **จังหวะหลักของช่วงนี้ (Primary Rhythm)**: โหมดพลังงานหลัก (เช่น โฟกัสเต็มกำลัง, ตรวจตรา, หรือถอยฟื้นฟู)
* **งานที่ควรทำ (Work to Focus)**: ประเภทกิจกรรมสร้างสรรค์หรือเขียนโค้ดที่เข้ากันได้ดีกับทิศทางลมฟ้าและตำแหน่งดาวจร
* **งานที่ควรชะลอ (Tasks to Postpone)**: กิจกรรมที่ตำแหน่งดาวจำกัดกำลังโฟกัสอยู่ ควรปรับเวลาออกไป
* **เรื่องที่ควรตรวจซ้ำ (Areas to Double-Check)**: ป้องกันความผิดพลาดเชิงคุณภาพ (เช่น ดาวพุธโคจรวิปริตเตือนให้ตรวจเอกสารทางกฎหมายและสเปกโค้ดซ้ำ)
* **ความเสี่ยงเชิงงาน / สมาธิ / พลังงาน (Focus & Energy Risks)**: แจ้งเตือนสภาวะคิดวนหรือความกดดันภายในจิตใจ
* **วิธีเดินงาน (Strategic Execution Guide)**: ข้อเสนอแนะแนวทางปฏิบัติงานจริง เช่น แนะนำให้จัดระเบียบไฟล์ก่อนขึ้นโปรเจกต์
* **คำถามสะท้อนคิด (Reflection Prompts)**: คำถามช่วยผู้ใช้ทบทวนพฤติกรรมการจัดสรรเวลาของตนเอง
* **ข้อควรพักหรือฟื้นฟู (Rest & Recovery Anchors)**: กิจกรรมผ่อนคลายความเหนื่อยล้าทางสมอง

*ข้อห้ามเด็ดขาด*: ห้ามใส่ข้อมูลส่งกลับที่เป็นเรื่องของลาภลอย โชคลี้ลับ การสูญเสียทรัพย์สิน การประสบอุบัติเหตุรุนแรง ความตาย หรือเหตุร้ายทางกายภาพ

## 7. UI Product Modules
โครงสร้างหน้าต่างแสดงผลบนเบราว์เซอร์ (UI Modules) ที่ล็อกแนวคิดไว้ประกอบด้วย:

1. **Birth Profile**: หน้าจอจัดการตั้งค่าวันเกิด เวลาเกิด และพิกัดสถานที่เกิดเพื่อสร้างโปรไฟล์ดวงชะตาส่วนบุคคล
2. **Today Strategy**: หน้าต่างหลักสรุปจังหวะของวันนี้พร้อมปฏิทินยาม และคำชี้แนะการจัดสรรพลังงานสมาธิ
3. **Weekly Strategy**: แดชบอร์ดสรุปทิศทางการบริหารเวลาในรอบสัปดาห์ (Weekly Block Planning)
4. **Monthly Strategy**: แนวทางการวิเคราะห์รอบเดือนสำหรับวางจุดสะท้อนคิดระยะกลาง
5. **Natal Strategy Profile**: หน้าแสดงสรุปรูปแบบดวงชะตากำเนิดเชิงจิตวิทยา เช่น จุดแข็ง จุดเปราะบาง และธาตุสมดุลส่วนตัว
6. **Transit Strategy View / Calendar**: ปฏิทินแสดงการทำมุมจรของดาวดวงสำคัญประจำวัน เพื่อช่วยวางแผนการนัดหมายเจรจาล่วงหน้า
7. **Reflection History**: ระบบประเมินและทบทวนความล้าจริงที่บันทึกไว้ในอดีต (Feedback Loop)
8. **Planning Notes**: กล่องจดบันทึกเป้าหมายการทำงานขนาดเล็กและการจัดสรรวินัย
9. **Export / Import / Backup**: ส่วนนำเข้าและสำรองข้อมูลในเครื่องแบบ Local-first ปลอดภัย
10. **Advanced Layer Settings**: สวิตช์ปิด/เปิดสำหรับกำหนดทัศนวิสัยและความหนาแน่นของการเรนเดอร์ศาสตร์เสริม (Chinese, I Ching, Chakra)

## 8. Copy Safety & Ethics
เพื่อป้องกันอาการกลัวชะตากรรม (Fate Anxiety) และรักษาระดับความมีสติปัญญาของผู้ใช้ ระบบจะทำการบล็อกถ้อยคำและน้ำเสียงต้องห้ามทั้งหมด:

### คำ/ประโยคต้องห้าม (Forbidden Copy Patterns)
* ห้ามใช้ประโยคเชิงกำหนดอนาคตล่วงหน้าว่าจะเกิดแน่นอน เช่น *"จะเกิดปัญหาในการทำงาน"*, *"จะสูญเสียของรัก"*, *"จะเจ็บไข้ได้ป่วยร้ายแรง"*
* ห้ามสร้างความตระหนกกลัว หรือใช้ความโชคร้ายมาเป็นตัวเร่งการกระทำ
* ห้ามให้คำสั่งที่ล่วงเกินสิทธิการตัดสินใจของผู้ใช้ เช่น *"ห้ามเซ็นสัญญาวันนี้"*, *"ให้ยกเลิกนัดทันที"*

### ชุดคำศัพท์ที่ให้ใช้อ้างอิงทดแทน (Approved Vocabulary Patterns)
* มีแนวโน้มให้เฝ้าสังเกตและระมัดระวังเป็นพิเศษในจุด...
* จังหวะรอบวันช่วงนี้เหมาะอย่างยิ่งสำหรับการจัดระเบียบและชะลอการขยายขอบเขตงาน
* แนะนำให้เพิ่มความละเอียดรอบคอบในการตรวจสอบข้อตกลงหรือสเปกการเขียนโปรแกรม
* ควรมุ่งเน้นการสะสางงานคงค้างเดิมและลดความเร่งรีบในการตัดสินใจประเด็นสำคัญ
* ควรจัดวางหน้าต่างเวลาสั้น ๆ เพื่อพักผ่อนสายตาและพักฟื้นฟูจิตใจจากการทำงานหน้าจอ

## 9. What We Will Not Build Yet
* **ไม่ทำ MyHora Clone**: จะไม่มีการเรนเดอร์ระบบแสดงผลตารางตัวเลขดาราศาสตร์ดวงแก้วซับซ้อนที่ดูยากสำหรับคนทั่วไป หรือการผูกดวงแบบดั่งเดิมสำหรับรับดูดวงทั่วไป
* **ไม่ทำดวงไทยเต็มระบบในทันที**: จะยังไม่พัฒนาปฏิทินตำแหน่งดวงดาวจรทศนิยม 4 ตำแหน่งหรือการทำมุมซับซ้อนในระบบจนกว่า Adapter v0.1 จะได้ตรวจสอบคุณภาพความถูกต้อง
* **ไม่ทำ BaZi เต็มรูปแบบ**: จะไม่มีการพยากรณ์ปฏิทินห้าธาตุจีนสิบบังคับในระบบ
* **ไม่เพิ่มศาสตร์ลี้ลับใหม่**: จะไม่ผสมผสานศาสตร์โบราณอื่น ๆ เพิ่มเติมนอกเหนือจากขอบเขต 4 เลเยอร์ที่สเปกไว้ใน MVP-v4
* **ไม่เพิ่มกล่อง Today Panel จนรก**: จะควบคุมเนื้อหา Today Panel ให้อ่านจบภายในหน้าจอเดียว (Default Collapsed สำหรับการ์ดเสริม)
* **ไม่เขียน Advanced output ลง Reflection History**: จนกว่า Schema การเชื่อมโยงความปลอดภัยข้อมูลจะได้รับการรับรองอย่างชัดเจนในเฟสถัดไป
