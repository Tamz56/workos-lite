# ASTRO-REAL-APP-DEV-072 — Thai Transit Timing Calculation Plan

## 1. Goal
วางแผนการคำนวณและประมวลผลดวงจรไทยขั้นต้น (Thai Transit Timing Calculation Plan v0.1) สำหรับแอปพลิเคชัน Astro Strategy Lab ของระบบ ArborDesk โดยมีเป้าหมายเพื่อตรวจหาพิกัดจังหวะการโคจรของดาวเคราะห์จร ณ วันเวลาเป้าหมายที่ผู้ใช้ต้องการวิเคราะห์ เปรียบเทียบกับพิกัดดวงชะตากำเนิด (Natal Chart จาก DEV-071) แล้วนำมาสกัดแปลผลเป็นสัญญาณกลยุทธ์การจัดลำดับการทำงานและการวางกรอบตัดสินใจประจำวัน โดยไม่มีการนำเสนอข้อมูลทำนายเรื่องราวเคราะห์กรรมหรือครอบงำความเป็นอิสระของผู้ใช้

---

## 2. Input Requirements
ข้อมูลนำเข้าที่จำเป็นต้องใช้ในการรันประมวลผลระบบดวงจร:

* **natalChartCalculationOutput**: ผลลัพธ์ที่ประมวลผลจากโครงสร้างดวงกำเนิดของบุคคลจริง (ลัคนา, ตำแหน่งดาวเคราะห์กำเนิด, ราศี, และเรือนชะตา)
* **targetDate**: วันที่ต้องการตรวจสอบยามและดวงจรปัจจุบัน (เช่น `2026-06-14`)
* **targetTime**: ช่วงเวลาตรวจการทำมุมสัมพันธ์ (เช่น `11:45`)
* **targetTimezone**: เขตเวลาของเครื่องเป้าหมาย (เช่น `"Asia/Bangkok"`)
* **targetLocation (Optional)**: พิกัดสถานที่ทำภารกิจเพื่อคำนวณยามอุบากองพื้นที่
* **transitPlanetPositions (Optional / Approximated)**: ตำแหน่งพิกัดเฉลี่ยของดาวเคราะห์จรทางดาราศาสตร์
* **userCurrentFocus (Optional)**: หัวข้อการจดจ่อในใจที่ผู้ใช้ระบุเลือกในขณะนั้น (เช่น การเขียนโปรแกรม, ประชุมงาน, หรือการหยุดพักฟื้นฟู)
* **recentReflectionContext (Optional)**: ข้อมูลสรุปความล้าสะสมจากประวัติสะท้อนคิดในช่วง 3-7 วันที่ผ่านมา (Feedback Loop)
* **dataConfidence notes**: บันทึกคำอธิบายหากข้อมูลดวงจรมีการประมาณค่าเนื่องจากพิกัดเวลาขาดหาย

## 3. Transit Calculation Scope v0.1
ขอบเขตตรรกะระบบคำนวณดวงจรไทยเวอร์ชันเริ่มต้น (v0.1):

* **การประมาณการพิกัดตำแหน่งดาวจร**: ดึงค่าตำแหน่งดาวเคราะห์ทั้ง 10 ดวงจากตารางข้อมูลเฉลี่ยประจำสัปดาห์/ประจำเดือนใน Client Dictionary
* **ราศีของดาวจร (Transit Sign)**: ระบุราศีปัจจุบันของดาวจรแต่ละดวง (ดาว 1 ถึงดาว 0)
* **เรือนชะตารองรับดาวจร (Transit Houses)**: ประเมินว่าดาวจรแต่ละดวงเคลื่อนเข้าสถิตในราศีที่เป็นเรือนชะตาที่เท่าใดเมื่อเทียบอ้างอิงจากราศีลัคนาเกิดของผู้ใช้ (เช่น ลัคนาพฤษภ ดาวพฤหัสจรเข้าเมถุน ซึ่งนับเป็นเรือนกฎุมพะ)
* **การวิเคราะห์ดาวจรสัมพันธ์กับเรือนงานหลัก**: มุ่งเน้นการตรวจจับดาวจรในเรือนที่มีผลต่อการวางกลยุทธ์ ได้แก่ **ตนุ** (พลังชีวิต), **กัมมะ** (การลงมือทำ), **ลาภะ** (ผลสำเร็จ), **อริ** (การดีบัก/อุปสรรค), **วินาศ** (งานเบื้องหลัง), และ **ปัตนิ** (การเจรจา/คู่ร่วมงาน)
* **ธาตุจรรายวันเทียบธาตุเด่นดวงเกิด (Element Alignment)**: คำนวณสมดุลความสัมพันธ์ระหว่างธาตุของวันจรกับสัดส่วนสี่ธาตุเกิดของผู้ใช้เพื่อหาแนวทางลดความล้า
* **คะแนนชี้วัดแรงกดดันและแรงส่งเสริม (Pressure & Support Score)**: ประมาณการระดับภาระสมองเชิงสถิติ (เช่น มีดาวบาปเคราะห์จำนวนมากกุมลัคนาจร จะได้คะแนนฝั่งแรงกดดันสูงขึ้น)
* **รหัสสัญญาณเวลาทำงานรายวัน (Daily Work Signals)**: สกัดรหัสเทคนิคประจำคาบเวลาของยามอุบากองและวันเกิดรอบสัปดาห์
* **รหัสสัญญาณระมัดระวังและพักผ่อน (Caution & Recovery Signals)**: ตรวจจับรอบดาวเสาร์จรหรือดาวอังคารจรทำมุมเบียดบังดาวจันทร์เกิด เพื่อสกัดรหัสพักฟื้นฟู

## 4. Transit Non-scope
* **ไม่ใช้ระบบคำนวณสมผุสดาวเคราะห์องศาละเอียดจาก API ภายนอก**: ระบบจะยังไม่ใช้การประมวลผลองศาลิปดาที่ซับซ้อนเกินกว่าโครงสร้าง Rule-based เฉลี่ย
* **ไม่คำนวณการทำมุมสัมพันธ์ทุกคู่ดาวเคราะห์**: จะไม่มีการสแกนหามุมเงื้อมดาวจรทำมุม 135 องศา หรือ 150 องศา ครบทุกจุดพิกัดในดวงชะตา
* **ไม่วาดรูปกราฟดวงจักรจรแบบวงกลม**: หลีกเลี่ยงการเรนเดอร์ UI รูปดวงดาวซ้อนแผ่นชะตาแบบดูดวงเชิงพาณิชย์
* **ไม่พยากรณ์ความโชคดีโชคร้ายเฉพาะเจาะจง**: แบนการให้ข้อความทำนายว่าจะเกิดอุบัติเหตุ, การเสียเงินทอง, การถูกหักหลัง หรือการล้มละลาย
* **ไม่จัดหาฤกษ์มงคลแบบลัทธิความเชื่อ**: จะไม่มีการวิเคราะห์จัดทำยามแต่งงาน ยามออกรถ หรือยามขึ้นบ้านใหม่เพื่อพิธีกรรม
* **ไม่บันทึกข้อมูลดวงจรแบบสะสมลงใน Storage**: ป้องกันปัญหาประวัติข้อมูลมีขนาดบวม

## 5. Transit Signal Categories
รหัสสัญญาณผลลัพธ์ดวงจรจะถูกแบ่งออกเป็น 8 หมวดหมู่หลักสำหรับการส่งต่อไปยัง Interpreter:

1. **Work Activation Signal**: สัญญาณเริ่มต้นลงมือลุยงาน โครงการใหม่ หรือการนำเสนองาน
2. **Deep Work Signal**: สัญญาณส่งเสริมการใช้สมาธิจดจ่อสูง เขียนรหัสหรือวิจัยเชิงลึก
3. **Review / QA Signal**: สัญญาณเตือนให้เข้าสู่โหมดวิเคราะห์ ตรวจหาสเปกและบั๊ก
4. **Communication Signal**: จังหวะที่ส่งเสริมการประสานงานทางวาจา อักษร หรือการนัดเจรจา
5. **Delay / Recheck Signal**: จังหวะที่เหมาะสำหรับการชะลอ และตรวจเช็คข้อมูลซ้ำเพื่อป้องกันข้อบกพร่อง
6. **Recovery / Rest Signal**: จังหวะเตือนความล้าสะสม แนะนำสมอเสียงหรือการพักสายตา
7. **Conflict / Low-burnout Signal**: จังหวะเตือนใจให้ลดการสลับสับเปลี่ยนหน้าที่การงานเพื่อป้องกันความตึงสมอง
8. **Planning / Strategy Signal**: จังหวะดีในการวางโครงสร้าง สรุปไดอะแกรม หรือจัดการฐานข้อมูลเก่า

## 6. Output Contract Concept
โครงสร้างข้อมูลส่งกลับที่เป็นมาตรฐานของระบบดวงจรไทย v0.1:

```typescript
export interface ThaiTransitCalculationOutput {
  /** วันที่ทำการคำนวณจร */
  readonly transitDate: string;
  /** โหมดพลังงานจรของวันนี้ */
  readonly transitMode: "Focus" | "Stabilize" | "Pause";
  /** รายชื่อเรือนชะตาที่มีดาวจรหลักกุมอยู่ */
  readonly activeTransitHouses: string[];
  /** รายละเอียดสรุปดาวจรแต่ละดวง */
  readonly transitPlanetSummary: {
    readonly planetId: number;
    readonly currentZodiac: string;
    readonly isRetrograde: boolean;
  }[];
  /** อิทธิพลของดาวจรที่เข้ามากระตุ้นเรือนชะตากำเนิด */
  readonly natalHouseImpacts: {
    readonly houseName: string;
    readonly impactLevel: "high_support" | "high_pressure" | "neutral";
    readonly durationDays: number;
  }[];
  /** ความสอดคล้องธาตุวันจรกับธาตุเกิด */
  readonly elementRelationship: {
    readonly compatibilityType: "supporting" | "neutral" | "clashing";
    readonly elementPairAdvice: string;
  };
  /** รหัสสัญญาณย่อยความเหมาะสมในการทำงาน */
  readonly workTimingSignals: string[];
  /** รหัสสัญญาณเฝ้าระวังสมาธิและการตัดสินใจ */
  readonly decisionCautionSignals: string[];
  /** รหัสสัญญาณเสนอแนะการพักฟื้นตัว */
  readonly recoverySignals: string[];
  /** โหมดงานที่แนะนำเป็นพิเศษวันนี้ */
  readonly recommendedWorkModes: string[];
  /** โหมดงานที่ควรหลีกเลี่ยงหรือเลื่อนออกไปชั่วคราว */
  readonly avoidOrDelayModes: string[];
  /** บันทึกคำอธิบายความแม่นยำทางดาราศาสตร์ */
  readonly confidenceNotes: string;
  /** คำเตือนความปลอดภัยตามมาตรฐานจริยธรรม */
  readonly safetyDisclaimer: string;
}
```

## 7. Strategy Mapping Rules (หลักเกณฑ์การสกัดเป็นแผนเชิงกลยุทธ์)
 Interpreter จะนำเอาผลลัพธ์เชิงตัวแปรจากลอจิกการคำนวณมาจับคู่แปลงความหมายตามกฎเกณฑ์ดังนี้:

* **ดาวจรเข้าเรือนกัมมะ (งานสำคัญ)**:
  - หากเป็นกลุ่มดาวศุภเคราะห์ (พฤหัส(5), พุธ(4)) -> แปลงเป็นกลยุทธ์ **"ริเริ่มขยายแผน โครงร่าง และเจรจานัดหมายใหญ่"**
  - หากเป็นกลุ่มดาวบาปเคราะห์ (เสาร์(7), อังคาร(3)) -> แปลงเป็นกลยุทธ์ **"เน้นสะสางภารกิจเดิมที่เป็นภาระสะสม ลดความเร่งร้อนตึงเครียด"**
* **ดาวจรเข้าเรือนอริ (อุปสรรค)**:
  - แปลงเป็นกลยุทธ์ **"สัปดาห์แห่งการเคลียร์บั๊ก ดีบักระบบ และทบทวนความถูกต้องของขั้นตอนการรันโปรแกรม"**
* **ดาวจรเข้าเรือนลาภะ (ผลสำเร็จ)**:
  - แปลงเป็นกลยุทธ์ **"จังหวะที่ดีในการสรุปเป้าหมาย ปิด Checkpoint รวบยอด หรือส่งมอบบทความฉบับสมบูรณ์"**
* **ดาวจรเข้าเรือนวินาศ (เบื้องหลัง)**:
  - แปลงเป็นกลยุทธ์ **"เหมาะสำหรับงานวิจัยเชิงลึก รวบรวมเอกสารคู่มือ หรือการพักเตรียมการในมุมสงบ"**
* **ดาวจรเข้าเรือนปัตนิ (ผู้คน/คู่ร่วมงาน)**:
  - แปลงเป็นกลยุทธ์ **"จัดจังหวะสำหรับการประชุมทีม รับคำชี้แนะ (Feedback) หรือทำความเข้าใจร่วมกันในทีมงาน"**
* **กรณีสัญญาณขัดแย้งข้ามศาสตร์**:
  - หากมีสัญญาณกดดันสูงจากดาวเสาร์หรืออังคารเบียดบังจุดเกิด แต่ยามย่อยของวันเป็นยามปลอดโปร่ง -> ระบบจะยึดถือเอาหลัก **"Low-burnout priority"** แนะนำให้ผู้ใช้ประคองโฟกัส และเลือกทำเฉพาะภารกิจเบา ๆ ในคาบเวลาปลอดโปร่ง แทนการโหมลุยงานจนล้า

## 8. Relationship with Natal Chart (ความสัมพันธ์กับดวงกำเนิดและบันทึกสะท้อนคิด)
การสังเคราะห์ข้อมูลต้องผสมผสานสามเสาหลักเข้าด้วยกันโดยไม่ละเมิดความเป็นจริงของผู้ใช้:
1. **Natal Chart (ดวงกำเนิด)**: คือพิกัดสัญญะแม่แบบคงที่ของตัวบุคคล ชี้วัดจุดแข็งและธาตุเด่นติดตัว
2. **Transit Timing (ดวงจร)**: คือจังหวะเวลาและการเปรียบเปรยเหมือนสภาพฟ้าอากาศภายนอกที่เกิดขึ้นชั่วครั้งชั่วคราว
3. **Reflection History (ประวัติสะท้อนคิด)**: คือข้อมูลการจดจ่อและความล้าจริงจากโลกความเป็นจริงของผู้ใช้
* *กฎสำคัญ*: ข้อมูลดวงจรและยามอุบากองจะไม่ถูกนำมาเขียนทับหรือละเมิดความรู้สึกจริงทางอารมณ์ของผู้ใช้ หากผู้ใช้จดบันทึกว่า "ล้าสะสมมาก" ระบบจะปรับลดทอนคำแนะนำให้พักผ่อนทันที แม้ดวงจรจะบอกว่าเป็นวันปลอดโปร่งลุยงานได้ก็ตาม

## 9. Safety & Ethics Rules (ภาษาปลอดภัย)
* **แบนคำสั่งฟันธงเด็ดขาด**: ห้ามใช้คำศัพท์ที่ลดสิทธิ์ความเป็นอิสระของผู้ใช้ เช่น *"ห้ามส่งงานเด็ดขาด"*, *"จะล้มเหลวแน่นอน"*, *"เป็นวันดวงกาลกิณีมืดมน"*
* **ภาษาที่ผ่านเกณฑ์ทดแทนความกังวล**:
  - *"จังหวะเวลานี้เหมาะแก่การตรวจทานระบบซ้ำเพื่อความรอบคอบ"*
  - *"ควรชะลอการตัดสินใจขนาดใหญ่ที่ไม่มีข้อมูลสนับสนุนเพียงพอ"*
  - *"จังหวะรอบวันสนับสนุนการเคลียร์ภารกิจเบื้องหลังและปิดความเสี่ยง"*
  - *"ควรลดการปะทะความคิดชั่วคราวและเปลี่ยนบรรยากาศพักสายตา"*
  - *"ใช้เป็นข้อมูลช่วยเตือนสติในการสะท้อนคิดส่วนตน"*
