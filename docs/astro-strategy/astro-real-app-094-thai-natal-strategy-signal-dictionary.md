# ASTRO-REAL-APP-DEV-094 — Thai Natal Strategy Signal Dictionary

เอกสารฉบับนี้กำหนดรายละเอียดและพจนานุกรมข้อเสนอแนะเชิงระบบ (Strategic Signal Dictionary v0.1) สำหรับการถอดรหัสรหัสสัญญาณ (Signal IDs) ที่ได้จากการประเมินลัคนา ภพชะตา และดาวเคราะห์เกิดของระบบไทย เพื่อแสดงผลข้อแนะนำการบริหารตารางงานและการฟื้นพลังกายใจแก่ผู้ใช้

---

## 1. Goal (เป้าหมายของพจนานุกรมรหัสสัญญาณ)

* **สร้างพจนานุกรมคำแปลเชิงระบบ**: ทำแผนที่แมป (Mapping Map) สำหรับแปลงลัคนา ภพ 12 เรือน และตำแหน่งดาว ๐ ถึง ๙ เป็นข้อเสนอแนะเชิงพฤติกรรมการจัดการภารกิจ
* **ข้อกำหนดความปลอดภัยของภาษา**: ควบคุมประโยคและเทมเพลตคำบรรยายไม่ให้เข้าข่ายคำทำนายทายทักโชคชะตาอนาคตเชิงทำนาย
* **ขอบเขตการจำกัดเทิร์น**:
  - ยังไม่เขียนชุดโค้ดรันไทม์ (Runtime dictionary file) ในรอบนี้
  - ยังไม่ดัดแปลงฐานข้อมูล LocalStorage
  - ยังไม่ผูกกลไกส่วนประสานงานผู้ใช้ (UI Integration) จริง

---

## 2. Dictionary Design Principles (หลักการออกแบบพจนานุกรม)

เพื่อรักษาโครงสร้างซอฟต์แวร์ให้สะอาดและโปร่งใส (Anti-Bloat Architecture) การประยุกต์ใช้งานพจนานุกรมมีกรอบกฎดังนี้:
* **การบันทึกเอาต์พุตเฉพาะรหัส (Signal-Only Persistence)**: เอาต์พุตของสัญญาประมวลผลดวงเกิด (Natal output) จะบรรจุเฉพาะรหัสสั้น (IDs) ห้ามเขียนเนื้อหาบรรยายยาวลงในชุดข้อมูลผู้ใช้โดยตรง
* **การแยกแยะเนื้อหาแปลคำ (Separation of translation files)**: ข้อความคำอธิบายภาษาไทยจะสถิตอยู่ในคอมโพเนนต์พจนานุกรมสแตติก (Static Content Dictionary) เพื่อความรวดเร็วในการบำรุงรักษา
* **การแปรผันตามคะแนนความมั่นใจ (Confidence Score Sensitivity)**:
  - หากระดับความเชื่อมั่นลัคนากลาง (0.4 - 0.7): จะใช้เทมเพลตคำประคองสิทธิ์ (เช่น "มีแนวโน้มสะท้อนลักษณะ...")
  - หากระดับความเชื่อมั่นลัคนาต่ำ (ต่ำกว่า 0.4): ระบบจะระงับการแปลเนื้อหาระดับเรือนชะตารายบุคคล (Suppressed signals) และคืนเฉพาะสัญญะดาวรายดวงอิงระบบเฉลี่ย (Baseline approximate signals) เพื่อความปลอดภัยสูงสุด

## 3. Signal Categories (การแบ่งหมวดหมู่สัญญาณยุทธศาสตร์)

ระบบพจนานุกรมจะจำแนกรหัสสัญญาณออกเป็น 10 หมวดหมู่หลักตามลักษณะงานวางแผนชีวิตและการงานของผู้ใช้:
1. **Work Style (ลักษณะงานที่เหมาะ)**: แนวทางการลงมือสะสางภารกิจ
2. **Decision Style (รูปแบบการคิดและการตัดสินใจ)**: กระบวนการจัดสรรความคุ้มค่าก่อนอนุมัติแผนงาน
3. **Recovery Style (โหมดฟื้นพลังกายใจ)**: กิจกรรมคืนกำลังและคลายความเหนื่อยล้า
4. **Collaboration Style (การร่วมงานกับผู้อื่น)**: รูปแบบการเจรจาและการวางตัวกับบุคคลภายนอก
5. **Risk Pattern (จุดสังเกตความเสี่ยง)**: จุดบอดและข้อบกพร่องเชิงระบบงานสะสม
6. **Learning Pattern (วิธีการรับวิสัยทัศน์)**: รูปแบบการศึกษาและเรียนรู้องค์ความรู้ใหม่
7. **Execution Pattern (สปีดการส่งมอบงาน)**: สปีดความเร่งและจังหวะก้าวในการทำงาน
8. **Review / Delay Pattern (การตรวจทานและหน่วงงาน)**: การตรวจสอบข้อบัญญัติและเอกสารบัญชีภาษี
9. **Communication Pattern (ธรรมชาติการติดต่อสื่อสาร)**: รูปแบบและปริมาณการติดต่อภายนอก
10. **Backstage / Deep Work Pattern (งานเบื้องหลังสันโดษ)**: โหมดกักตัวเพื่อจดจ่อภารกิจเอกสารสำคัญ

## 4. Ascendant Signal IDs (กลุ่มรหัสอ้างอิงจากลัคนา)

ใช้เพื่อแปลผลลักษณะเบื้องต้นของบุคคล (Baseline Strategy) จากลัคนาที่ประมาณการได้:

* **หมวดเป้าหมายตัวตน (TH_NATAL_ASC_SELF_ORIENTATION)**:
  - `TH_NATAL_ASC_SELF_DRIVEN`: มุ่งเน้นการสร้างสรรค์ด้วยตนเองเป็นเป้าหมายหลัก
  - `TH_NATAL_ASC_SUPPORT_ORIENTED`: เหมาะกับการอำนวยประโยชน์เบื้องหลังให้แก่กลุ่มงาน
* **หมวดสปีดงาน (TH_NATAL_ASC_WORK_TEMPO)**:
  - `TH_NATAL_ASC_WORK_TEMPO_FAST`: ตอบสนองรวดเร็ว ชอบภารกิจเร่งด่วนระยะสั้น
  - `TH_NATAL_ASC_WORK_TEMPO_STEADY`: ทำงานเป็นจังหวะก้าวสม่ำเสมอในระยะยาว
* **หมวดการวินิจฉัย (TH_NATAL_ASC_DECISION_STYLE)**:
  - `TH_NATAL_ASC_DECISION_ANALYTICAL`: ยึดเหตุผลและสถิติข้อมูลอ้างอิง
  - `TH_NATAL_ASC_DECISION_INTUITIVE`: ตระหนักรู้สัญชาตญาณความรู้สึกร่วมของทีม
* **หมวดความต้องการพัก (TH_NATAL_ASC_RECOVERY_NEED)**:
  - `TH_NATAL_ASC_RECOVERY_HIGH_SOLITUDE`: ต้องการความเงียบสงบโดยไร้สิ่งรบกวนภายนอก
  - `TH_NATAL_ASC_RECOVERY_ACTIVE_REST`: คืนกำลังด้วยการเปลี่ยนกิจกรรมทางกายภาพเบาๆ
* **หมวดจำกัดความมั่นใจต่ำ (TH_NATAL_ASC_CONFIDENCE_LOW)**:
  - `TH_NATAL_ASC_CONFIDENCE_LOW_WARNING`: ข้อมูลนำเข้าไม่เพียงพอ ใช้เฉพาะโหมดแนะนำทั่วไป

## 5. House Signal IDs (กลุ่มรหัสตามภพเรือนชะตา)

วิเคราะห์ตามความสัมพันธ์ของภพชะตาจากลัคนา:
* `TH_HOUSE_SELF_WORK_STYLE`: วิธีปฏิบัติภารกิจอิงจากราศีสถิตตนุ
* `TH_HOUSE_CAREER_FOCUS`: เป้าหมายงานส่งมอบหลักอิงจากกัมมะ
* `TH_HOUSE_NETWORK_GAIN`: โอกาสการดึงเครือข่ายเพื่อนร่วมงานมาประสานประโยชน์อิงจากลาภะ
* `TH_HOUSE_PROBLEM_SOLVING`: สไตล์การตรวจแก้ข้อผิดพลาดและบั๊กงานอิงจากอริ
* `TH_HOUSE_RECOVERY_BACKSTAGE`: การจำศีลทำงานยากเบื้องหลังเงียบๆ อิงจากวินาศ
* `TH_HOUSE_COLLABORATION`: แผนการประชุมเจรจากลุ่มคู่สัญญาอิงจากปัตนิ
* `TH_HOUSE_HOME_BASE`: เสถียรภาพสภาพแวดล้อมที่ทำงานอิงจากพันธุ
* `TH_HOUSE_LEARNING_EXPANSION`: การเพิ่มพูนองค์ความรู้เชิงลึกอิงจากศุภะ
* `TH_HOUSE_DELAY_REVIEW`: ความตึงเครียดเชิงภาระและบัญชีที่ต้องทบทวนอิงจากมรณะ
* `TH_HOUSE_DECISION_CAUTION`: ข้อระวังการจ่ายทรัพยากรส่วนกลางอิงจากกดุมภะ

## 6. Planet Signal IDs (กลุ่มรหัสสัมพันธ์ตำแหน่งดาวเคราะห์)

วิเคราะห์สัญญะของดวงดาวเด่นประจำวันกำเนิด (ดาว ๑ ถึง ๙):
* `TH_PLANET_SELF_DRIVE`: จุดจดจ่อและความเป็นผู้นำเฉพาะวัน (ดาว ๑)
* `TH_PLANET_EMOTIONAL_RHYTHM`: การประคองจิตใจและความละเอียดอ่อน (ดาว ๒)
* `TH_PLANET_ACTION_FORCE`: ความเพียรพยายามทางกายภาพและความเร็ว (ดาว ๓)
* `TH_PLANET_COMMUNICATION_STYLE`: การเจรจา การเจียมเนื้อเจียมตัว และงานวิเคราะห์ (ดาว ๔)
* `TH_PLANET_LEARNING_EXPANSION`: ความเคารพกฎเกณฑ์ ทฤษฎีวิชาการ และจรรยาบรรณ (ดาว ๕)
* `TH_PLANET_RELATIONSHIP_STYLE`: การสร้างมนุษยสัมพันธ์ สุนทรียศาสตร์ และการประนีประนอม (ดาว ๖)
* `TH_PLANET_STRUCTURE_DISCIPLINE`: วินัยความรับผิดชอบและความทรหด (ดาว ๗)
* `TH_PLANET_COMPLEXITY_CHECK`: การตรวจจับความเสี่ยงเทคโนโลยีและงานทางไกล (ดาว ๘)
* `TH_PLANET_BACKSTAGE_RELEASE`: การเคลียร์จุดตกหล่นและทำงานปิดทองหลังพระ (ดาว ๙)
* `TH_PLANET_RECOVERY_SIGNAL`: แหล่งคืนสภาพพลังงานร่างกายตามสมดุลธาตุประธาน

## 7. Strategy Copy Templates (แม่แบบข้อความปลอดภัยเชิงกลยุทธ์)

ประโยคอธิบายสำหรับแสดงผลบน UI จะถูกคุมด้วยแม่แบบจิตวิทยาเชิงบวกที่ระบุทางเลือกลงมือกระทำ:
* "วันนี้การสะท้อนคิดเชิงกลยุทธ์แนะนำให้เน้นการ..."
* "แนวโน้มจังหวะพื้นดวงสนับสนุนแผนงานประเภท..."
* "ควรประคองและชะลอการตัดสินใจที่อิงอารมณ์ชั่ววูบในเรื่อง..."
* "เหมาะสำหรับการตรวจสอบและทบทวนความคุ้มค่าของเอกสารสัญญาเชิงลึกในหมวด..."
* "หากพบความล้าสะสมล่าสุด แนะนำให้ลดขนาดโครงการจำกัดแรงกดดันสมองลงเหลือ..."
* "ใช้แผนผังจำลองสัญญะนี้ประกอบเป็นกรอบแนวทางเพื่อการทดลองและประเมินจังหวะชีวิตรายวัน"

## 8. Unsafe Copy Rules (กฎเหล็กการกรองคำศัพท์ไม่พึงประสงค์)

ห้ามไม่ให้มีชุดข้อความหรือองค์ประกอบคำทำนายเชิงตัดสินอนาคตเด็ดขาด:
* **คำต้องห้าม**: *เคราะห์, ซวย, กาลกิณี, อุบัติเหตุ, เงินเสียแน่, งานพัง, ความรักพัง, ห้ามทำเด็ดขาด, จะเกิดแน่นอน, ดวงบังคับ, ชะตากำหนด*
* **เจตจำนงการแปลความหมายเชิงบวก (Copy Safety Override)**:
  - เปลี่ยน ภพมรณะ เป็น "การปรับรูปแบบและส่งมอบระบบงานเดิม"
  - เปลี่ยน ภพอริ เป็น "การสะสางแก้บั๊กและดูแลสภาพความเหนื่อยล้าทางกายภาพ"
  - เปลี่ยน ภพวินาศ เป็น "โหมดการทำงานเบื้องหลังสันโดษ"
  - เปลี่ยน ดาวเสาร์ (๗) จรถึงลัคนา เป็น "การควบคุมวินัยอย่างเข้มงวดและการสร้างความสม่ำเสมอในเป้าหมายระยะยาว"

## 9. Confidence-aware Copy (ระดับข้อความประคองความมั่นใจ)

* **ความเชื่อมั่นสูง (Score >= 0.8)**: คืนข้อความระบุแผนงานปกติของระบบประเมินได้
* **ความเชื่อมั่นปานกลาง (0.4 - 0.7)**: ปรับโครงสร้างประโยคอ้างอิงให้มีตัวแปรช่วยประคอง เช่น "สัญญะจำลองเบื้องต้นอาจสะท้อน..." หรือ "ใช้เป็นกรอบประกอบการสังเกตตนเองเบื้องต้น..."
* **ความเชื่อมั่นต่ำ (ต่ำกว่า 0.4)**:
  - ระบบจะซ่อนคำแปลเฉพาะจุดรายภพชะตาและดาวจรปะทะตัว
  - แสดงผลลัพธ์คำอธิบายอภิปรายกว้างระดับโปรไฟล์ทั่วไป และระบุหมายเหตุจำกัดคะแนนความมั่นใจ
* **กรณีไม่มีเวลาเกิด (Missing birth time)**: ซ่อนการพยากรณ์รายละเอียดเชิงลึกของ 12 ภพ เพื่อประคองความถูกต้องของตารางกลยุทธ์การตัดสินใจของผู้ใช้

## 10. Dictionary Output Contract (ข้อกำหนดรูปแบบพจนานุกรม)

โครงสร้างข้อมูลของแต่ละ Entry ในระบบพจนานุกรม (ThaiNatalStrategySignalDictionaryEntry):

```typescript
interface ThaiNatalStrategySignalDictionaryEntry {
  signalId: string;                   // รหัสสัญญาณเฉพาะ (เช่น "TH_PLANET_SELF_DRIVE_FOCUS")
  category: 'work' | 'decision' | 'recovery' | 'collaboration' | 'risk' | 'learning' | 'execution' | 'review' | 'communication' | 'backstage';
  sourceType: 'ascendant' | 'house' | 'planet' | 'composer'; // จุดกำเนิดประมวลผล
  safeTitle: string;                  // ชื่อสัญญะฉบับสั้นเชิงบวก (ภาษาไทย เช่น "โหมดสร้างเสถียรภาพ")
  shortMeaning: string;               // ความหมายโดยย่อในเชิงบริหารจัดกิจกรรม
  strategyAdvice: string;             // ข้อเสนอแนะเชิงกลยุทธ์การทำงานที่ลงมือทำได้
  cautionNote?: string;               // หมายเหตุแจ้งเตือนจุดเสี่ยงหรือบั๊กงานที่ต้องเฝ้าระวัง (ไม่บังคับระบุ)
  recoveryNote?: string;              // แนวทางการคลายความล้าและการคืนกำลังสมอง (ไม่บังคับระบุ)
  confidenceRequirement: number;      // เกณฑ์ความเชื่อมั่นที่ยอมรับให้แสดงผล (0.0 - 1.0)
  forbiddenWhenConfidenceBelow: number; // จุดตัดการระงับการเรนเดอร์เนื้อหา (ถ้าค่าต่ำกว่าเกณฑ์นี้จะถูกซ่อน)
  copySafetyStatus: 'passed' | 'review_needed'; // การันตีผลการคัดกรองคำต้องห้าม
  version: string;                    // เวอร์ชันบันทึกระบบ (เช่น "0.1.0")
}
```

## 11. Product Interpretation Policy (จุดยืนการแปลความหมาย)

การตีความทางข้อมูลของพจนานุกรมต้องอยู่ภายใต้เกณฑ์ยุทธศาสตร์งานเท่านั้น:
* **ขอบเขตการแปลความหมาย**:
  - วิเคราะห์ลักษณะงานที่ควรให้ลำดับความสำคัญประจำยามเวลา
  - บันทึกจังหวะเวลาที่ควรตรวจทานเอกสารทางบัญชีและกฎหมายเงียบๆ
  - แนะนำแนวทางการเตรียมตัวประชุมกับคู่ค้าภายนอก
  - แจ้งเตือนข้อควรระวังเรื่องการใช้ร่างกายเมื่อระดับความเหนื่อยสะสมสูง
* **สิ่งที่ไม่แปลผลเด็ดขาด**: ไม่แปลเรื่องสุขภาพร้ายแรง อุบัติเหตุรุนแรง ความสัมพันธ์หักรักพัง หรือทิศทางการเสี่ยงโชคลาภเงินทองแบบไร้ข้อมูลสนับสนุน

---

## 12. Data Safety (ความปลอดภัยของข้อมูล)

* **ความคงอยู่แบบสแตติก**: ตัว Dictionary จะจัดตั้งอยู่ในรูปแบบ static content ภายใน source code Client-side ไม่มีการเรียกขอข้อมูลผ่านเครือข่าย
* **ไม่มีการเขียนข้อมูลเอาต์พุตเชิงประเมิน**: ระบบการจัดประวัติสะสมของผู้ใช้จะบันทึกเฉพาะชุดรหัส `Signal IDs` ไม่เก็บประโยคแปลความขนาดยาว เพื่อป้องกัน Regression และช่วยประหยัดเนื้อที่การ Import/Export ข้อมูลจำลอง

---

## 13. Non-Scope (กรอบนอกเหนือการดำเนินงาน)

* **ไม่จัดทำไฟล์รันไทม์จริง**: ไม่เขียนโปรแกรมเชิงตรรกะใน Workspace `src/` ทั้งหมด
* **ไม่ดัดแปลง LocalStorage**: คงรูปเสถียรภาพระบบดั้งเดิม
* **ไม่ต่อ API ภายนอก**: ระบบคำนวณและแปลผลยังคงเป็นแบบออนดีไวซ์ ปิดเครือข่าย
* **ไม่คัดลอกเนื้อหาตำราขนาดยาว**: หลีกเลี่ยงปัญหา Code Bloat
