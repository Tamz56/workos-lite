- **Status**: Passed
- **Evidence**:
  - ระบุฟิลด์ตรวจสอบหลักของ Birth Profile ได้แก่รูปแบบ `YYYY-MM-DD` ของ `birthDate` และรูปแบบ `HH:mm` ของ `birthTime`

- **Notes**: การกำหนดเกณฑ์ validation แบบ Atomic (All-or-Nothing) จะป้องกันปัญหาข้อมูลในเครื่องเสียหายบางส่วนหากไฟล์มีข้อผิดพลาดบางจุด
- **Follow-up required**: ใน DEV-046 ต้องแน่ใจว่าได้ใช้ตัวดักจับความถูกต้อง `validateAstroBirthProfile` ร่วมด้วย

### ค. โหมดการกู้คืนและการจัดการข้อขัดแย้ง (Restore Modes & Conflict Resolution)
- **Status**: Passed
- **Evidence**:
  - กำหนดโหมดการทำงานครบถ้วน 3 ระดับ ได้แก่:
    1. **Preview/Dry-Run**: เพื่อสแกนวิเคราะห์เชิงลึกโดยไม่เขียนข้อมูลลงดิสก์
    2. **Merge-Safe**: รักษารายการประวัติเดิมและเติมเฉพาะรายการใหม่ ป้องกันการเขียนทับโดยอุบัติเหตุ
    3. **Replace**: ล้างคีย์เดิมและนำเข้าทั้งหมดหลังจากการยินยอมแบบสองปัจจัย (Explicit confirmation checkbox + Dialogue)
- **Notes**: การให้ความสำคัญสูงสุดกับการมีส่วนร่วมยืนยันของผู้ใช้และตัวเลือกการผสานข้อมูลที่ปลอดภัยจะสร้างความโปรดปรานและความมั่นใจสูงสุด
- **Follow-up required**: ปุ่มควบคุมหน้าจอจะต้องถูกจัดวางในหน้าพรีวิวให้ชัดเจน ไม่ปะปนกับกระบวนการใช้งานหลัก

- **Evidence**:
