# ASTRO-REAL-APP-DEV-051 — MVP-v4 Advanced Astro Strategy Scope Lock

## Goal
จัดทำเอกสารและล็อกขอบเขตข้อกำหนดเชิงเนื้อหาและระบบ (Scope Lock) สำหรับเฟส **MVP-v4 — Advanced Astro Strategy Layer** ของ Astro Strategy Lab ในระบบ ArborDesk เพื่อกำหนดทิศทางผลิตภัณฑ์ ขอบเขตการพัฒนา สิ่งที่อยู่นอกเหนือขอบเขต แนวทางจริยธรรมภาษาและการนำเสนอที่ปลอดภัย และลำดับสายงานพัฒนา (DEV Sequence) ก่อนเริ่มดำเนินการแก้ไขโค้ดจริงในขั้นตอนถัดไป

---

## Scope
- การกำหนดธีมหลักและทิศทางของ MVP-v4 เพื่อขยายมิติการตัดสินใจและการประคองโฟกัสสมาธิ
- รายละเอียดข้อกำหนดของเลเยอร์ย่อยทั้ง 4 เลเยอร์ (โหราศาสตร์ไทย, เมตาฟิสิกส์จีน, อี้จิงเพื่อการตัดสินใจ, สมาธิและจักระ)
- หลักการประกอบข้อมูลเชิงลึกข้ามศาสตร์ (Multi-layer insight composition) และวิธีจัดการข้อขัดแย้งของคำแนะนำ
- มาตรฐานความปลอดภัยข้อมูลและข้อกำหนดภาษาการนำเสนอเพื่อความปลอดภัยของสภาพจิตใจผู้ใช้ (Copy & Ethics Guardrails)
- ผลกระทบต่อสถาปัตยกรรมเดิม (Data Model, Storage, Export/Import, UI Layout)
- การระบุขอบเขตการพัฒนาที่ต้องละเว้นไว้ก่อน (What must not be built yet)
- ทะเบียนความเสี่ยงและการป้องกัน (Risk Register)
- ข้อเสนอแนะในการพัฒนาชิ้นแรกหลังจากการล็อกสเปกนี้

## Non-scope
- การแก้ไขหรือดัดแปลงซอร์สโค้ดในรันไทม์ (src/) ในทุกกรณี
- การคำนวณตำแหน่งดวงดาวดาราศาสตร์จริงในโค้ด (ยังไม่เปิดใช้งานเครื่องคำนวณจริงในขั้นตอนนี้)
- การเชื่อมต่อกับฐานข้อมูลระบบคลาวด์ภายนอก หรือการใช้งาน API แบบระบุตัวตนออนไลน์

## MVP-v4 Theme & Product Direction

* **ธีมหลัก (Theme)**: **"Synthesized Strategic Wisdom, Internal Focus & Non-Deterministic Guidance"**
* **ความสำคัญของการทำต่อจาก Data Portability (MVP-v3)**:
  ในเฟส MVP-v3 ที่ผ่านมา ระบบได้พัฒนาฐานรากความพร้อมด้านการโอนย้ายข้อมูล (Data Portability) เช่น ระบบตรวจสอบประวัติสะท้อนคิด การนำเข้า/ส่งออก (Export/Import/Restore) ข้อมูลแบบ Local-first และการประเมินสเกลฐานข้อมูลอย่างปลอดภัย การที่ MVP-v4 ดำเนินการต่อจากจุดนี้ช่วยให้มั่นใจได้ว่า ข้อมูลมิติขั้นสูงที่ซับซ้อนขึ้นอย่างข้อมูลเวลาเกิด ธาตุประจำตัว ประวัติการโยนอี้จิง หรือการฟื้นฟูจักระ จะได้รับการปกป้องและจัดเก็บอย่างสมบูรณ์ ไม่แตกหักหรือสูญหายเมื่อระบบมีการอัปเกรดรุ่นถัดไป
* **ทิศทางผลิตภัณฑ์ (Product Direction)**:
  ยกระดับระบบให้เป็นเครื่องมือประคองสมาธิและการวางแผนเชิงกลยุทธ์ส่วนบุคคล (Focus Operating System) ที่ใช้สัญลักษณ์โบราณของเอเชียตะวันออกและเอเชียตะวันตกมาเป็นเครื่องมือช่วยกระตุ้นการสะท้อนสติ (Reflection Context) และจัดจังหวะเวลา โดยปราศจากการครอบงำทางความคิด การทำนายอนาคตเชิงลี้ลับ หรือการสร้างความหวาดกลัว เพื่อสร้างสภาพแวดล้อมการทำงานที่มีประสิทธิภาพและส่งเสริมสภาพจิตใจที่สงบ (Cognitive Calmness)

## Advanced Astro Strategy Product Design (4 Layers)

### Layer 1: Thai Astrology Strategy Layer (ยามอุบากองและธาตุสู้ชีวิต)
* **Purpose**: ใช้ยามอุบากอง (ยามเดินทาง/นัดหมายเจรจา) และรอบธาตุรายวันของโหราศาสตร์ไทยเพื่อประกอบการวางจังหวะเวลานัดหมาย ทำงานสำคัญ หรือเจรจาธุรกิจอย่างเหมาะสม
* **Input Data Needed**:
  - วันเกิดประจำสัปดาห์ (เช่น วันพฤหัสบดี) จากข้อมูล Birth Profile
  - วันที่ประเมินและเวลาปัจจุบัน (Target Date & Time)
* **Output Style**:
  - ตารางเปรียบเทียบยามอุบากองในวันปัจจุบันแบบเข้าใจง่าย (แบ่งเป็นช่วงเวลาดี/ปานกลาง/ควรระมัดระวัง)
  - คำแนะนำการจัดการภารกิจอิงตามจังหวะธาตุรายวัน เช่น "รอบวันธาตุน้ำไทย: เหมาะกับการเจรจาที่เน้นความยืดหยุ่นและการเจือจางความตึงเครียด"
* **What it should not claim (ข้อห้าม)**:
  - ห้ามอ้างความแม่นยำ 100% ว่ากิจกรรมจะสำเร็จแน่นอนหรือล้มเหลวแน่แท้
  - ห้ามกล่าวถึงอันตรายต่อชีวิตและทรัพย์สิน อุบัติเหตุร้ายแรง หรือเคราะห์กรรมที่หลีกเลี่ยงไม่ได้

### Layer 2: Chinese Metaphysics Strategy Layer (วิถีธาตุและจังหวะพลังงานห้าธาตุ)
* **Purpose**: วิเคราะห์สมดุลของพลังงาน 5 ธาตุ (ไม้ ไฟ ดิน ทอง น้ำ) ตามรอบฤดูกาลจีนเพื่อประเมินความพร้อมเชิงลึกและการบริหารสมาธิรายวัน
* **Input Data Needed**:
  - วันเดือนปีเกิดและเวลาเกิด (เพื่อสกัดหาธาตุประจำตัว/Day Master หรือธาตุส่งเสริมเบื้องต้น)
  - ฤดูกาลปัจจุบันตามปฏิทินสุริยคติจีน
* **Output Style**:
  - สัญลักษณ์สีและถ้อยคำอธิบายพลังงานประจำวัน เช่น "วันธาตุไฟหนุนเสริมผู้เกิดธาตุไม้: ปลุกพลังสร้างสรรค์และความกล้าส่งมอบผลงานชิ้นเอก"
* **What it should not claim (ข้อห้าม)**:
  - ห้ามฟันธงโชคลาภทางการเงิน การถูกหวย หรือความร่ำรวยทางลัด
  - ห้ามแนะนำให้ทำพิธีกรรมแก้ชง ปัดเป่าเสนียดจัญไร หรือการใช้จ่ายเพื่อซื้อสิ่งมงคลมาบูชา

### Layer 3: I Ching Decision Support Layer (อี้จิงสะท้อนความคิดเชิงกลยุทธ์)
* **Purpose**: มอบระบบดึงสัญญะอี้จิง (Hexagrams) รายสัปดาห์ เพื่อชี้แนะการสะท้อนสติและการตัดสินใจในภารกิจเชิงลึกยามพบอุปสรรคหรือทางเลือกที่ซับซ้อน
* **Input Data Needed**:
  - Strategic Question (คำถามหรือหัวข้อสำคัญที่ผู้ใช้ต้องการสะท้อนคิดประเมินเชิงกลยุทธ์)
  - ค่าสุ่มตัวเลข (Coin tosses จำลอง 6 ครั้ง) ที่เกิดจากการสุ่มภายในเครื่อง (Client-side Pseudo-randomization)
* **Output Style**:
  - ภาพสัญลักษณ์กู่ (Hexagram) พร้อมความหมายเชิงปรัชญาธรรมชาติ (เช่น ภูเขาอยู่เหนือดิน, ลมอยู่เหนือฟ้า)
  - คำถามสะท้อนคิด (Reflection Prompts) เพื่อชวนให้ผู้ใช้วิเคราะห์ประเด็นที่ตนอาจมองข้าม
* **What it should not claim (ข้อห้าม)**:
  - ห้ามตอบในลักษณะ Yes/No ที่ตัดสิทธิ์การตัดสินใจของผู้ใช้ (เช่น "ห้ามลงทุน" หรือ "ให้ลาออกทันที")
  - ห้ามอ้างว่าอี้จิงคือสัจธรรมสูงสุดที่ต้องปฏิบัติตามอย่างหลับหูหลับตา แต่เสนอในฐานะ "กระจกสะท้อนอีกด้านของกลยุทธ์"

### Layer 4: Meditation / Chakra Support Layer (ระบบประคองจักระและเสียงผ่อนคลาย)
* **Purpose**: เชื่อมโยงระดับพลังงานสะสมจากแบบประเมินเช็คอินรายวัน (Daily Checkin Snapshot) เพื่อแนะนำสมอเสียง (Sound Anchors) หรือคำแนะนำด้านสมาธิจดจ่อจักระเมื่อพบสัญญาณความเหนื่อยล้าสะสม
* **Input Data Needed**:
  - ข้อมูล Daily Checkin (energyLevel, clarityLevel, workloadPressure, focusCondition, bodySignal)
* **Output Style**:
  - คำแนะนำการทำสมาธิสั้น 1-3 นาทีที่สัมพันธ์กับจักระที่สอดคล้อง (เช่น จักระที่ 6 Ajna เมื่อคิดงานไม่ออก หรือจักระที่ 3 Manipura เมื่อรู้สึกหมดแรงผลักดัน)
  - คำแนะนำความถี่เสียงบำบัดธรรมชาติ (Sound anchor recommendations) เช่น คลื่นความถี่ Solfeggio 528Hz หรือ 639Hz
* **What it should not claim (ข้อห้าม)**:
  - ห้ามอ้างว่าช่วยบำบัดรักษาโรคภัยไข้เจ็บทางกายภาพ หรือรักษาโรคจิตเวช (เช่น ซึมเศร้า หรือไบโพลาร์)
  - ห้ามแสดงข้อความเชิงอภินิหาร เช่น การเบิกเนตรวิเศษ หรือการบรรลุธรรมลอยตัว

## Multi-layer Insight Composition Principles (หลักการผสานพลังงานอินไซต์)

1. **แกนมิติเวลาและความสอดคล้อง (Temporal & Contextual Alignment)**:
   - **มิติระยะสั้นรายวัน (Short-term Timing)**: ใช้ยามอุบากอง (ไทย) และรอบธาตุรายวันเพื่อประกอบตารางเวลาการทำงานประจำวัน
   - **มิติระยะกลางรายสัปดาห์ (Medium-term Strategy)**: ใช้อี้จิง (I Ching) เพื่อประเมินภาพรวมรายสัปดาห์และแนวทางสะท้อนคิดเชิงลึกเมื่อปิด Sprint
   - **มิติระยะยาวและเชิงลึก (Long-term Context & Persona)**: ใช้ธาตุประจำตัวตามฤดูกาลจีน ร่วมกับการฟื้นฟูจิตใจตามสเตตัสจักระ (Chakra/Meditation) เมื่อผู้ใช้พบสัญญาณหมดไฟ (Burnout/Stress)
2. **การจัดการข้อขัดแย้งเชิงคำแนะนำ (Conflict Resolution Logic)**:
   - หากคำแนะนำจากต่างศาสตร์มีผลลัพธ์ขัดแย้งกันอย่างมีนัยสำคัญ (เช่น โหราศาสตร์ไทยแนะนำให้ลุยเชิงรุกเต็มที่ แต่อี้จิงแนะนำให้ถอยห่างและสงบนิ่ง) ระบบจะไม่ปล่อยผ่านข้อความที่ขัดแย้งกันออกไปสู่หน้าจอเพื่อป้องกันความสับสนของผู้ใช้
   - **หลักการคุ้มครองพลังงานใจผู้ใช้เป็นหลัก (Safety-first & Low-burnout priority)**: ระบบจะสกัดคำแนะนำโดยปรับความสำคัญลงสู่โหมดปลอดภัยเสมือนเป็นกันชนทางอารมณ์ (เช่น ปรับให้เน้นการวางแผน Stabilize & Structure หรือ Pause & Calibrate) และเน้นการลงมือทำด้วยสติรอบคอบแทนความเร่งรีบ

## Output Safety and Copy Guardrails (ขอบเขตคำและภาษาป้องกันภัยทางจิตวิทยา)

- **โทนเสียง (Tone of Voice)**: มีความเป็นกลาง ให้คำแนะนำเชิงกลยุทธ์และการตั้งสติ (Objective Strategic Guidance) มีกลิ่นอายปรัชญาธรรมชาติ ปลุกพลังแห่งความตั้งมั่นและลดความตึงเครียด (Cognitive Calmness)
- **คำและแนวคิดที่ห้ามนำเสนอโดยเด็ดขาด (Forbidden Words & Concepts)**:
  - คำแสดงความสูญเสียทางกายภาพ: "หายนะ", "ดวงตก", "เคราะห์กรรมหนัก", "วิบัติ", "ล่มจม", "อุบัติเหตุคอขาดบาดตาย"
  - คำแสดงการฟันธงอนาคตล่วงหน้า: "รวยทางลัด", "ถูกรางวัล", "พบลู่ทางรวยแน่แท้", "จะโดนหักหลังแน่นอน"
  - คำเคลมเกินจริงทางการแพทย์: "รักษาโรคซึมเศร้าหายขาด", "บำบัดรักษาโรคหัวใจด้วยคลื่นเสียง"
- **แนวทางการเขียนข้อความทดแทน**:
  - แทนที่ด้วยแนวทาง "จุดควรเฝ้าสังเกตในการวางแผน", "การเผชิญหน้าความท้าทายด้วยความรอบคอบ", "ช่วงเวลาที่เหมาะสมในการหันมาทบทวนความพร้อมของเครื่องมือและแผนงาน"

## Architectural Implications (ผลกระทบต่อสถาปัตยกรรมระบบ)

### 1. Data Model Implications
- ขยายโมเดล `ReflectionHistoryItem` เพื่อรองรับข้อมูล Snapshot ของ Advanced Strategy ที่ผสานในอดีตอย่างเป็นระเบียบ:
  ```typescript
  export interface AdvancedAstroStrategySnapshot {
    thaiUbakongBrief?: string;
    chineseElementBrief?: string;
    ichingHexagramNumber?: number;
    activeChakraAnchor?: string;
  }
  ```
  โดยฟิลด์เหล่านี้ต้องเป็น Optional เพื่อคงความเข้ากันได้ย้อนหลัง (Backward Compatibility) กับข้อมูลประวัติสะสมเดิมทั้งหมด

### 2. Storage Implications
- ข้อมูลสะท้อนคิดที่มีรายละเอียดสูงขึ้นจะขยายปริมาณพื้นที่เบราว์เซอร์เร็วขึ้น แม้จะยังรองรับบน LocalStorage แต่ต้องสอดคล้องกับข้อคิดเห็นในรีวิว Scalability (DEV-048) เพื่อเตรียมย้ายไปใช้ IndexedDB และจัดการสแกนเก็บข้อมูลเฉพาะรหัสอ้างอิงของศาสตร์ (เช่น รหัส Hexagram `4` แทนการบันทึกบทความยาวๆ) เพื่อประหยัดเนื้อที่

### 3. Export / Import Implications
- ฟังก์ชันการตรวจสอบ Schema ในตอนนำเข้าข้อมูล (Import Validator) ที่พัฒนาขึ้นใน v3 ต้องอัปเดตให้รองรับคีย์ข้อมูลเสริมของ Advanced Layer ได้อย่างยืดหยุ่น เพื่อหลีกเลี่ยงการแจ้งเตือน "ข้อมูลเสีย" ระหว่างคืนค่าข้อมูลข้ามเครื่อง

### 4. UI Implications
- การจัดตำแหน่ง Desktop Layout ต้องไม่รบกวนประสิทธิภาพการอ่านเขียน:
  - แผงควบคุมซ้ายมือ: 280–320px (พื้นที่กรอก Birth Profile และสวิตช์ปิด/เปิดเลเยอร์)
  - แผงแก้ไขเนื้อหากลาง: minmax(560px, 1fr)
  - แผงประเมินขวามือ: 360–420px (แสดง Advanced Strategy Summary)
