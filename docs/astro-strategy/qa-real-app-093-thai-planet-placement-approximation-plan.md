## 3. Notes (บันทึกเพิ่มเติม)

* **การคุ้มครองข้อมูลอ่อนไหว**: การยอมรับข้อตกลงว่าตำแหน่งดาวเคราะห์จะทำงานบน In-memory ชั่วขณะเกิดของ Client-side เท่านั้น ช่วยสนับสนุนการใช้งานบราวเซอร์ส่วนตัวของผู้ใช้โดยไม่ต้องส่งผ่านข้อมูลเกิดออกภายนอก
* **ความกระชับของข้อมูล (Anti-Bloat)**: การเก็บค่าเอาต์พุตเฉพาะ Signal IDs และดาวประธานช่วยป้องกันปัญหา Code Bloat ในขอบเขตซอฟต์แวร์ได้อย่างต่อเนื่อง
