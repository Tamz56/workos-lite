# เอกสารการประเมินความพร้อมก่อนการสลับหน้าใช้งานจริง (Route Switch Readiness Review) — Astro Real App

เอกสารฉบับนี้เป็นการประเมินและเปรียบเทียบความแตกต่างระหว่างหน้าจอดั้งเดิม (Prototype - `/workspaces/astro-strategy`) และหน้าจอใหม่ที่พัฒนาขึ้น (Real App Preview - `/workspaces/astro-strategy/real-app-preview`) เพื่อความปลอดภัยก่อนการสลับหน้าเว็บใช้งานจริง

---

## 1. สถานะปัจจุบัน (Current State)
ในขั้นตอน DEV-001 ถึง DEV-015 ได้มีการพัฒนาและแยกคอมโพเนนต์ย่อยออกเป็นโมดูลที่เป็นสัดส่วน (Today, Reflection, History, Planning, Guide, Tools) พร้อมสร้างตัวเชื่อมข้อมูลถาวร LocalStorage Adapter v0.1 ที่ใช้งานระบบ Namespace แยกอย่างปลอดภัยเรียบร้อยแล้วบนหน้าพรีวิวแยกตัว

---

## 3. รายการตรวจสอบการจัดเก็บข้อมูล (Persistence Checklist)

- [x] **Namespace Isolation**: คีย์ใหม่ใช้พรีฟิกซ์ `astro-real-app:` ซึ่งไม่ทับซ้อนกับคีย์โปรโตไทป์เดิม (`astro-strategy:` / `astro.strategy.`) ทำให้มั่นใจได้ว่าไม่มีการขัดแย้งของข้อมูล
- [x] **Draft Recovery**: ดราฟต์ของข้อความสะท้อนคิดจัดเก็บบนคีย์แยกชิ้นและล้างค่าออกทันทีที่กดบันทึกประวัติสำเร็จหรือกดรีเซ็ต
- [x] **Version Envelope**: โครงสร้างไฟล์เซฟใช้รูปแบบ `AstroPersistedPayload<T>` ครอบหุ้มด้วยเวอร์ชันและฟิลด์วันเวลาอัปเดตเพื่อรองรับการขยายตัวในอนาคต

---

## 4. รายการตรวจสอบความปลอดภัย (Safety Checklist)

- [x] **No SSR Hydration Mismatch**: หน้าพรีวิวทำการโหลดข้อมูลหลังเมาท์ผ่าน `useEffect` และสถานะ `isHydrated` หมดห่วงเรื่องความแตกต่างระหว่าง HTML บนเซิร์ฟเวอร์และไคลเอนต์
- [x] **No Prototype Override**: ไม่มีส่วนใดของโค้ดพรีวิวเข้าไปอิมพอร์ตหรือแก้ไขคีย์จัดเก็บของหน้าโปรโตไทป์หลัก
- [x] **JSON Protection**: ฟังก์ชันแปลงไฟล์สตริงหุ้มด้วย `try-catch` หากพบความผิดปกติจะกู้ข้อมูลกลับเป็นค่าเริ่มต้น `MOCK_DATA` เสมอ

---

## 5. รายการสิ่งที่เป็น Mock หรือข้ามไปก่อน (Missing / Deferred Items)
1. **Astrology Timing Engine**: ข้อมูลทิศทางกลยุทธ์ประจำวัน (Today’s Mode, Strategic Direction, Work Recommendations) ในคอมโพเนนต์จริงยังเป็นค่าคงที่ (Static Mock Data) ขาดตัวรับส่งและคำนวณตามวันเดือนปีเกิดของผู้ใช้งาน
2. **Daily Check-in Input Panel**: ข้อมูลสภาวะปัจจุบัน (Energy, Clarity, Focus, Workload) ยังไม่มีส่วนติดต่อผู้ใช้ให้กรอกข้อมูลเป็นฟอร์มแยกชิ้น (จำลองข้อมูลคงที่ผ่านคอลแบ็กบันทึกย้อนหลังในหน้าสะท้อนคิดแทน)

---

## 6. ความเสี่ยงและแนวทางควบคุม (Risks)
- **ความเสี่ยงข้อมูลสูญหาย (Data Loss)**: หากทำการสลับหน้าใช้งานจริงทันที ข้อมูลสะท้อนคิดในเครื่องที่สะสมไว้ในระบบเก่าจะไม่ไหลเข้าสู่ระบบ namespace ใหม่
  - *แนวทางควบคุม*: ในระบบเวอร์ชันถัดไป (ก่อนสลับใช้งานจริง) ต้องมีการเขียน Data Migration ย้ายข้อมูลจากคีย์โปรโตไทป์เก่ามายัง namespace ใหม่
- **ความเสี่ยงขาดฟังก์ชันพยากรณ์ดวงเกิดจริง**: เนื่องจากระบบยังไม่มี Timing Engine คำนวณสด
  - *แนวทางควบคุม*: ในระยะถัดไป ต้องพอร์ตตรรกะคำนวณวันเกิดและตำแหน่งทางดาราศาสตร์เข้ามาไว้ในตัวประสานของแอปจริง

---

## 7. แผนการ Rollback/Revert (Rollback Plan)
หากหลังจากการสลับหน้าใช้งานแล้วพบข้อผิดพลาดหรือผู้ใช้งานต้องการกลับไปใช้ระบบเก่า:
1. การเชื่อมต่อหน้าเว็บหลัก `src/app/(main)/workspaces/astro-strategy/page.tsx` จะถูกปรับเปลี่ยนโดยง่าย เพียงแก้ไขการเรนเดอร์คอมโพเนนต์:
   - สลับจาก `<AstroRealAppPreview />` กลับเป็น `<AstroStrategyPrototypeClient />`
2. เนื่องจากระบบใหม่ใช้ Namespace ของคีย์แยกส่วนเด็ดขาด ข้อมูลผู้ใช้ในคีย์โปรโตไทป์เก่าจะยังคงสภาพสมบูรณ์ไร้รอยขีดข่วน สามารถนำกลับมาแสดงผลต่อได้ทันทีโดยไม่มีข้อมูลตกหล่น

---

## 8. แผนการสลับใช้งานจริงที่แนะนำ (Recommended Switch Strategy)
แนะนำให้ทำเป็น 3 ระยะ:
- **ระยะที่ 1 (ปัจจุบัน)**: เก็บหน้า Preview แยกตัว เพื่อให้ทำการ QA และจัดเอกสารแผนงาน
- **ระยะที่ 2 (DEV-017)**: รวมโค้ดคำนวณระบบดวงเกิด (Astrology Calculation Adapter) และพอร์ตฟังก์ชันคำนวณจังหวะรอบเวลามาจัดเก็บใน Adapter และเริ่มเขียน Adapter ย้ายข้อมูลสะสมเก่า (Migration v0.1)
- **ระยะที่ 3 (DEV-018)**: สลับการแสดงผลในหน้าเส้นทางหลัก `/workspaces/astro-strategy` โดยชี้ปลายทางมาที่คอมโพเนนต์แอปจริงตัวใหม่

## 9. ขอบเขตงานถัดไปที่เสนอของ DEV-017 (Proposed DEV-017 Scope)
- พัฒนา **Astrology Timing & Calculation Adapter** เพื่อคำนวณค่า Today's Mode และทิศทางจังหวะรายวันผ่านวันเกิดจริง
- พัฒนา **Data Migration v0.1 Adapter** เพื่อช่วยดึงค่าสะสมเดิมใน LocalStorage ของระบบโปรโตไทป์เก่า ย้ายถ่ายโอนมาเก็บไว้ในเนมสเปซใหม่ของตัวจริงอย่างนุ่มนวลเมื่อทำการรันแอปครั้งแรก
