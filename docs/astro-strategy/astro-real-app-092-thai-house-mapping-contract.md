# ASTRO-REAL-APP-DEV-092 — Thai House Mapping Contract

เอกสารฉบับนี้จัดทำขึ้นเพื่อกำหนดรูปแบบข้อตกลงโครงสร้างข้อมูล (Data Contract) ของการจัดเรือนชะตาไทย 12 ภพ (Thai House Mapping Contract v0.1) โดยอาศัยราศีลัคนา (Ascendant) เป็นจุดตั้งต้น เพื่อปูทางไปสู่การประมวลสัญญาณกลยุทธ์ส่วนบุคคล (Strategy Signal IDs) ตามพจนานุกรมแปลผลในขั้นตอนถัดไป

---

## 1. Goal (เป้าหมายของการกำหนดโครงสร้างภพชะตา)

* **กำหนดมาตรฐานข้อตกลงอินเทอร์เฟซ (Interface Data Contract)**: วางกรอบและคุณลักษณะข้อมูลของระบบผังภพเรือนชะตา 1-12 สำหรับดวงกำเนิดไทย v0.1
* **ใช้ลัคนาเป็นจุดเริ่มต้น**: อ้างอิงราศีลัคนาที่ประเมินได้เป็นจุดตั้งต้นของภพที่ 1 และเรียงลำดับราศีทวนเข็มนาฬิกาจนครบ 12 ภพเรือนชะตา
* **ฐานงานการแปลผล (Natal Strategy Interpreter Base)**: เพื่อใช้เชื่อมต่อกับตัวแปลสัญญาณกลยุทธ์ของหน้าสรุปการวางแผนชีวิตและการงาน
* **ข้อจำกัดในรอบการพัฒนา**:
  - ยังไม่มีการเขียนโค้ดคำนวณจริง (Runtime code) ในเทิร์นนี้
  - ยังไม่ส่งผลกระทบหรือแก้ไขโครงสร้าง LocalStorage schema

---

## 2. Why House Mapping Matters (ความสำคัญของการจัดเรือนชะตา)

เรือนชะตาหรือภพ (House System) ทำหน้าที่แบ่งแยกมิติชีวิตของผู้ใช้ออกเป็นหมวดหมู่ย่อย:
* **การตีความสภาพแวดล้อมเชิงกลยุทธ์**: ภพทั้ง 12 คือบริบทแวดล้อมที่ดวงดาวส่งพลังงานมากระทบ ช่วยแบ่งแยกกลุ่มกิจกรรมเชิงพฤติกรรม (ตัวตน, งาน, เพื่อนร่วมงาน, สิ่งกีดขวาง, การคืนพลังกาย)
* **ความคลาดเคลื่อนสะสม**: เนื่องจากโครงสร้างภพชะตาอ้างอิงตำแหน่งราศีลัคนาเป็นจุดกางเรือนชะตา หากลัคนาคลาดเคลื่อนเพียง 1 ราศี จะส่งผลให้ภพทั้งหมดเคลื่อนตำแหน่ง และทำลายความถูกต้องของกลยุทธ์ ระบบจึงต้องพิจารณาตัวแปรคะแนนความเชื่อมั่น (`confidenceScore`) และหมายเหตุความน่าจะเป็น (`uncertaintyNotes`) ร่วมด้วยเสมอ

## 3. Input Contract (ข้อตกลงอินเตอร์เฟซขาเข้า)

ชุดตัวแปรนำเข้าสำหรับการประมวลผลเรือนชะตา ซึ่งส่งต่อมาจากผลการประมาณค่าลัคนา:

```typescript
interface ThaiHouseMappingInputV01 {
  ascendantZodiacSign: string;        // ราศีลัคนาสถิต (ภาษาอังกฤษตัวเล็ก เช่น "aries", "taurus", ...)
  ascendantDegreeApprox?: number;      // องศาโดยประมาณของลัคนา (ไม่บังคับระบุใน v0.1)
  calculationMethod: string;          // วิธีการประมาณลัคนา (เช่น "sunrise_offset_v1")
  confidenceScore: number;            // คะแนนความมั่นใจที่ส่งต่อมา (0.0 - 1.0)
  zodiacSystem: 'sidereal' | 'tropical'; // ระบบจักรราศี (ค่าเริ่มต้นปฏิทินไทยคือ "sidereal")
  houseSystem: 'equal_house' | 'placidus' | 'prip-yart'; // ระบบจัดส่วนภพชะตา (เริ่มต้นใช้ "equal_house")
  birthDataConfidence: 'high' | 'medium' | 'low' | 'unknown'; // สภาพความสมบูรณ์ของข้อมูลตั้งต้น
  dayBoundaryRisk: boolean;           // แจ้งเตือนกรณีรอยต่อเวลาเปลี่ยนวันเกิด
  generatedAt: string;                // วันเวลาส่งข้อมูล (ISO-8601)
}
```

## 4. House Mapping Output Contract (ข้อตกลงอินเตอร์เฟซขาออก)

การจัดส่งชุดข้อมูลผังภพเรือนชะตาสำเร็จรูป (ThaiHouseMappingV01) สำหรับส่งต่อไปยังกลไกแปลผลกลยุทธ์:

```typescript
interface ThaiHouseMappingV01 {
  mappingId: string;                  // รหัสอ้างอิงเฉพาะของการประเมิน (UUID)
  source: string;                     // แหล่งที่มา (เช่น "AstroStrategyLab_HouseAdapter")
  calculationVersion: string;         // เวอร์ชันระบบการคำนวณ (เช่น "0.1.0")
  houseSystem: string;                // ระบบเรือนชะตาที่ใช้ในการจัดผัง
  ascendant: ThaiAscendantSnapshot;   // ภาพบันทึกข้อมูลลัคนาชะตากำเนิด
  houses: IndividualHousePlacementV01[]; // รายละเอียดของเรือนชะตาทั้ง 12 ภพ
  dominantWorkHouses: number[];       // รายการภพชะตาที่เน้นหนักในเรื่องงาน (เช่น 1, 10, 11)
  sensitiveHouses: number[];          // รายการภพชะตาที่ควรระมัดระวังเป็นพิเศษในการจัดแผน (เช่น 6, 12)
  strategicSignalIds: string[];        // รายการ Signal IDs โดยรวมที่สกัดได้จากสมดุลภพชะตา
  confidenceNotes: string;            // อธิบายระดับความเชื่อมั่นและเกณฑ์จำกัดของการประมาณค่า
  safetyDisclaimer: string;           // คำเตือนสิทธิ์จุดยืนข้อมูลกลยุทธ์ความมั่นคงปลอดภัย
  generatedAt: string;                // วันเวลาประมวลผลสำเร็จ (ISO-8601)
}

interface ThaiAscendantSnapshot {
  zodiacSign: string;
  confidenceScore: number;
  calculationMethod: string;
}
```

## 5. Individual House Contract (ข้อตกลงเรือนชะตารายภพ)

ข้อมูลเฉพาะตัวในแต่ละภพชะตาจากลำดับที่ 1 ถึง 12:

```typescript
interface IndividualHousePlacementV01 {
  houseNumber: number;                // ลำดับเรือนชะตา (1 ถึง 12)
  houseNameThai: string;              // ชื่อภพชะตาภาษาไทย (เช่น "ตนุ", "กฎุมพะ")
  houseNameTransliteration?: string;  // คำอ่านถอดสัญญะ (ไม่บังคับระบุ)
  zodiacSign: string;                 // ราศีสากลที่ครองเรือนชะตานี้ (เช่น "libra", "scorpio")
  themeCategory: 'work' | 'resource' | 'network' | 'obstacle' | 'recharge' | 'other'; // หมวดหมู่อิทธิพล
  workLifeTheme: string;              // หัวข้อหลักของการตีความความสัมพันธ์กับงานและชีวิต
  strategyMeaningIds: string[];       // รายการ Signal IDs ด้านกิจกรรมการทำงานที่สอดคล้อง
  cautionSignalIds: string[];         // รายการ Signal IDs ด้านจุดเตือนและการตรวจสอบความเสี่ยง
  recoverySignalIds: string[];        // รายการ Signal IDs ด้านกิจกรรมฟื้นพลังกายและพลังสมอง
  confidenceScore: number;            // คะแนนระดับความมั่นใจรายภพ (คำนวณแปรผันตามลัคนาและข้อมูลเกิด)
  uncertaintyNotes: string;           // บันทึกระบุสาเหตุความคลาดเคลื่อนเฉพาะภพ
}
```

## 6. 12 Houses Definition (นิยามและขอบเขตเชิงกลยุทธ์ของ 12 ภพ)

การจัดประเภทความหมายของภพเรือนชะตา มุ่งเน้นการสะท้อนสภาพพฤติกรรมและการวางแผนทำงานของผู้ใช้อย่างเหมาะสม:

1. **ตนุ (House 1)**: ตัวตน แรงผลักดัน และลักษณะการแสดงพฤติกรรมการทำงานส่วนบุคคล
2. **กดุมภะ (House 2)**: แหล่งทรัพยากรการเงิน สินทรัพย์ และการประเมินการจัดสัดส่วนเครื่องมือ
3. **สหัชชะ (House 3)**: สังคมในระดับใกล้ชิด การสื่อสารระยะสั้น การเจรจารายวัน และการเดินทางบ่อย
4. **พันธุ (House 4)**: ฐานหลักการทำงาน ระบบสนับสนุน (Supportive network) และสภาพแวดล้อมที่ตั้งของสำนักงาน
5. **ปุตตะ (House 5)**: โครงการริเริ่มสร้างสรรค์ใหม่ๆ งานทดลองระดับเริ่มต้น หรือความสุขุมในการริเริ่มภารกิจ
6. **อริ (House 6)**: โหมดงานแก้ปัญหาเฉพาะหน้า การตรวจสภาพความล้าของร่างกาย และการจัดการอุปสรรค
7. **ปัตนิ (House 7)**: ผู้ร่วมสัญญา พันธมิตรทางธุรกิจ และโหมดวางแผนเจรจาตกลงผลประโยชน์
8. **มรณะ (House 8)**: การสิ้นสุดและการส่งผ่านระบบ การฟื้นฟูปรับปรุงโครงสร้างงานเดิม และการแก้ไขข้อตกลงระยะยาว
9. **ศุภะ (House 9)**: องค์ความรู้ใหม่ วิสัยทัศน์กว้างไกล การศึกษาเพิ่มเติม และการวางมุมมองระยะยาว
10. **กัมมะ (House 10)**: หน้าที่รับผิดชอบหลัก งานส่งมอบที่ต้องใส่แรงพลังสมองสูง และเป้าหมายความลุล่วง
11. **ลาภะ (House 11)**: เครือข่ายการส่งต่อกลุ่มเพื่อน โอกาสรับประโยชน์พิเศษ และผลสัมฤทธิ์ปลายน้ำ
12. **วินาศ (House 12)**: ภารกิจเบื้องหลัง การปกปิดปิดทองหลังพระ โหมดการเก็บตัวทำงานสันโดษ และการหยุดชะงักเพื่อทบทวน

## 7. Work & Life Strategy Focus Houses (ภพชะตาที่ใช้ในการจัดวางแผน)

ระบบ Astro Strategy Lab ในเวอร์ชัน 0.1 จะดึงข้อมูลเฉพาะกลุ่มภพเด่นเพื่อนำเสนอเป็นคำเตือนและแผนกิจกรรมบน Today Panel ดังนี้:
* **ตนุ (ตัวตน)**: วิเคราะห์แนวทางสไตล์การใช้สมองและการลงมือทำงาน
* **กัมมะ (การงาน)**: ใช้แสดงภารกิจหลักที่ผู้ใช้ต้องส่งมอบ
* **ลาภะ (ความสำเร็จ)**: ประเมินเครือข่ายโอกาสในการช่วยอำนวยความสะดวก
* **อริ (ปัญหาและการสะสาง)**: แปลงเป็นรายการจุดเตือนด้านสุขภาพการทำงาน ความล้าสะสม และการแก้บั๊ก
* **วินาศ (การทำงานเบื้องหลัง)**: ระบุช่วงเวลาการลดกิจกรรมประชุมภายนอก หรืองดงานสังคมเร่งร้อน
* **ปัตนิ (การร่วมประสาน)**: ออกคำแนะนำสำหรับแผนการติดต่อประสานงานคู่ค้า
* **พันธุ (ระบบสนับสนุน)**: การจัดระเบียบพื้นที่รอบตัวและระบบแบคอัพข้อมูล
* **ศุภะ (การเปิดรับวิสัยทัศน์)**: แนะนำให้ศึกษาเอกสารวิเคราะห์และสรุปบทเรียนประจำวัน

## 8. Strategy Signal IDs (รายการสัญญะสำหรับแปลผลกลยุทธ์)

รหัสสั้น (Signal IDs) ที่ถูกคืนในผลลัพธ์ข้อมูลเพื่อนำไปเชื่อมโยงกับรายละเอียดข้อความกลยุทธ์ในระบบพจนานุกรมแปลผล:

### 1. รูปแบบตัวตนและการทำงาน (TH_HOUSE_SELF_WORK_STYLE)
* `TH_HOUSE_SELF_WORK_STYLE_SPRINTER`: เหมาะกับโหมดงานเร่งเสร็จเร็วจบในรอบวัน
* `TH_HOUSE_SELF_WORK_STYLE_SYSTEMATIC`: เหมาะกับการสร้างเสถียรภาพและสร้างรูทีน

### 2. ภาระการงานหลัก (TH_HOUSE_CAREER_FOCUS)
* `TH_HOUSE_CAREER_FOCUS_DELIVERABLE`: มุ่งส่งมอบงานหลักตามใบงานหรือคำสั่งโดยเร็ว
* `TH_HOUSE_CAREER_FOCUS_INFRASTRUCTURE`: วางรากฐาน พัฒนาโปรเจกต์ภายในเครื่องตนเอง

### 3. ผลสัมฤทธิ์และเครือข่าย (TH_HOUSE_NETWORK_GAIN)
* `TH_HOUSE_NETWORK_GAIN_PEER_HELP`: ใช้ความช่วยเหลือของกลุ่มเพื่อนส่งต่องาน
* `TH_HOUSE_NETWORK_GAIN_MILESTONE_ACHIEVE`: ตรวจจับผลสัมฤทธิ์ตามกรอบหลักไมล์

### 4. การจัดการปัญหาและบั๊ก (TH_HOUSE_PROBLEM_SOLVING)
* `TH_HOUSE_PROBLEM_SOLVING_REFACTOR`: สะสางปัญหาซ่อนเร้น ลบโค้ดส่วนเกิน (Anti-Bloat)
* `TH_HOUSE_PROBLEM_SOLVING_CONFLICT_RESOLVE`: เจรจาระงับข้อพิพาทในความรับผิดชอบ

### 5. โหมดพักจำศีลและกิจกรรมเบื้องหลัง (TH_HOUSE_RECOVERY_BACKSTAGE)
* `TH_HOUSE_RECOVERY_BACKSTAGE_OFF_SCREEN`: ปิดกั้นการรบกวนหน้าจอ ลุยงานเอกสารเงียบๆ
* `TH_HOUSE_RECOVERY_BACKSTAGE_RESTORE_ENERGY`: ชะลอแผนงานใหญ่ เน้นชดเชยเวลาพัก

### 6. การประชุมและการเจรจา (TH_HOUSE_COLLABORATION)
* `TH_HOUSE_COLLABORATION_ALIGNMENT`: สอดประสานความเข้าใจร่วมกับทีมงานคู่ค้า
* `TH_HOUSE_COLLABORATION_CONTRACT_SIGN`: ตรวจทานข้อกำหนดเพื่อจัดทำสัญญาอย่างรอบคอบ

### 7. โครงสร้างสนับสนุนระบบ (TH_HOUSE_HOME_BASE)
* `TH_HOUSE_HOME_BASE_WORK_FROM_HOME`: ปักหลักทำงานที่บ้าน เลี่ยงออฟฟิศพลุกพล่าน
* `TH_HOUSE_HOME_BASE_WORKSPACE_CLEANUP`: ทำความสะอาดและจัดเก็บไฟล์ใน Workspace

### 8. การขยายปัญญาและความรู้ (TH_HOUSE_LEARNING_EXPANSION)
* `TH_HOUSE_LEARNING_EXPANSION_DEEP_READ`: ใช้เวลาทบทวนเอกสารวางแผนงานวิชาการเชิงลึก
* `TH_HOUSE_LEARNING_EXPANSION_SKILL_UPGRADE`: อัปเกรดขีดความสามารถเฉพาะทาง

### 9. การชะลอและทบทวนความคุ้มค่า (TH_HOUSE_DELAY_REVIEW)
* `TH_HOUSE_DELAY_REVIEW_RISK_CHECK`: ประเมินข้อตกลงและตรวจสอบเอกสารการเสียภาษี/บัญชี
* `TH_HOUSE_DELAY_REVIEW_ANTI_BLOAT_SCAN`: ทบทวนฟีเจอร์ที่ไม่จำเป็นของแผนงาน

### 10. ข้อควรระมัดระวังในการตัดสินใจ (TH_HOUSE_DECISION_CAUTION)
* `TH_HOUSE_DECISION_CAUTION_NO_IMPULSE`: ห้ามตัดสินใจด้วยอารมณ์ชั่ววูบในเรื่องเงิน
* `TH_HOUSE_DECISION_CAUTION_CONSENSUS_FIRST`: ปรึกษาผู้ร่วมงานส่วนใหญ่ก่อนลงนามอนุมัติ

## 9. Confidence Policy (นโยบายการประเมินคะแนนความมั่นใจ)

เพื่อปกป้องสิทธิ์และการรับรู้ข้อมูลที่แม่นยำของผู้ใช้ ระบบจะใช้นโยบายความมั่นใจดังนี้:
* **การถ่ายทอดคะแนนความคลาดเคลื่อน (Confidence Cascading)**: หากคะแนนความมั่นใจของลัคนาชะตากำเนิดต่ำ (เช่น ต่ำกว่า 0.4) คะแนนความมั่นใจของภพชะตาเฉลี่ยจะต้องถูกปรับลดลงให้เทียบเท่าโดยอัตโนมัติ
* **การปกป้องกรณีเวลาเกิดสูญหาย (Missing Birth Time)**: ในกรณีที่ระบุเวลาเกิดไม่ได้ ระบบจะไม่ทำการแปลความหมายของเนื้อหาภพชะตาแบบเจาะจงรายบุคคล (House-level interpretation) และให้สิทธิการแสดงผลเฉพาะ Today Engine เดิมเพื่อความปลอดภัยของแผนกลยุทธ์
* **กรณีสถานที่เกิดสูญหาย**: ปรับลดระดับความเชื่อมั่นของเรือนชะตาลง 20%
* **ข้อกำหนดเตือนรอยต่อวัน**: แสดงข้อความเตือนเด่นชัดเมื่อตรวจจับรอยต่อของวัน (เวลาเกิด 00:00 - 06:00 น.) ในส่วนหมายเหตุความไม่แน่นอน (`uncertaintyNotes`)
* **ไม่เคลมเป็นสัจธรรม**: ห้ามแสดงผังเรือนชะตาเป็นสัจธรรมเด็ดขาดเมื่อคะแนนความเชื่อมั่นอยู่ในเกณฑ์ต่ำ

## 10. Product Interpretation Policy (นโยบายแปลผลเชิงจิตวิทยาเชิงบวก)

ระบบการแมปและถอดความหมายภพชะตาจะประยุกต์ใช้เพื่อการประคองทิศทางการตัดสินใจเท่านั้น:
* **แปลผลเพื่อจัดระเบียบภารกิจ**: แนะนำช่วงเวลาและกิจกรรมทำงานที่สอดคล้องกับพฤติกรรม
* **หลีกเลี่ยงคำทำนายเคราะห์กรรม (Copy Safety)**: 
  - ห้ามอ้างอิงเรื่องกาลกิณี อุบัติเหตุ ความสูญเสียในครอบครัว หรือชะตากรรมที่หลีกเลี่ยงไม่ได้
  - ห้ามใช้คำตัดสินความพังพินาศของการเงินและความรัก
  - แปลงภพมรณะ (House 8) เป็น "การปรับปรุงรูปแบบโครงสร้างงานเดิม" และแปลงภพวินาศ (House 12) เป็น "การประมวลผลงานเบื้องหลัง" เท่านั้น

## 11. Data Safety & Storage (ความปลอดภัยในการจัดเก็บข้อมูล)

* **ความปลอดภัยของ LocalStorage**: ในเวอร์ชัน 0.1 นี้ระบบจะประมวลผลและสร้างผังภพเรือนชะตาบนหน่วยความจำชั่วคราว (In-memory) เท่านั้น ไม่จัดเก็บโครงสร้างนี้ลงใน LocalStorage
* **กรอบการบันทึกถาวรในอนาคต**: หากต้องมีการ Persist ข้อมูลในภายหลัง ให้บันทึกเฉพาะ **House IDs** หรือ **Zodiac Placement Keys** ของลัคนา ห้ามจัดเก็บคำแปลยาวดิบลงไปเพื่อหลีกเลี่ยง Regression และการล้นเนื้อที่ของบราวเซอร์
* **ความเป็นส่วนตัว**: ข้อมูลเกิดและโครงสร้างดวงเป็นความลับส่วนบุคคลของผู้ใช้ หากมีฟังก์ชันส่งออกข้อมูล JSON ระบบจะต้องแจ้งเตือนความเป็นส่วนตัวแก่ผู้ใช้เสมอ

## 12. Non-Scope (ขอบเขตนอกเหนือการดำเนินงาน)

* **ไม่พัฒนาโปรแกรมรันไทม์**: ละเว้นการเขียนโค้ดตรรกะในโปรเจกต์ `src/` ตลอดรอบการทำงานนี้
* **ไม่แตะต้อง LocalStorage schema**: ประคองเสถียรภาพ baseline ปัจจุบัน
* **ไม่มีการเชื่อมต่อภายนอก**: ไม่ดึง API โหราศาสตร์ และไม่ใช้ระบบ Ephemeris หรือขยายขนาดบันเดิล
* **ไม่ใช้คำพยากรณ์เชิงโชคชะตา**: ยึดหลักข้อตกลงจิตวิทยาบวกและยุทธศาสตร์การทำงานเท่านั้น
