## 7. Transit-Date Failure Mode

**Observed symptom only (recorded, not asserted as root cause):**

- A selected transit date reportedly **returned to the current date** after some interaction.

**Architecture hypotheses (explicitly separate from the observed symptom):**

- Timer overwriting user-selected state
- Remount resetting to today
- URL/storage/UI state divergence
- Stale service-worker bundle
- PWA lifecycle mismatch

These are hypotheses for future investigation, **not** conclusions. No root cause is asserted in this gate.

---

## 8. Required Time-State Contract

To prevent the failure mode above, the system must keep three time values distinct and explicit:

| Value | Meaning |
| :--- | :--- |
| `referenceNow` | The system's reference "now" used for default calculations. |
| `selectedEventTime` | The user-selected event/transit time for a calculation. |
| `calculationTime` | The timestamp at which a specific calculation result was produced. |

**Rule**: These values must remain **separate**. **Only an explicit user command may return `selectedEventTime` to today.** No timer, remount, or background refresh may silently overwrite `selectedEventTime`.

**Required contract fields**:

- timezone
- calendar/date source
- persistence policy (where each time value is stored and how it survives reload)
- calculation request ID
- calculation result version
- report/history date consistency (what date is shown in history/report)

## 9. Calculation and Interpretation Authority

- Every date/time input goes through the **Calculation Authority** before any interpretation.
- There is **no special prompt-only path for “today”** — the AI must never be the source of a chart calculation.
- Produces a **versioned deterministic calculation result**.
- **Validation before interpretation**: calculated facts are validated before any AI explanation consumes them.
- AI explanation receives **calculated facts and provenance**; it does not compute charts from model memory.
- AI does not calculate charts — it interprets already-calculated, versioned results.
