# DEV-040 — Astro Real App MVP-v3 Roadmap & Scope Lock

## Goal
จัดทำแผนงานและเอกสารขอบเขตข้อกำหนดระบบขั้นถัดไป (MVP-v3 Roadmap & Scope Lock) ของระบบ Astro Strategy Lab เพื่อจัดลำดับความสำคัญของสายงานพัฒนา (Workstreams) ควบคุมระดับความเสี่ยงทางสถาปัตยกรรมข้อมูล และล็อกขอบเขตของฟีเจอร์อย่างรัดกุมก่อนเริ่มเข้าสู่เฟสการพัฒนาถัดไป

## Scope
- การกำหนดหัวข้อเป้าหมายและธีมหลักของระบบเวอร์ชัน MVP-v3
- การวิเคราะห์สายงานย่อยในการพัฒนา 7 สายงานหลัก (Onboarding, Backup/Restore, Scalability, Advanced timing engine, Thai layer, Chinese layer, Chakra layer)
- การจัดลำดับความสำคัญในสายการพัฒนาโค้ด (Prioritized DEV Sequence)
- การระบุข้อห้ามในการพัฒนาสำหรับเฟสนี้ (What must not be built yet)
- การทบทวนมาตรฐานการป้องกันข้อมูลและจริยธรรมภาษา (Data Safety & Copy/Ethics Guardrails)

## Non-scope
- ไม่แก้ไข ดัดแปลง หรือสลับตัวนำทางในไฟล์ซอร์สโค้ดโปรแกรมรันไทม์ (Documentation-only)

## MVP-v2 Completion Baseline
- **ความสำเร็จสูงสุด**: แอปพลิเคชันจริงรันไทม์ (Today, Weekly, Monthly, Profile, Reflection, History, Planning) แสดงผลบนเส้นทางหลัก `/workspaces/astro-strategy` อย่างสมบูรณ์และเสถียร
- **ตรรกะข้อมูล**: ข้อมูลจัดเก็บแยก Namespace ปลอดภัยภายใต้ `astro-real-app:*` และมีระบบควบคุม Data Tools แยกเฉพาะหน้าพรีวิวย่อยอย่างปลอดภัย

## MVP-v3 Theme & Product Direction
* **ธีมหลัก (Theme)**: **"Precision Timing, Scalable Storage & Multi-Tradition Synthesis"**
* **ทิศทางผลิตภัณฑ์ (Product Direction)**: เปลี่ยนผ่านจากเครื่องมือจัดสเปกแบบง่ายสู่ระบบจัดวางแผนและประคองสมาธิเชิงลึก (Focus Operating System) ที่รวมความรู้จังหวะดาราศาสตร์และฤกษ์ยามของเอเชียตะวันออกและตะวันตกเข้าไว้ด้วยกันอย่างเป็นกลาง ปลอดภัย และอิงจริยธรรมข้อมูลส่วนบุคคลสูงสุด

## Workstream Breakdown

### Workstream 1: Onboarding / First-Run Guidance (คำแนะนำใช้งานครั้งแรก)
* **เป้าหมาย**: เพิ่มหน้าจอยินดีต้อนรับและการกรอกข้อมูล Birth Profile อย่างเป็นระเบียบเมื่อผู้ใช้เปิดใช้งานระบบเป็นครั้งแรก (First-run detection)
* **กลไก**: หากพบว่าคีย์ `astro-real-app:birth-profile:v1` ว่างเปล่า ระบบจะบังคับให้แสดงหน้ากรอกโปรไฟล์ดวงเกิดก่อนเข้าสู่แท็บ Today เพื่อลดความสับสนและปรับปรุงประสบการณ์ใช้งาน (UX)

### Workstream 2: Export / Backup / Restore (การสำรองและกู้คืนประวัติ)
* **เป้าหมาย**: เพิ่มปุ่มสำหรับการดาวน์โหลดประวัติสะท้อนคิดสะสม (`historyLogs`) และแผนงานออกเป็นไฟล์ JSON และการกู้คืน (Import/Restore) เพื่อความปลอดภัยเมื่อผู้ใช้ต้องการเปลี่ยนเครื่องหรือเบราว์เซอร์

### Workstream 3: Storage Scalability (IndexedDB / Pagination)
* **เป้าหมาย**: เพิ่มประสิทธิภาพการบันทึกประวัติเพื่อความเร็วในกรณีประวัติสะสมมีจำนวนรายการสูง
* **กลไก**: พัฒนาตัวแยกแบ่งหน้า (Pagination) ในแผงประวัติ (History Panel) เพื่อโหลดประวัติรอบละ 20 รายการ และเตรียมเปลี่ยนตัวจัดเก็บเบื้องหลังเป็น IndexedDB แทน LocalStorage เพื่อขยายขีดความจุความปลอดภัย

### Workstream 4: Advanced Timing Engine (พิกัดดาราศาสตร์แม่นยำ)
* **เป้าหมาย**: ยกระดับระบบคำนวณ timing จากแบบใช้เงื่อนไขสูตรตายตัว (Rule-based) ไปสู่ระบบพิกัดคำนวณตรรกะทางดาราศาสตร์จริงอิงตามตารางดาวเคราะห์ (Ephemeris calculations) หรือ Solar Transits เพื่อความแม่นยำตามพิกัดละติจูดและลองจิจูดเกิด

### Workstream 5: Thai Astrology Layer (โหราศาสตร์ไทยและการวางจังหวะท้องถิ่น)
* **เป้าหมาย**: ผสานมิติความรู้ฤกษ์ยามไทยที่เป็นกลางและเอื้อต่อการทำงานส่วนบุคคล
* **ขอบเขต**: ผสานตรรกะระบบเวลา เช่น "ฤกษ์ยามอุบากอง" (ยามเดินทาง/ยามเริ่มโครงการ) หรือ "จังหวะธาตุรายวัน" มาใช้เป็นตัวเลือกประกอบการวางแผนสั้น ๆ

### Workstream 6: Chinese Metaphysics / I Ching Layer (อี้จิงและจังหวะเวลาจีน)
* **เป้าหมาย**: รวมการประเมินสัญลักษณ์อี้จิง (Hexagrams) ประจำวัน หรือการคำนวณธาตุ 5 แขนงตามฤดูกาลมาใช้ชี้แนะกลยุทธ์การทำงานเชิงลึก

### Workstream 7: Chakra & Meditation Support Layer (ระบบประคองจักระและจิตวิทยาการพักผ่อน)
* **เป้าหมาย**: เพิ่มกลไกและคำแนะนำเชิงสมาธิและการฟื้นฟูจักระ (Chakra alignment) เพื่อผสานความเหนื่อยล้าทางสมอง เช่น แนะนำการพักผ่อนแนวจิตบำบัด หรือการเปิดเสียงผ่อนคลาย (Sound anchor) เมื่อผู้ใช้บันทึกระดับความจดจ่อว่า "เหนื่อยล้าสะสม"

## Prioritized DEV Sequence (ลำดับขั้นการพัฒนา)
เพื่อรักษาวินัยความก้าวหน้าและการป้องกันฟีเจอร์บวม ให้เรียงลำดับการพัฒนาดังนี้:
1. **DEV-041**: อิมพลีเมนต์ Onboarding / First-Run Detection และหน้าจอนำทางกรอกโปรไฟล์ดวงเกิดแรกเริ่ม
2. **DEV-042**: อิมพลีเมนต์ระบบ Export / Import / Backup / Restore ข้อมูล JSON ของประวัติและแผนงาน
3. **DEV-043**: พัฒนาระบบแบ่งหน้า (Pagination) ในแผงประวัติเพื่อประคองประสิทธิภาพ LCP
4. **DEV-044**: เชื่อมต่อฤกษ์ยามเอเชีย (Thai Layer - ยามอุบากอง และ Chinese Layer - จังหวะธาตุประจำฤดูกาล) เป็นค่าฟิลด์เสริมของสรุปวันทำงาน
5. **DEV-045**: เพิ่มคำแนะนำเชิงสมาธิและการพักผ่อนฟื้นฟูจักระเมื่อประวัติเช็คอินรายงานความตึงเครียดสูง

## What Must NOT Be Built Yet (ขอบเขตที่ห้ามแตะต้อง)
- **ห้าม** สร้างกลไก AI Generative Advice หรือ API ส่งข้อมูลออกภายนอก (เพื่อรักษาความเป็นส่วนตัวของข้อมูลผู้ใช้งาน 100% ภายในเครื่อง)
- **ห้าม** เชื่อมต่อระบบ Cloud Database หรือระบบสมาชิกเรียกเก็บเงิน (Paid subscriptions)
- **ห้าม** เขียนคำทำนายโชคชะตาที่สร้างความกลัว สุขภาพกายที่ร้ายแรง ชะตากรรม หรือภัยพิบัติล่วงหน้าเด็ดขาด

## Data Safety & Copy/Ethics Guardrails
- **ความปลอดภัยข้อมูล**: ข้อมูลทั้งหมดของ MVP-v3 ต้องคงคุณสมบัติจัดเก็บภายในเบราว์เซอร์ของผู้ใช้เท่านั้น (Local-first)
- **ภาษาและจริยธรรม**: ยึดโทนภาษาในการวางแผนงาน การจัดการประสิทธิภาพ และความสงบทางสมาธิ (Cognitive Calmness & Professional Performance) ปราศจากเรื่องลี้ลับเด็ดขาด

---

## Technical & UX Risks
- **ความลื่นไหลของหน้าจอ (Hydration mismatches)**: การเรียกทำงานพิกัดเวลาของเครื่องจำลองในช่วง Mount เพจของ NextJS อาจกระตุ้นผล hydration ผิดพลาดได้ ดังนั้นต้องใช้ hook ควบคุมการโหลดหลัง hydration เสมอ
- **สัดส่วนข้อมูลที่หนาแน่นขึ้น (UX Density)**: การรวมศาสตร์หลายTraditional อาจทำให้หน้าจอรกเกินไป
  - *การป้องกัน*: เพิ่มระบบ Collapse/Expand หรือฟิลเตอร์เลือกว่าผู้ใช้ต้องการดูศาสตร์แขนงใดบ้าง
