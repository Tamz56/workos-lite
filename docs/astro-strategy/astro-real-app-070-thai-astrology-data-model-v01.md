# ASTRO-REAL-APP-DEV-070 — Thai Astrology Data Model v0.1

## Goal
ออกแบบข้อกำหนดโครงสร้างข้อมูลระบบโหราศาสตร์ไทยขั้นต้น (Thai Astrology Data Model v0.1) สำหรับแอปพลิเคชัน Astro Strategy Lab ของระบบ ArborDesk โดยยึดหลักสถาปัตยกรรม Natal + Transit จาก DEV-069 เพื่อนำมาประยุกต์ใช้ในการสกัดสัญญาณกลยุทธ์การทำงานและการจัดเวลาพักผ่อน โดยเอกสารนี้เป็นข้อกำหนดเชิงทฤษฎีและสัญญาข้อมูลหลัก (Data Contract Specs) ที่จะยังไม่มีการแก้ไขซอร์สโค้ดจริงในรอบนี้

## 1. Birth Profile Expansion
ในเฟสถัดไป ข้อมูลประวัติเกิดดั้งเดิม (`AstroBirthProfile`) จะต้องได้รับการขยายขอบเขตเพื่อรองรับการผูกดวงแบบดาราศาสตร์ไทยบนเบราว์เซอร์ โดยกำหนดเป็นฟิลด์ชนิด Optional ทั้งหมดเพื่อป้องกันความเสียหายของข้อมูลเก่า:

```typescript
export interface ThaiBirthProfileExtension {
  /** พิกัดละติจูดสถานที่เกิดเพื่อคำนวณลัคนาจริง (เช่น 13.7563 สำหรับกรุงเทพฯ) */
  readonly latitude?: number;
  /** พิกัดลองจิจูดสถานที่เกิด (เช่น 100.5018) */
  readonly longitude?: number;
  /** เขตเวลาตอนเกิดอิงตาม IANA Database (เช่น "Asia/Bangkok") */
  readonly timezone?: string;
  /** ข้อมูลวันจันทรคติไทยจำลอง (ถ้าคำนวณสกัดได้) */
  readonly lunarInfo?: {
    readonly waxingWaning: "waxing" | "waning"; // ข้างขึ้น / ข้างแรม
    readonly lunarDay: number; // 1-15 ค่ำ
    readonly lunarMonth: number; // เดือนจันทรคติไทย เช่น เดือน 5, เดือน 8
    readonly zodiacYear: string; // ปีนักษัตรไทย (ชวด, ฉลู, ขาล...)
  };
}
```

## 2. Natal Chart Data Model (ดวงกำเนิด)
โครงร่างสัญญาข้อมูลแผ่นดวงชะตากำเนิด (Natal Chart) ของดวงบุคคลจริงเพื่อทำหน้าที่เป็นพิกัดอ้างอิงเชิงกลยุทธ์:

```typescript
export interface ThaiNatalChart {
  /** ลัคนาเกิดสถิตราศีใด (Ascendant Sign) */
  readonly ascendantZodiac: ThaiZodiacSign;
  /** องศาของลัคนาเกิด (0 - 29.99 องศา) */
  readonly ascendantDegree: number;
  /** พิกัดตำแหน่งดาวเกษตรในแต่ละช่องจักรราศี */
  readonly planetPositions: ThaiPlanetPosition[];
  /** ธาตุประจำแผ่นดวงเกิดเชิงสถิติ (คำนวณจากสัดส่วนดาวสถิตราศีธาตุต่าง ๆ) */
  readonly dominantElements: {
    readonly earth: number; // คะแนนสัดส่วน 0.0 - 1.0
    readonly water: number;
    readonly wind: number;
    readonly fire: number;
  };
}
```

## 3. Thai Planet / Graha Model (ดาวเคราะห์และจุดอ้างอิงโบราณ)
การกำหนดรหัสมาตรฐานและโครงสร้างดาวทางโหราศาสตร์ไทย 10 ดวงหลักร่วมกับจุดพิกัดลัคนา:

### ตารางมาตรฐานดาวเคราะห์ไทย
| ID ดาว | ชื่อดาวภาษาไทย | ชื่อภาษาอังกฤษ | สัญญะเชิงกลยุทธ์ (Strategic Core) |
| :--- | :--- | :--- | :--- |
| `1` | อาทิตย์ | Sun | เกียรติยศ, ความเจิดจ้า, พลังชีวิต, อัตตา |
| `2` | จันทร์ | Moon | อารมณ์, ความใส่ใจ, การบริการ, สมาธิรับฟัง |
| `3` | อังคาร | Mars | พลังขับเคลื่อน, ความรวดเร็ว, การลงมือปฏิบัติงาน |
| `4` | พุธ | Mercury | การสื่อสาร, งานเขียนบทความ, ลอจิกลงรหัส |
| `5` | พฤหัสบดี | Jupiter | ปัญญาความรู้, จริยธรรม, การวางแผนใหญ่, วิสัยทัศน์ |
| `6` | ศุกร์ | Venus | ศิลปะและการออกแบบ, ความคิดสร้างสรรค์, การจัดสรรการเงิน |
| `7` | เสาร์ | Saturn | ความอดทน, งานโครงสร้าง, ความรับผิดชอบ, ความเครียด |
| `8` | ราหู | Rahu (North Node) | งานทางเลือกเทคโนโลยี, การตลาดแปลกใหม่, เครือข่าย |
| `9` | เกตุ | Ketu (South Node) | สัญชาตญาณ, ความคิดฉับพลัน, เรื่องคาดไม่ถึง |
| `0` | มฤตยู | Uranus | การดิสรัปต์ระบบงานเดิม, การหักศอกเรียนรู้ใหม่ |

```typescript
export interface ThaiPlanetPosition {
  readonly planetId: number; // 0-9
  readonly zodiacSign: ThaiZodiacSign;
  readonly houseId: ThaiHouseId;
  readonly degree: number; // องศาในราศี
  readonly minute: number; // ลิปดา
  /** มาตรฐานดาวเคราะห์ในดวงชะตา */
  readonly dignity: ThaiPlanetDignity[];
  /** สัญญาณถอยหลัง/หยุดนิ่ง (Retrograde / Stationary) */
  readonly motion: "direct" | "retrograde" | "stationary";
}
```

## 4. Rasi / Zodiac Model (สัญญะราศี)
แบ่งขอบเขตท้องฟ้าออกเป็น 12 ราศี โดยจับคู่สัมพันธ์กับความถนัดเชิงกลยุทธ์ส่วนบุคคล:

```typescript
export type ThaiZodiacSign =
  | "aries"     // ราศีเมษ (ไฟ) - ริเริ่ม บุกเบิก รวดเร็ว
  | "taurus"    // ราศีพฤษภ (ดิน) - แน่วแน่ มั่นคง ประณีต
  | "gemini"    // ราศีเมถุน (ลม) - สื่อสารสองทาง ประสานงาน
  | "cancer"    // ราศีกรกฎ (น้ำ) - ฟูมฟัก โอบอุ้ม ดูแลบริการ
  | "leo"       // ราศีสิงห์ (ไฟ) - ความเป็นผู้นำ จัดแสดงนำเสนอ
  | "virgo"     // ราศีกันย์ (ดิน) - ตรวจแก้ ดีบัก จัดระบบเอกสาร
  | "libra"     // ราศีตุลย์ (ลม) - หุ้นส่วน ประนีประนอม เจรจา
  | "scorpio"   // ราศีพิจิก (น้ำ) - สืบค้นข้อมูล ลึกลับ มุ่งมั่นแก้ปัญหา
  | "sagittarius" // ราศีธนู (ไฟ) - วางวิสัยทัศน์ วิจัยและพัฒนา
  | "capricorn" // ราศีมังกร (ดิน) - บริหารโครงสร้าง วินัยระยะยาว
  | "aquarius"  // ราศีกุมภ์ (ลม) - เครือข่าย เทคโนโลยี ไอเดียปฏิวัติ
  | "pisces";   // ราศีมีน (น้ำ) - สรุปทบทวน จินตนาการ ศิลปะชั้นสูง
```

## 5. Ruen / House Model (เรือนชะตาสำหรับประเมินทิศทางงาน)
เรือนชะตาทั้ง 12 เป็นการระบุถึงสภาวะแวดล้อมหรือหมวดหมู่ชีวิตที่ดาวเคราะห์ต่าง ๆ เข้ามาส่งอิทธิพล เพื่อนำมาตีความพฤติกรรมการตัดสินใจ:

```typescript
export type ThaiHouseId =
  | "tanu"      // ตนุ (ตัวตน, บุคลิกการใช้ชีวิตประจำวัน)
  | "kadumpa"   // กฎุมพะ (การเงินส่วนบุคคล, ทรัพยากรที่มีในเครื่อง)
  | "sahatcha"  // สหัชชะ (การเจรจาระยะสั้น, งานเขียนบันทึกย่อ)
  | "panthu"    // พันธุ (รากฐานระบบ, โครงสร้างพื้นที่ทำงานหลัก)
  | "putta"     // ปุตตะ (โปรเจกต์ริเริ่มใหม่, นวัตกรรมทดลอง)
  | "ari"       // อริ (อุปสรรค, บั๊กของระบบ, ข้อติดขัด)
  | "patni"     // ปัตนิ (คู่สัญญา, พันธมิตรธุรกิจ, ผู้ตรวจโค้ด)
  | "morana"    // มรณะ (การเปลี่ยนแปลงระบบ, รื้อโค้ดเก่า, ทางไกล)
  | "supa"      // ศุภะ (ความเจริญ, การศึกษาเป้าหมายใหญ่, วิสัยทัศน์)
  | "kamma"     // กัมมะ (หน้าที่การงาน, งานเขียนโค้ดฟีเจอร์หลัก)
  | "lapa"      // ลาภะ (ผลลัพธ์ของงาน, Checkpoint สำเร็จ, โบนัส)
  | "vinas";    // วินาศ (งานลับหลัง, งานเบื้องหลังคลังความรู้)
```

## 6. Dignity / Planet Status Model (เกณฑ์มาตรฐานความเข้มแข็งของดาว)
มาตรฐานความแปรสภาพของดาวดวงเกิดหรือดาวจร ชี้วัดระดับความหนาแน่นของคุณสมบัติ:

```typescript
export type ThaiPlanetDignity =
  | "kaset"     // เกษตรบดี (ความสม่ำเสมอ มั่นคง ยืนระยะได้ยาวนาน)
  | "uch"       // มหาอุจ (ความเด่นชัด มีแรงผลักดันและสมาธิสูงที่สุด)
  | "chak"      // มหาจักร (ความโลดโผน ผันผวน คาดเดายากแต่สร้างผลงานใหญ่)
  | "chok"      // ราชาโชค (การได้ผลลัพธ์ราบรื่น ได้แรงสนับสนุนจากคนรอบตัว)
  | "pra"       // ประเกษตร (ขาดพลังงานในตนเอง ต้องพึ่งพาสภาพแวดล้อมภายนอก)
  | "nid"       // มหานิพัทธ์/พินทุบาทว์ (จุดบกพร่องที่ต้องเฝ้าระมัดระวังเป็นพิเศษ)
  | "normal";   // มาตรฐานปกติทั่วไป
```

## 7. Thai Element / Tattwa Model (ความสัมพันธ์สี่ธาตุหลัก)
การแมปธาตุเกิดคู่กับธาตุวันจรประกอบการปรับสมดุลสมาธิ (ดิน น้ำ ลม ไฟ):

```typescript
export interface ThaiElementRelationship {
  readonly selfElement: "earth" | "water" | "wind" | "fire";
  readonly dayElement: "earth" | "water" | "wind" | "fire";
  /** ลำดับความขัดแย้ง/สอดคล้อง */
  readonly compatibility: "supporting" | "neutral" | "clashing";
  readonly adviceText: string; // แนะนำวิธีผ่อนปรนอาการล้าทางสมอง
}
```

## 8. Transit Timing Input Model (ข้อมูลดวงจรรายวัน)
พิกัดสำหรับนำเข้าคำนวณดวงจรประจำวันเป้าหมายเพื่อนำมาทำมุมชี้วัดสัมพันธ์กับดวงชะตากำเนิด:

```typescript
export interface ThaiTransitInput {
  /** วันที่ประเมิน เช่น 2026-06-14 */
  readonly targetDate: string;
  /** เวลา ณ ช่วงนั้นๆ */
  readonly targetTime: string;
  /** ตำแหน่งดาวจรบนท้องฟ้าจริง ณ ขณะนั้น */
  readonly transitPlanetPositions: {
    readonly planetId: number;
    readonly zodiacSign: ThaiZodiacSign;
    readonly degree: number;
    readonly motion: "direct" | "retrograde" | "stationary";
  }[];
}
```

## 9. Strategy Signal Output IDs
เพื่อป้องกันปัญหาระบบเขียนอักษรภาษาไทยยาว ๆ จนพื้นที่สะสมข้อมูลเต็ม (ตามข้อกำหนด Anti-Bloat) ระบบจะกำหนดรหัสสั้น (Output IDs) ลงใน JSON แล้วจึงนำไปแมปกับบทความภาษาไทยที่จัดเก็บในฝั่ง Client Dictionary:

```typescript
export type ThaiAstroStrategySignalId =
  | "TH_SIG_DEEP_WORK"       // ยามปลอดโปร่ง เหมาะสำหรับ Deep Work
  | "TH_SIG_QA_REVIEW"       // ยามศูนย์หนึ่ง เหมาะกับงานตรวจทานดีบัก
  | "TH_SIG_RECALIBRATE"     // วันเกิดทับลัคนา ควรชะลอการเปิดโปรเจกต์ใหม่
  | "TH_SIG_COMMUNICATE"     // ดาวพุธส่งกระแสถึงลัคนา สื่อสารราบรื่น
  | "TH_SIG_REST_EYE"        // ยามมหาอุบาทว์ล้าสะสม แนะนำให้พักสายตาด่วน
  | "TH_SIG_AVOID_DECISION"  // ดาวเสาร์กดทับดาวจันทร์เกิด เลี่ยงการคุยประเด็นขัดแย้ง
  | "TH_SIG_REFACTOR";       // ดาวอังคารร่วมดาวอูเรนัส จัดระเบียบเคลียร์โค้ดเก่า
```

## 10. Compatibility กับ Export / Import / Restore
เพื่อรักษาคุณสมบัติความเข้ากันได้ย้อนหลังอย่างสมบูรณ์แบบ (Backward Compatibility 100%) ในเฟสถัดไป:
- ข้อมูลโมเดลใหม่ทั้งหมดของโหราศาสตร์ไทยจะสถิตอยู่ภายใต้ฟิลด์ Optional ในระบบโปรไฟล์ดวงเกิดเดิม
- ฟังก์ชัน Validator ของระบบนำเข้า/ส่งออก JSON จะต้องยอมรับการมีอยู่หรือไม่มีอยู่ของคีย์ใหม่นี้โดยไม่มีการปฏิเสธไฟล์ประวัติสะสมเดิมของผู้ใช้ (Graceful fallback)

## 11. Non-scope (ขอบเขตที่ไม่สร้างในเวอร์ชัน v0.1)
- **ไม่ทำ MyHora Clone**: จะไม่มีการวาดจักรราศีแผงกลมแบบทศนิยม 4 ตำแหน่งหรือแสดงการทำมุมกากบาทลวดลายยุ่งเหยิงบนแผงควบคุมหลัก
- **ไม่พยากรณ์ลี้ลับ**: แบนระบบตีความชะตากรรมเรื่องอุบัติเหตุ โชคร้าย และการสูญเสียทางการเงิน
- **ไม่เก็บข้อความเอาท์พุตยาว ๆ ลง Storage**: จะเก็บเฉพาะค่า `ThaiAstroStrategySignalId` เพื่อประหยัดเนื้อที่ LocalStorage
